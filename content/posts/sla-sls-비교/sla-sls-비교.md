산업용 3D프린팅 방식 중 가장 많이 쓰이는 둘이 SLA와 SLS입니다. 둘 다 정밀하고 표면이 좋지만, 쓰는 곳이 다릅니다.

**어느 쪽이 맞는지는 부품이 정합니다.**

# 핵심 차이

| 항목 | SLA (레진) | SLS (분말) |
| --- | --- | --- |
| 원리 | 레이저가 액체 레진을 굳힙니다 | 레이저가 나일론 분말을 녹여 붙입니다 |
| 소재 | 광경화 레진 (수십 종) | 나일론 PA12, PA11, TPU 등 |
| 서포트 | 필요합니다. 떼어낸 자국이 남습니다 | 필요 없습니다. 분말이 서포트 역할을 합니다 |
| 표면 | 매끄럽습니다 | 약간 거칩니다 (미세한 분말 질감) |
| 치수 정확도 | ±0.05~0.1 mm | ±0.1~0.2 mm |
| 강도 | 레진에 따라 다릅니다. 일반 레진은 잘 깨집니다 | 나일론이라 충격에 강합니다 |
| 내열성 | 고온 레진은 200°C 이상 | PA12 기준 약 180°C |
| 한 판 출력량 | 중소형 부품 수 개 | 빌드 챔버에 수십~수백 개 적재 |

# 이 부품이면 SLA

| 용도 | 이유 |
| --- | --- |
| 외관 시제품 | 표면이 매끄럽고 디테일이 살아납니다 |
| 정밀 부품 | ±0.05 mm 수준의 치수 정확도가 필요할 때 |
| 투명 부품 | 투명 레진이 있습니다. SLS에는 없습니다 |
| 주조 원형 | 캐스터블 레진으로 직접 소실 주조가 됩니다 |
| 금형 인서트 | 고온 레진으로 사출·진공성형 금형을 만듭니다 |

SLA가 맞는 부품은 **외관이 중요하거나 치수가 정밀해야 하는 것**입니다.

# 이 부품이면 SLS

| 용도 | 이유 |
| --- | --- |
| 기능 시제품 | 나일론이라 떨어뜨려도 안 깨집니다 |
| 조립 검증 | 서포트 자국이 없어 조립면이 깨끗합니다 |
| 소량 양산 | 한 판에 수십 개를 채워 단가를 낮춥니다 |
| 복잡한 형상 | 서포트 없이 내부 채널이나 격자가 됩니다 |
| 스냅핏·힌지 | 나일론의 탄성으로 반복 탈착이 됩니다 |

SLS가 맞는 부품은 **맞아도 안 깨져야 하거나, 형상이 복잡하거나, 수량이 많은 것**입니다.

# 비용 비교

| 항목 | SLA | SLS |
| --- | --- | --- |
| 1개 단가 | 낮음~보통 | 보통~높음 |
| 10개 이상 | 개수에 비례 | 적재 밀도를 올리면 단가 낮아짐 |
| 100개 이상 | 비용 높아짐 | SLS가 유리 (한 판에 채움) |
| 후처리 비용 | 서포트 제거 + 세척 + UV 후경화 | 분말 제거 + 선택적 표면 마감 |

**소량이면 SLA, 수량이 늘면 SLS가 유리합니다.** SLS는 한 판에 빈 공간을 채워 넣을 수 있어서 수량이 늘수록 단가가 빠르게 떨어집니다.

비용이 어떻게 갈리는지는 [같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)에 정리했습니다.

# 둘 다 되는 경우

부품에 따라 SLA와 SLS 둘 다 가능한 경우가 있습니다.

| 상황 | 추천 |
| --- | --- |
| 외관 확인만 할 것 | SLA (표면이 나음) |
| 조립 검증까지 할 것 | SLS (서포트 자국 없음, 안 깨짐) |
| 투명해야 할 것 | SLA (SLS에는 투명 소재 없음) |
| 검은색이면 되는 것 | SLS (나일론 기본색이 검정/회색) |
| 색상이 중요한 것 | SLA (컬러 레진 또는 도색 용이) |

한 방식으로 정하기 어려우면 같은 부품을 SLA·SLS 각각 뽑아 비교하는 방법도 있습니다. [같은 부품을 방식별로 뽑아 비교한 사례](/blog/같은-부품-방식별-비교-사례-3건/)에 실물 비교를 정리했습니다.

# 담당자가 확인할 것

1. **부품 용도**를 알려주십시오. 보여 줄 것이면 SLA, 써 볼 것이면 SLS가 맞습니다.
2. **필요한 표면 수준**을 정합니다. 도색할 거면 SLA, 기능만 되면 SLS입니다.
3. **수량**을 알려주십시오. 10개 이상이면 SLS 적재를 검토합니다.
4. **치수 공차**를 확인합니다. ±0.1 mm 이내면 SLA가 유리합니다.

# 자주 묻는 질문

## SLS는 왜 서포트가 없나요

분말이 서포트입니다. 출력하지 않은 분말이 부품 주위에 쌓여 있어 아래로 처지지 않습니다. 출력이 끝나면 분말을 털어 내면 됩니다. 서포트 제거 작업이 없어 조립면이 깨끗합니다.

## SLA 부품이 잘 깨진다고 하던데요

일반 레진(스탠다드 레진)은 경도가 높지만 충격에 약합니다. 떨어뜨리면 깨질 수 있습니다. 하지만 터프 레진이나 듀러블 레진은 ABS 수준의 내충격성이 있습니다. 소재를 바꾸면 됩니다.

## 두 방식을 섞어 쓸 수 있나요

됩니다. 외관 부품은 SLA로, 내부 구조는 SLS로 나눠 뽑은 뒤 조립하는 경우가 있습니다. 각 부품의 요구에 맞는 방식을 고르면 됩니다.

부품 용도와 수량을 알려주시면 어느 방식이 맞는지 확인해 드립니다.
