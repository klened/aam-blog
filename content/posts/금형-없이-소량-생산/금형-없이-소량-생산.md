가장 애매한 구간이 있습니다. **100개가 필요한 경우**입니다.

시제품이라기에는 많고, 금형을 파자니 아깝습니다. 간이 금형도 200만 원부터 시작하는데, 100개를 뽑고 나면 그 금형은 창고에 들어갑니다.

이 구간을 금형 없이 넘기는 방법이 세 가지 있습니다.

# 1. 3D프린팅 직접 생산

출력한 부품을 그대로 씁니다. 중간 공정이 없습니다.

초기 비용이 **0원**입니다. 데이터만 있으면 오늘 시작합니다. 대신 개당 단가가 수량이 늘어도 크게 안 떨어집니다. 100개를 뽑으면 100개분의 시간이 그대로 듭니다.

| 항목 | 내용 |
| --- | --- |
| 맞는 수량 | 1~30개 |
| 초기 비용 | 없음 |
| 개당 단가 | 3만~30만 원 |
| 납기 | 1~5일 |
| 소재 | 레진, 나일론, ABS, TPU |

**설계가 아직 바뀔 수 있으면 여기가 안전합니다.** 파일만 고치면 다음 것부터 바로 반영됩니다.

부품마다 형상이 다른 경우에도 유리합니다. 100개가 전부 다른 형상이어도 단가가 같습니다. 금형으로는 불가능한 방식입니다.

# 2. 진공주형 (실리콘 몰드)

마스터 모델을 하나 만들고, 실리콘으로 틀을 떠서 우레탄 수지를 붓습니다.

틀 하나로 **10~25개**를 복제합니다. 더 필요하면 틀을 추가로 뜹니다.

| 항목 | 내용 |
| --- | --- |
| 맞는 수량 | 10~50개 |
| 초기 비용 | 마스터 + 틀 30만~130만 원 |
| 개당 단가 | 3만~15만 원 |
| 납기 | 5~10일 |
| 틀 수명 | 10~25회 |

**외관 부품에서 가장 값을 합니다.** 표면이 매끄럽고 도색까지 하면 양산품과 구분이 어렵습니다. 전시회 샘플이나 투자 프레젠테이션, 고객 배포용에 자주 씁니다.

색을 수지에 섞어 넣을 수도 있어서 도색 없이 원하는 색을 낼 수 있습니다.

단점은 틀 수명입니다. 100개를 만들려면 틀을 4~5개 떠야 하고, 그만큼 비용과 시간이 붙습니다.

# 3. 분말 방식 양산 (SLS·SAF·MJF)

분말 속에서 부품을 굳히는 방식입니다. **서포트가 없어서** 조형통 전체를 3차원으로 채웁니다.

이것이 소량 생산에서 결정적입니다. 바닥에만 놓는 것이 아니라 공중에 띄워 층층이 쌓으므로, 한 번 돌릴 때 수십~수백 개가 나옵니다.

| 항목 | 내용 |
| --- | --- |
| 맞는 수량 | 50~수천 개 |
| 초기 비용 | 없음 |
| 개당 단가 | 5,000원~5만 원 |
| 납기 | 3~10일 |
| 소재 | PA12, PA11, PP, TPU |

**수량이 늘수록 개당 단가가 내려갑니다.** 조형통을 얼마나 채우느냐로 정해지기 때문입니다. 100개를 한 통에 넣으면 10개씩 열 번 돌리는 것보다 훨씬 쌉니다.

실제로 이 방식으로 산업 부품을 지속 생산하는 곳들이 있습니다. 폴리프로필렌(PP)처럼 사출에서 쓰던 소재도 분말로 나와 있어서, 금형 없이 양산 소재 그대로 만들 수 있습니다.

배치 설계는 [분말 방식 설계 3가지](/blog/분말-방식-설계-3가지/)에, 방식 차이는 [SLS와 MJF 비교](/blog/sls-mjf-차이/)에 정리했습니다.

수량만으로 정해지지는 않습니다. 아래를 함께 봅니다.

| 조건 | 유리한 방법 |
| --- | --- |
| 외관이 중요하다 | 진공주형 |
| 강도가 필요하다 | 분말 방식 (PA12·CF) |
| 형상이 전부 다르다 | 3D프린팅 직접 |
| 무른 소재가 필요하다 | 진공주형 또는 TPU 분말 |
| 설계가 아직 바뀐다 | 3D프린팅 직접 |
| 양산 소재를 써야 한다 | 분말 방식 (PP 등) |

# 금형으로 넘어갈 때

소량 생산은 결국 다리 역할입니다. 수량이 계속 늘면 어느 지점에서 금형이 싸집니다.

넘어가는 시점을 정하는 기준은 이렇습니다.

1. **월 수량이 안정적으로 수백 개를 넘는가**
2. **설계가 6개월 이상 바뀌지 않았는가**
3. **금형비를 회수할 기간이 잡히는가**

셋이 다 맞으면 금형을 검토합니다. 하나라도 걸리면 소량 생산으로 더 버티는 편이 낫습니다.

금형 전에 검증하는 순서는 [사출 금형 만들기 전에 3D프린팅으로 검증하는 방법](/blog/사출-전-3d프린팅-검증/)에, 방법별 비용 비교는 [시제품 제작 비용](/blog/시제품-제작-비용/)에 정리했습니다.

# 자주 묻는 질문

:::faq
3D프린팅 부품을 실제 제품으로 팔아도 되나요
됩니다. 소량 생산되는 산업 장비 부품이나 의료 보조기구는 실제로 3D프린팅으로 만들어 납품하는 경우가 많습니다. 다만 인증이 필요한 제품이면 소재 인증을 먼저 확인하셔야 합니다.
:::

:::faq
진공주형 부품은 사출품과 물성이 같나요
같지 않습니다. 우레탄 수지라 사출 플라스틱과 다릅니다. ABS나 PP와 비슷한 물성을 내는 수지가 있어서 외관과 감촉은 가깝지만, 정확한 물성 시험이 필요한 부품이면 CNC나 시사출을 쓰셔야 합니다.
:::

:::faq
100개를 만들려면 어느 방법이 가장 싼가요
부품 크기와 소재에 따라 다릅니다. 작은 나일론 부품이면 분말 방식이 가장 쌉니다. 큰 외관 부품이면 진공주형이 유리한 경우가 있습니다. 도면과 수량을 알려주시면 방법별로 비교해 안내드립니다.
:::

:::faq
같은 부품을 계속 주문할 수 있나요
가능합니다. 데이터를 보관하므로 필요할 때마다 같은 조건으로 재생산합니다. 재고를 쌓지 않고 필요한 만큼만 만드는 방식으로 쓰시는 곳이 많습니다.
:::

:::faq
소량 생산도 견적을 받을 수 있나요
됩니다. 도면과 수량, 용도를 알려주시면 방법·소재·단가·납기를 함께 안내드립니다. 수량이 애매한 구간이면 두세 가지 방법을 비교해 드립니다.
:::
