*3D프린팅 소량 생산의 배치 구성을 설명하기 위한 이미지입니다.*

1개 견적을 100배 하면 100개 금액이 될까요. 실제 견적은 그렇게 계산하지 않습니다.

수량이 늘면 파일 검토와 장비 준비 비용을 나눌 수 있습니다. 반면 출력 배치와 후처리를 반복하면 개당 단가가 기대만큼 내려가지 않을 수도 있습니다.

# 단가는 4부분으로 구성됩니다

| 비용 항목 | 수량이 늘 때 생기는 변화 |
| --- | --- |
| 파일 검토·장비 준비 | 여러 부품에 나눠 적용할 수 있습니다 |
| 출력·소재 | 배치 효율이 좋아지면 개당 부담이 줄 수 있습니다 |
| 후처리 | 부품마다 손이 가면 수량에 비례해 늘어납니다 |
| 검사·포장 | 전수 검사와 개별 포장은 수량만큼 작업이 필요합니다 |

3D프린팅은 금형비가 없습니다. 그래서 1개부터 시작하기 좋습니다. 다만 제작 수량이 늘어도 장비 시간과 소재비가 사라지는 것은 아닙니다.

![출력과 후처리, 검사, 포장 단계별로 동일 부품을 분류하는 소량 생산 작업대](/images/3d프린팅-소량생산-단가/4.webp)

# 10개·50개·100개에서 보는 것

| 수량 | 견적에서 먼저 확인할 것 |
| --- | --- |
| 10개 | 한 배치에 들어가는지, 설계 수정 가능성이 남았는지 |
| 50개 | 배치를 몇 번 반복하는지, 후처리를 묶어서 할 수 있는지 |
| 100개 | 장비 생산 능력, 배치별 편차, 검사와 포장 인력 |

작은 SLS 부품은 입체로 배치합니다. 수량이 늘어도 한 배치에 들어가면 효율이 좋아집니다. 큰 FDM 부품은 바닥 면적을 많이 차지하므로 같은 수량도 여러 번 출력할 수 있습니다.

정확한 단가는 파일을 장비에 배치해 봐야 나옵니다.

![SLS 분말층에 같은 부품을 촘촘하게 배치해 한 개를 꺼내는 모습](/images/3d프린팅-소량생산-단가/5.webp)

# 개당 단가가 잘 줄지 않는 경우

도색과 연마는 사람 손이 많이 필요한 공정입니다. 부품마다 마스킹하거나 색을 확인해야 하면 출력 효율과 별개로 비용이 붙습니다.

![한 배치에서 여러 SLS 부품을 꺼내 분말을 제거하는 모습](/images/3d프린팅-소량생산-단가/2.webp)

검사도 같습니다. 주요 치수 2곳을 표본으로 재는 주문과 모든 부품의 10개 치수를 기록하는 주문은 범위가 다릅니다. 개별 포장과 라벨 작업도 따로 계산해야 합니다.

![동일한 3D프린팅 부품을 캘리퍼와 검사 지그로 치수 검사하는 모습](/images/3d프린팅-소량생산-단가/6.webp)

같은 크기인데 견적이 다른 이유는 [같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)에서 확인할 수 있습니다.

# 견적은 3개 수량으로 같이 받습니다

처음부터 10개·50개·100개 조건을 함께 요청하면 수량별 변화를 보기 쉽습니다. 이때 파일과 소재, 후처리, 검사 기준을 같게 맞춰야 합니다.

설계가 확정되지 않았다면 10개를 먼저 제작할 수 있습니다. 조립과 사용 시험을 끝낸 뒤 다음 수량으로 넘어가면 100개를 다시 만드는 위험을 줄일 수 있습니다.

![수량이 다른 동일 부품을 검사하고 포장하는 모습](/images/3d프린팅-소량생산-단가/3.webp)

Formlabs는 3D프린팅을 금형 없이 소량 최종 부품을 만들거나 양산 전 시장 검증에 쓰는 방법으로 안내합니다. 수량이 계속 늘면 사출이나 CNC도 함께 비교해야 합니다.

![같은 형상의 3D프린팅 부품과 CNC 가공 부품, 사출 부품을 비교하는 작업대](/images/3d프린팅-소량생산-단가/7.webp)

# 맞는 경우와 다시 검토할 경우

| 3D프린팅이 잘 맞는 경우 | 다른 방법도 비교할 경우 |
| --- | --- |
| 1개부터 100개 안팎이 필요한 경우 | 같은 부품을 계속 대량 생산하는 경우 |
| 설계 변경 가능성이 남은 경우 | 형상과 소재가 완전히 확정된 경우 |
| 모델별로 형상이 조금씩 다른 경우 | 단순 형상을 매우 짧은 주기로 반복 생산하는 경우 |
| 내부 유로와 복잡한 형상이 있는 경우 | 사출 금형비를 회수할 수 있는 수량인 경우 |

수량만으로 공정을 정하지는 않습니다. 금형 없이 만드는 3가지 방법은 [금형 없이 소량 생산하는 3가지 방법](/blog/금형-없이-소량-생산/)에서 비교할 수 있습니다.

# 담당자가 확인할 것

1. **총수량과 1회 주문 수량을 나눕니다.** 연간 100개와 한 번에 100개는 다릅니다.
2. **수량별 견적 조건을 통일합니다.** 소재와 후처리, 검사를 같게 맞춥니다.
3. **첫 제작 수량을 정합니다.** 1개나 10개로 기능을 확인할 수 있습니다.
4. **개별 작업을 표시합니다.** 도색, 조립, 전수 검사, 포장을 구분합니다.
5. **다음 공정 전환 기준을 정합니다.** 단가와 설계 변경 빈도를 함께 봅니다.

# 자주 묻는 질문

## 100개를 주문하면 개당 단가가 절반이 되나요

정해진 비율은 없습니다. 한 배치에 들어가는 수량과 소재 사용량, 후처리, 검사 범위를 파일로 계산해야 합니다.

## 10개를 먼저 만들고 같은 조건으로 추가할 수 있나요

가능합니다. 첫 주문의 방식, 소재, 방향, 후처리 조건을 기록해 두면 반복 제작 기준으로 쓸 수 있습니다.

## 수량이 많으면 사출이 항상 싼가요

금형비와 설계 변경 가능성을 함께 봐야 합니다. 형상이 확정되고 반복 수량이 충분하면 사출이 유리할 수 있습니다.

## 여러 형상을 섞어 주문해도 되나요

가능합니다. 방식과 소재가 같으면 한 배치에 넣을 수 있는지 검토합니다. 형상마다 파일 검토와 분류 작업은 필요합니다.

수량별 견적에서는 할인율보다 배치 구성을 먼저 봐야 합니다. 같은 조건으로 3개 수량을 비교하면 생산 방법을 정하기 쉬워집니다.
