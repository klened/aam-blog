*3D프린팅 소량 생산의 배치 구성을 설명하기 위한 이미지입니다.*

1개 견적에 100을 곱하면 100개 금액이 나올까요. 그렇게 계산하지 않습니다.

개당 단가를 정하는 것은 수량이 아닙니다. **한 배치에 몇 개가 들어가는가**입니다. 여기에 후처리와 검사 범위가 붙습니다.

# 수량이 늘어도 값이 사라지지 않습니다

3D프린팅은 금형비가 없습니다. 그래서 1개부터 시작하기 좋습니다.

다만 장비 시간과 소재비는 그대로 붙습니다. 사출과 다릅니다. 금형을 한 번 만들어 두고 찍어 내는 방식이 아닙니다. 100개를 만들면 100개만큼 장비가 돌아갑니다.

| 값을 만드는 것 | 100개로 늘리면 |
| --- | --- |
| 파일 검토·장비 준비 | 100개에 나눠 붙어 개당이 내려갑니다 |
| 출력 시간·소재 | 배치를 잘 채우면 조금 내려갑니다 |
| 후처리 | 손이 가는 만큼 100배 그대로 붙습니다 |
| 검사·포장 | 전수 검사와 개별 포장은 100배 그대로입니다 |

개당이 확실히 내려가는 것은 첫 줄뿐입니다. 아래 세 줄은 수량을 따라 올라갑니다.

![출력과 후처리, 검사, 포장 단계별로 동일 부품을 분류하는 소량 생산 작업대](/images/3d프린팅-소량생산-단가/4.webp)

# 한 배치에 몇 개가 들어가나

같은 100개라도 부품 크기에 따라 값이 달라집니다.

작은 SLS 부품은 분말층에 입체로 담습니다. 위아래로 겹치니 한 번에 많이 들어갑니다. FDM 은 다릅니다. 큰 부품이 바닥 면적을 차지해 같은 100개도 여러 번 나눠 뽑습니다.

![SLS 분말층에 같은 부품을 촘촘하게 배치해 한 개를 꺼내는 모습](/images/3d프린팅-소량생산-단가/5.webp)

| 수량 | 물어볼 것 | 왜 물어보나 |
| --- | --- | --- |
| 10개 | 한 배치에 다 들어갑니까 | 들어가면 개당이 가장 쌉니다 |
| 50개 | 배치를 몇 번 돌립니까 | 돌리는 횟수가 준비 시간을 정합니다 |
| 100개 | 배치마다 치수가 같습니까 | 여러 번 돌리면 편차가 생깁니다 |

정확한 단가는 파일을 장비에 배치해 봐야 나옵니다.

# 개당이 잘 안 내려가는 값

배치를 아무리 잘 채워도 줄지 않는 값이 있습니다. 사람 손이 들어가는 공정입니다.

도색과 연마가 그렇습니다. 부품마다 마스킹하고 색을 확인해야 하면 출력 효율과 무관하게 값이 붙습니다.

![한 배치에서 여러 SLS 부품을 꺼내 분말을 제거하는 모습](/images/3d프린팅-소량생산-단가/2.webp)

검사도 같습니다. 주요 치수 2곳을 표본으로 재는 주문과 모든 부품의 10개 치수를 기록하는 주문은 작업량이 다릅니다. 개별 포장과 라벨도 따로 계산합니다.

![동일한 3D프린팅 부품을 캘리퍼와 검사 지그로 치수 검사하는 모습](/images/3d프린팅-소량생산-단가/6.webp)

견적서에서 이 항목들이 따로 적혀 있는지 보시면 됩니다. 묶여 있으면 수량을 바꿀 때 무엇이 움직이는지 알 수 없습니다.

같은 크기인데 견적이 다른 이유는 [같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)에서 확인할 수 있습니다.

# 3개 수량을 한 번에 받습니다

처음부터 10개·50개·100개를 함께 요청하시면 수량별 변화가 보입니다.

이때 파일과 소재, 후처리, 검사 기준을 같게 맞춰야 합니다. 조건이 다르면 금액을 견줄 수 없습니다.

설계가 확정되지 않았으면 10개를 먼저 만드는 방법이 있습니다. 조립과 사용 시험을 끝낸 뒤 다음 수량으로 넘어가면 100개를 다시 만드는 일을 막습니다.

![수량이 다른 동일 부품을 검사하고 포장하는 모습](/images/3d프린팅-소량생산-단가/3.webp)

Formlabs는 3D프린팅을 금형 없이 소량 최종 부품을 만들거나 양산 전 시장 검증에 쓰는 방법으로 안내합니다. 수량이 계속 늘면 사출이나 CNC도 함께 비교해야 합니다.

![같은 형상의 3D프린팅 부품과 CNC 가공 부품, 사출 부품을 비교하는 작업대](/images/3d프린팅-소량생산-단가/7.webp)

# 맞는 경우와 다시 검토할 경우

| 3D프린팅으로 갑니다 | 사출·CNC 도 같이 봅니다 |
| --- | --- |
| 한 번에 100개 안팎을 만드는 건 | 같은 부품을 해마다 수천 개 쓰는 건 |
| 설계가 아직 바뀔 수 있는 건 | 형상과 소재를 확정한 건 |
| 모델마다 형상이 조금씩 다른 건 | 단순한 형상을 짧은 주기로 찍는 건 |
| 안에 유로가 있어 깎기 어려운 건 | 금형비를 뽑을 수 있는 수량인 건 |

수량만으로 공정을 정하지는 않습니다. 금형 없이 만드는 3가지 방법은 [금형 없이 소량 생산하는 3가지 방법](/blog/금형-없이-소량-생산/)에서 비교할 수 있습니다.

# 담당자가 확인할 것

1. **한 번에 몇 개인지 적습니다.** 해마다 100개와 한 번에 100개는 다릅니다.
2. **3개 수량의 조건을 맞춥니다.** 소재, 후처리, 검사를 같게 둡니다.
3. **먼저 만들 수량을 정합니다.** 1개나 10개로 기능을 봅니다.
4. **손이 가는 작업을 따로 적습니다.** 도색, 조립, 전수 검사, 포장입니다.
5. **갈아탈 시점을 정합니다.** 단가와 설계 변경 빈도를 함께 봅니다.

# 자주 묻는 질문

## 100개면 개당이 절반이 되나요

정해진 비율이 없습니다. 배치에 들어가는 수량과 소재량, 후처리, 검사 범위를 파일로 계산해야 나옵니다.

## 배치가 무엇인가요

장비를 한 번 돌릴 때 함께 들어가는 묶음입니다. 조형 공간을 채워 돌리면 준비 시간을 여러 부품이 나눠 씁니다.

## 10개를 먼저 만들고 나중에 채워도 되나요

됩니다. 첫 주문의 방식, 소재, 방향, 후처리를 기록해 두면 다음 주문의 기준이 됩니다.

## 수량이 많으면 사출이 싼가요

금형비와 설계 변경 가능성을 함께 봐야 합니다. 형상을 확정했고 반복 수량이 충분하면 사출이 유리합니다.

## 형상이 다른 부품을 섞어도 되나요

됩니다. 방식과 소재가 같으면 한 배치에 넣을 수 있는지 봅니다. 형상마다 파일 검토와 분류는 따로 붙습니다.

견적을 받으실 때는 할인율보다 배치 구성을 먼저 보시면 됩니다. 같은 조건으로 3개 수량을 견주면 생산 방법이 정해집니다.
