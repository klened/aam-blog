수술 훈련용 모델은 장기 모양만 닮아서는 부족합니다. 드릴이 뼈를 통과할 때의 저항과 단단한 조직에서 무른 조직으로 바뀌는 지점도 느낄 수 있어야 합니다.

COSA는 PolyJet 멀티소재로 측두골 훈련 모델을 만들었습니다. 이 글은 [Stratasys가 공개한 COSA 사례](https://www.stratasys.com/en/resources/case-studies/cosa-surgical-training-anatomical-models/)를 바탕으로 정리했습니다.

# 실제 검체는 같은 조건을 만들기 어렵습니다

카데바는 해부 구조와 촉감을 확인할 수 있지만 검체마다 구조가 다릅니다. 특정 병변을 원하는 위치와 크기로 반복 준비하기도 어렵습니다.

여러 의료진의 훈련 결과를 비교하려면 출발 조건이 같아야 합니다. 한 사람은 얇은 뼈를, 다른 사람은 두꺼운 뼈를 다룬다면 수행 결과를 같은 기준으로 보기 어렵습니다.

# 형상과 재질을 함께 배치했습니다

COSA는 Stratasys Digital Anatomy와 PolyJet 멀티소재 출력을 사용했습니다. 측두골의 해부 구조뿐 아니라 조직이 바뀌는 경계와 시각적 표지도 표현했습니다.

| 확인 항목 | 모델에서 구현한 것 |
| --- | --- |
| 경질 구조 | 측두골 형상과 드릴 저항 |
| 연질 구조 | 주변 조직의 눌림과 경계 |
| 시각 정보 | 해부학적 위치를 찾는 표지 |
| 반복 조건 | 같은 해부 구조와 병변 재현 |

재료 이름 하나로 촉감을 정하지는 않습니다. 같은 재료도 두께와 내부 구조가 달라지면 드릴 저항과 눌리는 정도가 달라집니다.

# 같은 모델로 반복 훈련할 수 있습니다

디지털 파일을 기준으로 만들면 여러 의료진에게 같은 해부 구조를 제공할 수 있습니다. 병변의 위치와 크기도 훈련 목적에 맞게 바꿀 수 있습니다.

공식 사례는 수술 훈련뿐 아니라 의료기기 사전 검증, 사용성 평가와 제품 개발에도 활용할 수 있다고 설명합니다. 시제품 단계별 확인 항목은 [의료기기 시제품, 개발 단계별로 무엇을 만드나](/blog/의료기기-시제품-제작/)에서 볼 수 있습니다.

# 실제 환자에게 쓰는 제품은 아닙니다

훈련 모델이 실제 조직과 비슷하게 느껴져도 인체 삽입물이나 치료용 의료기기가 되는 것은 아닙니다. 멸균, 생체적합성, 장기 내구성과 임상 성능을 대신 증명하지 않습니다.

목적을 먼저 나눠야 합니다. 해부 위치를 보는 모델인지, 절삭과 봉합을 연습하는 모델인지, 의료기기 조작성을 시험하는 모델인지에 따라 필요한 재질과 검증 방법이 달라집니다.

경질·연질 재료를 한 출력에 넣는 방법은 [PolyJet 마스크 시제품 사례](/blog/polyjet-마스크-밀착-시제품-사례/)에서 확인할 수 있습니다. 색과 작동을 함께 보는 사례는 [PolyJet 컬러 시제품 사례](/blog/polyjet-컬러-작동-시제품-사례/)에 정리했습니다.

# 맡기기 전에 확인할 것

1. CT·MRI 데이터와 필요한 해부 영역을 정합니다.
2. 정상 구조인지 특정 병변을 넣을지 표시합니다.
3. 단단해야 하는 조직과 눌려야 하는 조직을 구분합니다.
4. 절삭·봉합·삽입 가운데 실제로 연습할 동작을 적습니다.
5. 교육 평가와 의료기기 시험의 합격 기준을 나눕니다.

# 자주 묻는 질문

## CT 데이터만 보내면 바로 출력할 수 있나요

영상에서 필요한 조직을 분리하고 출력 가능한 3D 데이터로 만들어야 합니다. 경계가 흐린 조직은 의료진과 제작 담당자가 함께 범위를 확인해야 합니다.

## 실제 뼈와 촉감이 완전히 같은가요

완전히 같다고 단정할 수 없습니다. 드릴 저항과 조직 경계를 훈련 목적에 맞게 조정할 수 있지만 실제 검체와 비교 평가가 필요합니다.

## 같은 환자 모델을 여러 개 만들 수 있나요

가능합니다. 같은 파일과 출력 조건을 사용하면 동일한 해부 구조를 반복 제작할 수 있습니다. 후처리와 보관 조건도 함께 관리해야 합니다.

## 출력 모델로 의료기기 인증 시험을 끝낼 수 있나요

그렇지 않습니다. 형상과 조작성 검토에는 쓸 수 있지만 법정 시험과 임상 검증은 해당 규정과 최종 제품 조건에 맞춰 별도로 진행해야 합니다.

수술 훈련 모델은 색보다 **어떤 조직에서 어떤 동작을 연습할지**를 먼저 정해야 합니다. 영상 데이터와 훈련 목적을 보내주시면 나눠 표현할 조직과 재질 범위를 정리해 드립니다.
