금속 부품이 필요한데 수량이 적습니다. 금형을 여는 것이 맞지 않습니다.

**SLA 레진으로 원형을 뽑고 그것으로 주조하면 금형 없이 금속 부품을 만들 수 있습니다.**

# 원형을 만드는 기존 방법이 맞지 않는 이유

| 방법 | 막히는 것 |
| --- | --- |
| CNC로 원형 절삭 | 곡면이 복잡하면 가공비가 높고 2~3주 걸립니다 |
| 수작업 왁스 원형 | 숙련공이 필요하고 복제할 때 형상이 달라집니다 |
| 금형 | 금형비가 수백만 원입니다. 5개 이하면 개당 금형비가 부품값을 넘습니다 |

소량이면 원형부터 만드는 방법이 달라야 합니다.

SLA는 표면이 매끄럽고 치수 정확도가 **±0.15%**입니다. 원형의 표면 거칠기가 그대로 주조품에 옮겨지므로 표면이 중요합니다.

| 쓰임 | 방법 |
| --- | --- |
| 실리콘 몰드 원형 | 레진 원형을 만들고 실리콘을 부어 몰드를 뜹니다. 몰드에서 우레탄이나 왁스를 뽑습니다 |
| 로스트 왁스 원형 | 캐스터블 레진으로 뽑으면 소성 시 잔재 없이 타서 빠집니다. 석고 몰드에 금속을 부을 수 있습니다 |
| 형상 검증 | 금속 주조 전에 레진 원형으로 형상과 조립을 먼저 확인합니다 |

**레진을 잘못 고르면 주조가 안 됩니다.** 실리콘 몰드용 원형은 표준 레진으로 됩니다. 로스트 왁스는 반드시 캐스터블 레진을 써야 합니다. 일반 레진은 소성 시 탄화물이 남아 주조 불량이 됩니다. 용도를 말씀해 주시면 맞는 레진을 골라 드립니다.

비슷한 공정은 [3D프린팅 몰드, 7만 원과 80만 원](/blog/3d프린팅-몰드-사례-2건/)에 정리했습니다. SLA 몰드 시제품 사례가 **7만 원**이었습니다. 절삭 원형 대비 자릿수가 다릅니다.

# 수정이 빠릅니다

원형에 문제가 있으면 파일만 고쳐 당일 다시 출력합니다. 절삭 원형은 다시 2~3주를 기다려야 합니다.

도면이 없어도 됩니다. 기존 부품이나 스케치를 주시면 원형을 설계해 드립니다. **1개만 필요해도 만듭니다.** 절삭은 셋업비가 붙어 1개와 10개 값이 비슷하지만 SLA는 1개 값이 1개 값입니다.

# 맞는 경우와 다시 봐야 할 경우

| 구분 | 내용 |
| --- | --- |
| 잘 맞는 경우 | 수량 50개 이하 / 형상이 복잡한 소형 부품 / 설계가 확정되지 않은 시제품 단계 / 납기가 급한 소량 주조 |
| 다시 봐야 할 경우 | **원형 크기가 300mm를 넘는 경우** — SLA 빌드 크기를 확인해야 합니다. 나눠 뽑거나 다른 방식을 봐야 합니다 / **수량이 100개를 넘는 경우** — 금형을 여는 편이 개당 단가가 낮아집니다 / **표면 거칠기 Ra 1μm 이하가 필요한 경우** — 원형 후처리가 추가로 붙습니다 |

**표면을 짚겠습니다.** SLA는 적층 결이 남습니다. 외관이 중요한 부품은 원형 단계에서 연마 후처리를 붙입니다. 후처리 종류는 [3D프린팅 후처리, 어디까지 해야 하나](/blog/3d프린팅-후처리-종류/)에 정리했습니다.

# 담당자가 확인할 것

1. **최종 제품의 소재**를 알려주십시오. 알루미늄인지 청동인지에 따라 주조 방식이 달라지고 원형 레진도 달라집니다.
2. **수량**을 정합니다. 5개 이하면 원형을 직접 쓰고, 20개 이상이면 실리콘 몰드를 만드는 편이 빠릅니다.
3. **표면 기준**을 확인합니다. 주조 후 어디까지 후가공할 것인지에 따라 원형의 후처리 수준이 달라집니다.
4. **도면 유무**를 알려주십시오. 없으면 실물이나 스케치로 시작합니다.

# 자주 묻는 질문

## 레진 원형 하나로 몇 개까지 뽑을 수 있나요

실리콘 몰드 하나로 보통 10~20개를 뽑습니다. 원형이 아니라 몰드의 수명이 한계입니다. 몰드가 닳으면 같은 원형으로 다시 부으면 됩니다.

## 캐스터블 레진이 보통 레진과 뭐가 다른가요

캐스터블 레진은 소성하면 잔재 없이 탑니다. 보통 레진은 탄화물이 남아 주조품에 기포나 불순물이 생깁니다. 로스트 왁스 공정에는 반드시 캐스터블을 써야 합니다.

## 투명 원형도 되나요

됩니다. SLA 투명 레진으로 원형을 만들면 안쪽 유로나 구조를 눈으로 확인한 뒤 주조로 넘길 수 있습니다. [투명 부품, 소재는 어떻게 다른가](/blog/투명-3d프린팅-부품-소재-비교/)를 보십시오.

## 금속 3D프린팅과 뭐가 다른가요

금속 3D프린팅은 금속 분말을 직접 녹여 쌓습니다. 소재 선택지가 다릅니다. 주조는 전통 금속 공정이므로 알루미늄·청동·스테인리스 등 소재 범위가 넓고 후가공 체계가 갖춰져 있습니다. [금속 3D프린팅, 깎을 수 없는 형상](/blog/금속-3d프린팅-사례-3건/)에 정리했습니다.

원형의 형상이 아니라 **최종 제품의 소재와 수량**이 먼저입니다. 그것이 정해져 있으면 원형은 거기에 맞춰 설계하면 됩니다.

용도를 알려주시면 원형 소재와 주조 방식을 잡아 드립니다.
