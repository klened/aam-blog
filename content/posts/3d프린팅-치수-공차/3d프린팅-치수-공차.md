*3D프린팅 부품의 치수 확인을 설명하기 위한 이미지입니다.*

CAD에서 50mm로 그린 부품이 항상 50mm로 나오지는 않습니다. 출력물은 열을 받고 식으며, 적층 방향에 따라 표면 모양도 달라집니다.

그래서 공차는 장비 정밀도 한 줄로 정할 수 없습니다. 어떤 치수를 어디서 어떻게 잴지부터 정해야 합니다.

# 치수 차이를 만드는 4가지

| 조건 | 출력물에서 생기는 변화 |
| --- | --- |
| 부품 크기 | 길이가 길수록 수축과 휨이 누적될 수 있습니다 |
| 출력 방향 | 같은 구멍도 놓인 방향에 따라 원형도와 표면이 달라집니다 |
| 형상 | 얇은 벽, 긴 평면, 깊은 구멍은 변형에 민감합니다 |
| 소재와 공정 | 열가소성 수지, 레진, 금속은 수축과 후처리 방식이 다릅니다 |

장비 사양은 출발점입니다. 실제 부품의 위치와 배치도 치수에 영향을 줍니다. Formlabs도 SLS 설계 지침에서 같은 조건을 설명합니다. 출력 배치에 따라 치수 정확도가 달라질 수 있습니다.

# 모든 치수를 같은 수준으로 맞추지 않습니다

도면 전체에 빠듯한 공차를 요구하면 측정과 후가공 범위가 커집니다. 먼저 기능을 결정하는 치수를 고릅니다.

| 먼저 표시할 곳 | 이유 |
| --- | --- |
| 상대 부품과 닿는 면 | 조립 위치를 결정합니다 |
| 나사·핀·베어링 구멍 | 기성품 규격과 맞아야 합니다 |
| 개스킷·오링 홈 | 눌리는 양이 밀폐에 영향을 줍니다 |
| 센서와 광학 부품 장착부 | 중심과 높이가 기능을 결정합니다 |
| 기준면에서 떨어진 거리 | 다른 치수를 측정하는 출발점입니다 |

외관 곡면과 장식 무늬까지 같은 기준으로 재면 비용만 늘 수 있습니다. 기능 치수와 참고 치수를 도면에서 구분하십시오.

# 치수는 측정 방법까지 정해야 합니다

캘리퍼스로 잰 값과 3D 스캐너로 비교한 값은 같은 뜻이 아닙니다. 측정 도구마다 확인할 수 있는 형상이 다릅니다.

| 측정 방법 | 잘 맞는 항목 |
| --- | --- |
| 캘리퍼스·마이크로미터 | 폭, 두께, 바깥지름처럼 접근하기 쉬운 치수 |
| 핀 게이지 | 구멍의 통과 여부와 실제 끼움 |
| 높이 게이지 | 기준면에서 높이와 단차 |
| 3D 스캔 | 자유곡면과 전체 형상 비교 |
| 조립 시험 | 실제 상대 부품과의 간섭·흔들림 |

표면이 거칠면 측정 위치에 따라 값이 달라집니다. 측정 전에 분말과 서포트를 제거하고, 기준면을 정해야 합니다.

# 한 번에 맞추기 어려운 경우

공차가 빠듯하면 1개를 먼저 출력합니다. 결과를 측정한 뒤 파일이나 공정 조건을 보정합니다.

구멍은 후가공 여유를 두는 방법도 있습니다. 리밍이나 절삭으로 마무리할 면을 미리 정하면 출력만으로 모든 치수를 맞추려는 부담이 줄어듭니다.

끼움은 기준이 다릅니다. 넣고 뺄 것인지, 눌러 고정할 것인지에 따라 간격이 달라집니다. 자세한 내용은 [끼워 맞추는 부품, 공차는 어떻게 잡나](/blog/3d프린팅-조립-공차/)에서 확인할 수 있습니다.

# 맞는 경우와 다시 검토할 경우

| 3D프린팅으로 확인하기 좋은 경우 | 다시 검토할 경우 |
| --- | --- |
| 조립 가능 여부를 보는 시제품 | 정밀 회전축과 베어링 끼움 |
| 기준 치수가 몇 곳인 지그 | 모든 면에 가공급 공차가 필요한 부품 |
| 시험 출력 후 보정할 수 있는 부품 | 온도와 하중에 따른 변형 허용치가 매우 작은 부품 |
| 후가공할 구멍과 기준면이 정해진 부품 | 규격 성적서가 반드시 필요한 납품 부품 |

3D프린팅이 가능한 형상과 요구 공차를 만족하는 형상은 다를 수 있습니다. 공차가 기능을 결정한다면 방식 선택 전에 시험 제작 범위를 정하십시오.

# 담당자가 확인할 것

1. **기준면을 지정합니다.** 치수 측정의 출발점을 하나로 맞춥니다.
2. **필수 치수를 표시합니다.** 모든 치수를 같은 수준으로 요구하지 않습니다.
3. **측정 방법을 정합니다.** 도구와 위치가 달라지면 값도 달라집니다.
4. **후가공 가능 여부를 확인합니다.** 구멍과 평면을 나중에 맞출 수 있습니다.
5. **시험 출력 수량을 정합니다.** 1개를 재고 보정한 뒤 나머지를 제작할 수 있습니다.

# 자주 묻는 질문

## 장비 사양의 정확도를 그대로 적용하면 되나요

장비 사양만으로 납품 공차를 확정하기는 어렵습니다. 부품 크기와 방향, 소재, 후처리, 측정 방법을 함께 봐야 합니다.

## STL보다 STEP 파일이 더 정확한가요

STEP은 치수 수정과 형상 검토에 유리합니다. STL도 충분히 촘촘하게 변환하면 출력할 수 있지만, 수정 가능성이 있으면 STEP을 함께 보내는 편이 좋습니다.

## 구멍이 도면보다 작게 나오면 어떻게 하나요

리밍이나 드릴 가공이 가능한지 먼저 확인합니다. 반복 제작이라면 측정값을 바탕으로 파일의 구멍 치수를 보정합니다.

## 한 부품만 측정해도 되나요

시제품은 1개로 시작할 수 있습니다. 양산 검수라면 첫 부품, 배치별 표본, 전수 검사 중 어느 범위가 필요한지 따로 정해야 합니다.

공차 협의는 숫자를 받는 일이 아닙니다. 기능을 결정하는 치수와 측정 방법을 합의하는 일입니다.
