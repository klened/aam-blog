![개발자가 같은 형상의 회색 3D프린팅 시제품과 검은색 사출 하우징을 작업대에서 비교하는 모습](/images/사출-전-시제품-양산-소재/1.webp)

사출 전 시제품을 반드시 양산 소재와 같게 만들 필요는 없습니다. 형상과 조립을 확인한다면 치수와 표면이 알맞은 대체 소재로도 충분합니다. 먼저 이번 시제품에서 확인할 시험 항목을 적으세요.

문제는 시제품에 양산품과 같은 성능까지 기대할 때 생깁니다. `ABS-Like` 레진으로 만든 부품을 사출 ABS와 같다고 보고 낙하 시험을 통과시켜서는 안 됩니다.

# 소재 이름보다 시험 목적을 먼저 봅니다

시제품은 한 번에 모든 것을 증명하는 완성품이 아닙니다. 확인할 항목에 맞춰 소재와 공정을 정하는 도구입니다.

| 확인할 항목 | 양산 소재와 같아야 하나 | 먼저 맞출 것 |
| --- | --- | --- |
| 크기·간섭·조립 순서 | 대체 소재로 가능 | 치수, 공차, 표면 상태 |
| 색·투명도·외관 | 대체 소재로 가능 | 색상, 광택, 질감, 후처리 |
| 스냅핏·힌지·낙하 | 물성 비교가 필요 | 연신율, 충격강도, 피로 특성 |
| 열과 장시간 하중 | 물성 비교가 필요 | 열변형온도, 사용 온도, 크리프 |
| 기름·약품·실외 노출 | 실제 조건 시험이 필요 | 내약품성, 흡수율, 자외선 조건 |
| 인증·고객 최종 승인 | 양산 조건이 필요할 수 있음 | 실제 등급, 성형 조건, 시험 규격 |

Formlabs도 시제품 소재를 고를 때 강도 하나만 보지 않고 충격강도, 인장강도, 열변형온도, 크리프처럼 용도에 필요한 물성을 함께 비교하도록 안내합니다.

# 같은 ABS라는 이름만으로는 같지 않습니다

같은 계열의 플라스틱이라도 결과는 달라집니다.

- 사출용 ABS와 FDM용 ABS는 등급과 첨가제가 다를 수 있습니다.
- 사출품은 수지 흐름, 금형 온도, 보압과 냉각 조건의 영향을 받습니다.
- FDM 부품은 적층 방향에 따라 강도가 달라집니다.
- SLA의 `ABS-Like`, `PP-Like`는 해당 플라스틱의 일부 거동을 모사한 레진입니다.
- 후경화와 수분 상태가 달라지면 같은 출력 소재도 측정값이 달라질 수 있습니다.

재료 데이터시트를 비교할 때는 숫자만 옮기지 마세요. 시험 규격, 시편 방향, 후처리 상태와 온도가 같은지도 확인해야 합니다.

# 스냅핏을 시험한다면 여기를 맞춥니다

![작업자가 3D프린팅 하우징의 스냅핏 걸쇠를 반복해서 눌러 변형과 복원 상태를 확인하는 모습](/images/사출-전-시제품-양산-소재/2.webp)

스냅핏 하우징을 예로 들겠습니다. 뚜껑이 닫히는지만 볼 때는 정밀한 SLA 시제품으로 충분합니다. 걸쇠가 100번 열고 닫혀도 버티는지를 보려면 이야기가 달라집니다.

이때는 경도보다 연신율과 반복 굽힘, 걸쇠 뿌리의 응력 집중을 봐야 합니다. 양산품이 PP라면 유연성과 복원 거동이 비슷한 출력 소재를 먼저 찾습니다. 양산품이 유리섬유 강화 나일론이라면 단단함뿐 아니라 섬유 방향과 파손 형태도 확인해야 합니다.

출력 시제품은 설계 후보를 줄이는 시험에 씁니다. 최종 반복 수명은 양산 공정으로 만든 부품에서 다시 확인하는 편이 안전합니다.

# 양산 소재가 꼭 필요한 시점

다음 단계에서는 유사 소재보다 실제 양산 소재가 필요합니다.

1. 시험 성적서에 소재 등급이 지정된 경우
2. 낙하·충격·피로 수치로 합격 여부를 정하는 경우
3. 고온에서 오랫동안 하중을 받는 경우
4. 세정제·연료·오일·소독제에 반복 노출되는 경우
5. 식품·의료 접촉이나 난연 등급을 확인하는 경우
6. 고객이 양산 공정의 시사출품을 승인 시료로 요구하는 경우

이때는 양산 수지로 시사출하거나 양산 금형의 초도품을 시험해야 합니다. 수량이 적고 부품 조건이 맞으면 [3D프린팅 사출 금형](/blog/3d프린팅-사출-금형/)으로 실제 수지를 사출하는 방법도 검토할 수 있습니다.

# 시제품을 2번으로 나누면 낭비가 줄어듭니다

처음부터 비싼 소재로 여러 개 만들 필요는 없습니다.

**1차 시제품**은 형상과 조립을 확인합니다. 값과 납기를 우선해 FDM이나 SLA를 선택할 수 있습니다.

**2차 시제품**은 기능을 확인합니다. 실제 사용 조건에 필요한 충격, 열, 유연성, 약품 저항을 기준으로 SLS 나일론이나 엔지니어링 레진, 산업용 FDM 소재를 선택합니다.

2차 시험을 통과한 뒤에도 인증과 양산 승인 항목은 시사출품으로 확인합니다. 금형 제작 전 전체 검증 순서는 [사출 금형 만들기 전에 3D프린팅으로 검증하는 방법](/blog/사출-전-3d프린팅-검증/)에서 확인할 수 있습니다.

# 의뢰 전에 적을 것

소재 이름을 먼저 정하는 대신 아래 조건을 전달해 주세요.

- 양산 소재의 정확한 등급과 제조사
- 이번 시제품에서 확인할 항목
- 사용 온도와 하중이 유지되는 시간
- 닿는 물·오일·약품의 이름
- 반복 횟수와 허용할 변형
- 적용할 시험 규격이나 고객 승인 기준

양산 소재가 아직 정해지지 않았다면 [3D프린팅 소재 종류, 용도로 고르는 지도](/blog/3d프린팅-소재-종류/)에서 요구 조건부터 정리할 수 있습니다.

# 자주 묻는 질문

:::faq
ABS-Like 레진이면 사출 ABS와 같은가요
아닙니다. ABS-Like는 ABS의 강성이나 충격 거동 일부를 모사한 광경화성 레진입니다. 제품명만 보고 같다고 판단하지 말고 필요한 물성값과 시험 조건을 비교해야 합니다.
:::

:::faq
형상 확인용 시제품도 양산 소재로 만들어야 하나요
대부분은 필요하지 않습니다. 크기, 간섭, 버튼 위치와 조립 순서를 확인한다면 치수와 표면 품질이 알맞은 대체 소재가 더 빠르고 경제적입니다.
:::

:::faq
양산품의 강도를 3D프린팅 시제품으로 예측할 수 있나요
설계 후보를 비교하는 데에는 쓸 수 있습니다. 다만 적층 방향과 후처리, 사출 성형 조건이 달라 결과를 그대로 양산품 수명으로 옮길 수는 없습니다. 최종 합격 시험은 승인된 소재와 공정으로 만든 부품에서 진행해야 합니다.
:::

:::faq
양산 소재 데이터시트에서 무엇을 보내야 하나요
제조사와 정확한 등급명이 먼저 필요합니다. 시험 목적에 따라 인장·굴곡·충격·열변형·내약품 자료와 시험 규격도 함께 확인합니다.
:::

3D프린팅 출력이 필요하시면 문의를 남겨주세요. 담당 엔지니어가 시험 항목과 양산 소재를 확인한 뒤 적합한 공정과 소재를 안내드립니다.
