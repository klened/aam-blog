*3D프린팅 부품의 품질 검사를 설명하기 위한 이미지입니다.*

“성적서도 같이 주세요”라고 요청하면 필요한 문서가 바로 정해질 것 같지만 그렇지 않습니다. 치수 측정표와 소재 자료, 시험 결과는 서로 다른 문서입니다.

검수 범위를 먼저 나눠야 합니다. 그래야 측정 장비와 수량, 납기를 정할 수 있습니다.

# 검수는 4가지로 나눕니다

![3D프린팅 브래킷 여러 개를 캘리퍼와 높이 게이지로 검사하는 모습](/images/3d프린팅-부품-검수/2.webp)

| 구분 | 확인하는 항목 | 결과물 예시 |
| --- | --- | --- |
| 외관 검사 | 균열, 휨, 미세 구멍, 후처리 상태 | 외관 확인 기록과 사진 |
| 치수 검사 | 길이, 구멍, 두께, 기준면 거리 | 치수 측정표 |
| 기능 검사 | 끼움, 나사 체결, 누설, 작동 | 조립 확인 또는 별도 시험 결과 |
| 문서 확인 | 소재명, 공정, 배치, 장비 상태 | 소재 자료와 공정 기록 |

검수 범위는 주문마다 다릅니다. 형상 확인용 시제품이면 외관과 주요 치수 몇 곳으로 충분할 수 있습니다. 고객사 납품 부품은 문서 범위가 더 넓어집니다.

# 치수 성적서에 들어갈 것

치수 성적서는 도면의 숫자를 옮겨 적는 문서가 아닙니다. 실제 측정값과 허용 범위를 비교할 수 있어야 합니다.

| 항목 | 제작 전에 정할 내용 |
| --- | --- |
| 측정 위치 | 도면 번호와 기준면 |
| 목표 치수 | 도면의 기준값 |
| 허용 범위 | 상한과 하한 또는 공차 |
| 측정 도구 | 캘리퍼스, 핀 게이지, 3D 스캔 등 |
| 검사 수량 | 첫 부품, 표본, 전수 검사 |

측정 위치를 그림으로 표시하면 해석 차이가 줄어듭니다. 거친 표면이나 자유곡면은 접촉식 측정만으로 판단하기 어려울 수 있습니다.

단품 치수 기준은 [3D프린팅 공차, 도면 치수대로 어디까지 나오나](/blog/3d프린팅-치수-공차/)에서 자세히 확인할 수 있습니다.

# 소재 자료와 시험 성적서는 다릅니다

소재 제조사가 공개한 데이터시트는 재료의 대표 물성을 설명합니다. 납품한 부품을 직접 시험했다는 뜻은 아닙니다.

| 요청 문서 | 무엇을 확인하나 |
| --- | --- |
| 소재 데이터시트 | 제조사가 공개한 대표 물성 |
| 소재 로트 자료 | 사용한 재료의 배치 정보 |
| 치수 측정표 | 납품 부품의 실제 측정값 |
| 시험 성적서 | 지정 조건에서 수행한 시험 결과 |
| 장비 교정 자료 | 측정 장비의 교정 상태 |

수압, 기밀, 인장, 난연처럼 시험 조건이 필요한 항목은 별도 협의가 필요합니다. 시험 규격과 시편 수, 합격 기준을 먼저 정해야 합니다.

# 몇 개를 검사해야 하나

![하우징의 평탄도와 표면 상태를 틈새 게이지와 조명으로 확인하는 모습](/images/3d프린팅-부품-검수/3.webp)

시제품 1개는 전수로 확인할 수 있습니다. 100개를 모두 측정하면 검사 시간이 크게 늘어납니다.

첫 부품부터 확인합니다. 반복 생산에서는 배치별 표본을 정하는 방법이 있습니다. 안전이나 규격이 걸린 치수는 전수 검사가 필요할 수 있습니다.

Stratasys Direct는 새 제조 공정의 첫 부품이 지정 요구사항에 맞는지 확인하는 첫 부품 검사를 품질 관리 항목으로 설명합니다. 검사 범위는 주문마다 달라야 합니다.

# 맞는 경우와 다시 검토할 경우

| 일반 검수로 진행하기 좋은 경우 | 별도 시험을 검토할 경우 |
| --- | --- |
| 외관과 주요 치수만 확인하는 시제품 | 규격 인증이 납품 조건인 부품 |
| 상대 부품과 조립해 보는 지그 | 수압·기밀·내구 수치가 필요한 부품 |
| 첫 부품을 확인한 뒤 반복 제작하는 경우 | 모든 치수의 추적성이 필요한 부품 |
| 소재 데이터시트로 충분한 내부 부품 | 의료·식품·항공처럼 문서 요구가 정해진 부품 |

출력업체의 일반 검수와 공인 시험기관의 시험은 같지 않습니다. 필요한 문서의 발행 주체까지 확인하십시오.

# 담당자가 확인할 것

1. **부품 용도와 납품처 요구를 확인합니다.** 사내 확인용인지 고객사 제출용인지 구분합니다.
2. **도면에 검사 치수를 표시합니다.** 기준면과 번호를 함께 적습니다.
3. **검사 수량을 정합니다.** 첫 부품, 표본, 전수 중에서 고릅니다.
4. **문서 이름과 발행 주체를 확인합니다.** 데이터시트와 시험 성적서를 구분합니다.
5. **합격 기준을 제작 전에 전달합니다.** 출력이 끝난 뒤 기준을 추가하면 재작업이 생길 수 있습니다.

# 자주 묻는 질문

## 기본 견적에 치수 성적서가 포함되나요

주문 조건에 따라 다릅니다. 측정 항목과 수량이 정해져야 작업 범위와 비용을 계산할 수 있습니다.

## 3D 스캔으로 전체 형상을 비교할 수 있나요

가능합니다. 자유곡면과 전체 편차를 확인할 때 유용합니다. 다만 사용할 장비와 비교 기준, 결과물 형식을 먼저 정해야 합니다.

## 소재 데이터시트만으로 납품할 수 있나요

납품처 요구에 따라 다릅니다. 데이터시트는 재료의 대표 물성이고, 납품 부품의 시험 결과는 아닙니다.

## 물이 새지 않는다는 성적서도 받을 수 있나요

시험 조건을 정해야 합니다. 압력, 시간, 온도, 합격 기준과 시험기관 요구를 확인한 뒤 가능 여부를 협의합니다.

검수에서 먼저 정할 것은 문서 이름이 아닙니다. 어떤 부품을 몇 개 측정하고, 어떤 기준으로 합격시킬지입니다.
