장비 안에 케이블이 흩어져 있습니다. 정리할 가이드가 필요합니다.

**기성품은 케이블 지름이나 경로가 안 맞습니다.** 장비마다 다르기 때문입니다.

# 기성품이 안 맞는 이유

| 방법 | 막히는 것 |
| --- | --- |
| 기성 클립 | 케이블 지름이 안 맞습니다. 너무 헐겁거나 조입니다 |
| 케이블 타이 | 묶을 수는 있지만 경로를 잡아 주지 못합니다 |
| 판금 브래킷 | 곡선 경로를 따라가기 어렵습니다. 날카로운 모서리가 케이블을 긁습니다 |

케이블이 움직이면 커넥터가 빠지거나 피복이 벗겨집니다. 경로를 잡아 주는 가이드가 있어야 합니다.

케이블 지름에 맞는 홈을 넣으면 됩니다. 도면이 없어도 케이블 지름과 장착 위치를 알려주시면 설계해 드립니다.

| 형태 | 쓰는 곳 |
| --- | --- |
| 스냅 클립 | 케이블 1~2가닥을 패널에 고정합니다. 탈착이 됩니다 |
| 벽면 가이드 | 장비 벽면을 따라 케이블 경로를 잡습니다 |
| 묶음 클램프 | 여러 가닥을 한 묶음으로 잡습니다 |
| 코너 가이드 | 꺾이는 곳에서 케이블 꺾임 반경을 지켜 줍니다 |

**1개만 필요해도 됩니다.** 장비마다 경로가 다르면 각각 다르게 뽑습니다.

# 소재

| 조건 | 소재 | 이유 |
| --- | --- | --- |
| 일반 실내 장비 | FDM ABS | 비용이 낮습니다. 가장 흔한 선택입니다 |
| 탈착이 잦은 곳 | SLS 나일론(PA12) | 스냅이 반복 사용에 버팁니다 |
| 고온 위치 | ABS-ESD7, ULTEM | 60°C 이상이면 PLA는 변형됩니다 |
| 진동이 있는 곳 | SLS 나일론(PA12) | 진동에도 잘 깨지지 않습니다 |

**FDM이 가장 많이 쓰입니다.** 가이드는 하중이 적고 형상이 단순해 FDM으로 충분한 경우가 많습니다. 비용도 가장 낮습니다. 비용이 어떻게 나뉘는지는 [같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)에 정리했습니다.

수정이 나오면 모델만 고쳐 당일 다시 뽑습니다.

# 맞는 경우와 다시 봐야 할 경우

| 구분 | 내용 |
| --- | --- |
| 잘 맞는 경우 | 기성 클립이 안 맞는 장비 / 케이블 경로가 곡선인 곳 / 소량 장비 제작 / 시제품 단계 배선 정리 |
| 다시 봐야 할 경우 | **고온 위치** — 모터나 히터 옆은 온도가 높습니다. 소재를 확인해야 합니다 / **수량이 1,000개를 넘는 경우** — 사출이 개당 단가에서 이깁니다 / **케이블이 수십 kg 하중을 받는 경우** — 금속 브래킷이 맞습니다 |

비슷한 형태의 부품인 [현장 지그](/blog/3d프린팅-지그-고정구-사례-4건/)도 같은 방식으로 만듭니다. 클립의 스냅 구조가 걱정되면 [조립 공차](/blog/3d프린팅-조립-공차/)를 먼저 보십시오.

# 담당자가 확인할 것

1. **케이블 지름과 가닥 수**를 알려주십시오. 홈 크기가 정해집니다.
2. **장착 방법**을 정합니다. 나사인지, 양면테이프인지, 스냅인지에 따라 구조가 달라집니다.
3. **주변 온도**를 확인합니다. 고온이면 소재가 달라집니다.
4. **수량**을 알려주십시오. 10개 이하면 FDM, 그 이상이면 SLS가 나을 수 있습니다.

# 자주 묻는 질문

## 스냅 클립이 부러지지 않나요

FDM ABS는 반복 탈착에 약합니다. 자주 열고 닫을 곳이면 SLS 나일론이 낫습니다. 나일론은 탄성이 있어 스냅이 수백 회 버팁니다.

## 케이블이 긁히지 않나요

FDM은 표면이 거칠어 피복이 약한 케이블에 자국이 날 수 있습니다. 홈 안쪽을 라운드로 만들거나 SLS로 뽑으면 표면이 고릅니다.

## 방수가 필요한 곳에도 되나요

야외 장비라면 자외선과 수분을 확인해야 합니다. ASA 소재가 내후성이 있습니다. 완전 방수가 필요하면 후처리를 붙여야 합니다.

먼저 정할 것은 클립 크기가 아닙니다. **케이블이 몇 가닥이고 어디를 지나는가**입니다. 경로가 정해지면 가이드는 거기에 맞춰 설계하면 됩니다.

케이블 사양과 장착 위치를 알려주시면 형태를 잡아 드립니다.
