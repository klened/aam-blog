환자마다 체형이 다릅니다. 기성품 보조기구는 사이즈가 안 맞습니다.

**석고로 본을 뜨고 수작업으로 깎으면 시간이 오래 걸립니다.** 3D 스캔으로 뽑으면 빠르고 정확합니다.

# 수작업이 오래 걸리는 이유

| 단계 | 걸리는 것 |
| --- | --- |
| 석고 채형 | 환자가 와서 석고를 떠야 합니다 |
| 양성 모형 | 석고를 깎아 모형을 만듭니다 |
| 열성형 | 플라스틱 판을 가열해서 모형에 씌웁니다 |
| 수정 | 맞지 않으면 처음부터 다시 합니다 |

**전체 과정에 수일이 걸립니다.** 수정이 나오면 또 수일입니다. 3D프린팅은 스캔 데이터에서 바로 출력합니다.

| 무릎 보조기 | 관절 축 위치가 환자마다 다릅니다 |
| 연구용 시제품 | 새 구조를 빠르게 만들어 시험합니다 |

**석고 본뜨기가 없습니다.** 3D 스캔 데이터를 받아 바로 설계에 들어갑니다.

# 장점

기존 수작업과 비교했을 때 세 가지가 다릅니다.

| 항목 | 수작업 | 3D프린팅 |
| --- | --- | --- |
| 채형 | 석고로 본을 뜹니다 | 3D 스캔으로 데이터를 받습니다 |
| 제작 | 플라스틱 판을 가열해서 씌웁니다 | 스캔 데이터로 바로 출력합니다 |
| 수정 | 처음부터 다시 만듭니다 | 파일만 고쳐 다시 뽑습니다 |
| 통기성 | 구멍을 뚫기 어렵습니다 | 격자 구조나 구멍을 자유롭게 넣습니다 |
| 무게 | 두껍게 만들어야 강합니다 | 얇게 만들어도 강도가 나옵니다 |

수정이 나오면 모델만 고쳐 당일 다시 출력합니다.

# 소재

| 조건 | 소재 | 이유 |
| --- | --- | --- |
| 강도·내구성 | SLS 나일론(PA12) | 가볍고 강합니다. 반복 하중에 버팁니다 |
| 유연한 부분 | SLS TPU | 탄성이 있습니다. 인솔이나 패드에 맞습니다 |
| 정밀 외형 | SLA 레진 | 표면이 매끄럽습니다. 피부 접촉면에 쓸 수 있습니다 |
| 투명 확인 | SLA 투명 레진 | 안쪽 구조를 눈으로 확인합니다 |

**SLS 나일론이 가장 많이 쓰입니다.** 가볍고 강도가 높아 체중을 받는 보조기에 맞습니다.

# 의료기기 인허가

한 가지를 확인해야 합니다.

| 구분 | 내용 |
| --- | --- |
| 시제품·연구용 | 인허가 없이 바로 만들 수 있습니다 |
| 환자에게 적용하는 제품 | 의료기기 인허가가 필요할 수 있습니다. 별도 확인이 필요합니다 |

**더블에이엠은 출력을 담당합니다.** 인허가와 임상 적용은 의뢰하시는 쪽에서 판단해 주셔야 합니다. 시제품 단계나 연구용이면 바로 진행할 수 있습니다.

# 맞는 경우와 다시 봐야 할 경우

| 구분 | 내용 |
| --- | --- |
| 잘 맞는 경우 | 환자별 맞춤 보조기 / 통기 구멍이나 격자가 필요한 부목 / 연구용 시제품 / 기존 보조기 형상 개선 테스트 |
| 다시 봐야 할 경우 | **의료기기 인허가가 필요한 제품** — 출력은 가능하지만 인허가는 의뢰처에서 확인해야 합니다 / **체중 전체를 받는 구조 부품** — 소재 강도를 확인해야 합니다. 시험 데이터가 필요할 수 있습니다 / **수량이 많은 경우** — 사출이 개당 단가에서 이깁니다 |

# 담당자가 확인할 것

1. **3D 스캔 데이터가 있는지** 확인합니다. 없으면 스캔 방법을 안내해 드립니다.
2. **용도**를 알려주십시오. 시제품인지, 환자 적용인지에 따라 절차가 달라집니다.
3. **하중 조건**을 확인합니다. 체중을 받는 부위인지에 따라 소재와 두께가 달라집니다.
4. **피부 접촉 여부**를 알려주십시오. 접촉면이면 표면 후처리가 필요할 수 있습니다.

# 자주 묻는 질문

## 3D 스캔은 어떻게 하나요

간단합니다. 핸드헬드 3D 스캐너로 환자 부위를 스캔합니다. STL이나 OBJ 파일로 보내주시면 됩니다. 스캐너가 없으면 방법을 안내해 드립니다.

## 피부에 닿아도 되나요

나일론(PA12)은 피부 접촉에 많이 쓰이는 소재입니다. 다만 의료 목적 사용은 의뢰처에서 판단해 주셔야 합니다.

## 기존 보조기보다 가벼운가요

가능합니다. 같은 강도에서 더 얇게 만들 수 있습니다. 격자 구조를 넣으면 무게가 더 줄어듭니다. 통기성도 좋아집니다.

먼저 정할 것은 소재가 아닙니다. **어디에 착용하고 어떤 하중을 받는가**입니다. 부위와 하중이 정해지면 소재와 두께가 따라옵니다.

스캔 데이터나 기존 보조기 사진을 보내주시면 방식을 잡아 드립니다.
