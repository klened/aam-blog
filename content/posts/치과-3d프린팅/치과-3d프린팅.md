치과는 3D프린팅을 가장 빠르게 도입한 분야 중 하나입니다. 환자마다 형상이 다르고, 하나씩 만들어야 하고, 정밀해야 합니다.

**이 세 가지가 전부 3D프린팅에 맞습니다.**

# 기존 방식의 문제

| 기존 방식 | 문제 |
| --- | --- |
| 기공소 외주 | 보내고 받는 데 2~7일 걸립니다 |
| 석고 모형 | 깨지기 쉽고 보관이 어렵습니다 |
| 수작업 왁스업 | 숙련도에 따라 품질이 갈립니다 |
| 밀링(CAM) | 소재가 제한적이고 복잡한 형상이 어렵습니다 |

# 3D프린팅이 쓰이는 곳

## 서지컬 가이드

임플란트 식립 위치를 안내하는 투명 가이드입니다. CT 데이터로 설계하고 SLA로 출력합니다.

| 항목 | 내용 |
| --- | --- |
| 소재 | 서지컬 가이드 전용 레진 (생체적합성 인증) |
| 정밀도 | ±0.1 mm 수준. 구강 내 정확히 안착합니다 |
| 시간 | 스캔부터 출력까지 당일 가능합니다 |
| 이점 | 식립 정확도가 높아집니다. 수술 시간이 줄어듭니다 |

서지컬 가이드는 치과 3D프린팅 도입의 시작점입니다. 하나만 도입해도 효과가 큽니다.

## 교정 모델

구강 스캔 데이터를 물리적 모형으로 뽑습니다. 석고를 대체합니다.

| 항목 | 내용 |
| --- | --- |
| 소재 | 모델 레진 (고정밀, 저비용) |
| 정밀도 | ±0.05~0.1 mm. 석고보다 정확합니다 |
| 시간 | 한 판에 여러 모형 동시 출력. 1~2시간이면 됩니다 |
| 이점 | 석고와 달리 깨지지 않습니다. 디지털 보관이 됩니다 |

## 투명 교정 장치(얼라이너)

투명 교정 장치의 열성형 금형을 3D프린팅으로 만듭니다. 단계별 치아 이동 모형을 뽑고 그 위에 시트를 열성형합니다.

| 항목 | 내용 |
| --- | --- |
| 소재 | 모델 레진 (열성형용 고정밀) |
| 단계 | 치아 이동 시뮬레이션 → 단계별 모형 출력 → 열성형 |
| 이점 | 단계마다 모형을 개별 제작합니다. 외주 비용의 1/3 이하입니다 |

## 임시 보철(크라운·브릿지)

영구 보철이 나올 때까지 쓰는 임시 크라운이나 브릿지를 출력합니다.

| 항목 | 내용 |
| --- | --- |
| 소재 | 임시 보철 전용 레진 (FDA Class II, 장기 착용 가능) |
| 정밀도 | 마진 적합도 우수. 밀링보다 복잡한 형상 가능 |
| 시간 | 설계 후 1시간 이내 출력 |
| 이점 | 체어사이드에서 당일 제작. 환자 재내원이 줄어듭니다 |

## 나이트가드·스플린트

이갈이 방지용 나이트가드나 교합 스플린트를 직접 출력합니다.

| 항목 | 내용 |
| --- | --- |
| 소재 | 스플린트 전용 레진 (투명, 생체적합성 인증) |
| 강점 | 열성형 방식보다 적합도가 높습니다 |
| 시간 | 스캔부터 완성까지 당일 가능합니다 |

## 의치 베이스·틀니

디지털로 설계한 의치 베이스를 출력합니다.

| 항목 | 내용 |
| --- | --- |
| 소재 | 의치 전용 레진 (핑크 베이스 + 치아 색상) |
| 이점 | 수작업 왁스업을 대체합니다. 적합도가 일정합니다 |

## 주조 원형(캐스터블)

금속 보철을 주조하기 위한 소실 원형을 출력합니다.

| 항목 | 내용 |
| --- | --- |
| 소재 | 캐스터블 레진 (소실 주조용) |
| 과정 | 원형 출력 → 매몰 → 소환 → 금속 주입 |
| 이점 | 왁스 조각보다 정확하고 재현성이 높습니다 |

# 비용 비교

| 항목 | 기공소 외주 | 원내 3D프린팅 |
| --- | --- | --- |
| 서지컬 가이드 1개 | 5만~15만 원 | 소재비 약 5,000~1만 원 |
| 교정 모형 1세트 | 1만~3만 원 | 소재비 약 2,000~5,000원 |
| 제작 기간 | 2~7일 | 당일 |
| 재제작 | 다시 의뢰 + 대기 | 바로 재출력 |

**소재비만 보면 외주의 1/5~1/10입니다.** 장비 구입비가 있지만 월 서지컬 가이드 10개 이상이면 1년 안에 회수됩니다.

# 필요한 장비

| 장비 | 역할 |
| --- | --- |
| SLA 3D프린터 | 출력 (치과 전용 프린터 또는 범용 SLA) |
| 후경화기(UV) | 출력물을 완전히 굳힙니다. 생체적합성 인증 조건입니다 |
| 세척기 | IPA 또는 전용 세척액으로 미경화 레진을 제거합니다 |
| 구강 스캐너 | 3D 스캔 데이터를 생성합니다 (이미 도입된 경우 많음) |
| CAD 소프트웨어 | 보철·가이드 설계 (3Shape, exocad 등) |

SLA 프린터와 후경화기·세척기가 핵심입니다. 구강 스캐너와 CAD는 대부분 이미 쓰고 있습니다.

# 소재 안전성

치과용 레진은 생체적합성 인증이 필수입니다.

| 인증 | 내용 |
| --- | --- |
| FDA Class I | 구강 내 비접촉 (교정 모형 등) |
| FDA Class II | 구강 내 접촉·장기 착용 (가이드, 스플린트, 임시 보철) |
| CE/MDR | 유럽 의료기기 인증 |
| ISO 10993 | 생체적합성 시험 (세포독성, 감작성 등) |

**인증받은 소재만 써야 합니다.** 범용 레진은 구강 내에 쓸 수 없습니다.

# 담당자가 확인할 것

1. **주요 용도**를 정합니다. 서지컬 가이드부터 시작하는 것을 권합니다.
2. **월 출력량**을 추산합니다. 월 10건 이상이면 장비 투자 회수가 빠릅니다.
3. **구강 스캐너 호환**을 확인합니다. STL 또는 PLY 파일을 내보낼 수 있으면 됩니다.
4. **설치 공간**을 확인합니다. SLA 프린터, 세척기, 후경화기가 들어갈 공간이 필요합니다.

# 자주 묻는 질문

## SLA 말고 다른 방식은 안 되나요

밀링(CAM)도 치과에 쓰입니다. 하지만 밀링은 블록을 깎아내는 방식이라 형상에 제약이 있습니다. 서지컬 가이드처럼 속이 빈 부품은 만들기 어렵습니다. SLA는 형상 자유도가 높고 정밀도가 좋아서 치과 적용 범위가 넓습니다.

## 직원 누구나 쓸 수 있나요

됩니다. SLA 프린터 운용은 어렵지 않습니다. 소프트웨어에서 배치하고 시작 버튼을 누르면 됩니다. 보철 설계(CAD)가 더 어려운 부분인데, 이건 3D프린터와 별개로 필요한 역량입니다.

## 출력물을 바로 구강에 넣어도 되나요

후경화를 반드시 해야 합니다. 출력 직후에는 미경화 레진이 남아 있습니다. 제조사가 지정한 시간과 파장으로 후경화한 뒤에야 생체적합성 인증 조건을 충족합니다.

용도와 월 예상 출력량을 알려주시면 장비 구성을 안내해 드립니다.
