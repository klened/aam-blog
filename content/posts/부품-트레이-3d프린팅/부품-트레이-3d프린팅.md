부품을 정리해서 담을 트레이가 필요합니다. 기성품은 포켓 크기가 안 맞습니다.

**전용 트레이를 3D프린팅으로 만들면 부품 형상에 딱 맞는 포켓을 금형 없이 넣을 수 있습니다.**

# 기성품 트레이가 안 맞는 이유

| 방법 | 막히는 것 |
| --- | --- |
| 기성품 트레이 | 포켓 크기가 안 맞습니다. 부품이 놉니다 |
| 스펀지 재단 | 칼로 자르면 형상이 일정하지 않습니다 |
| 사출 트레이 | 금형비가 수백만 원입니다. 20개만 쓸 거면 맞지 않습니다 |

조립 라인에서 부품이 뒤섞입니다. 검사할 때 방향이 틀어집니다. 운반 중에 부딪혀 흠이 납니다.

SLS 나일론(PA12)이나 FDM으로 뽑으면 부품 형상에 맞는 포켓이 한 번에 나옵니다.

| 용도 | 설명 |
| --- | --- |
| 조립 라인 트레이 | 부품을 순서대로 담습니다. 빠뜨리면 빈 포켓이 바로 보입니다 |
| 검사 트레이 | 부품 방향을 잡아 줍니다. [게이지](/blog/검사-게이지-3d프린팅/)를 대는 면이 항상 위를 봅니다 |
| 운반 트레이 | 포켓이 부품을 감쌉니다. 이동 중 부딪힘을 막습니다 |
| 고객 납품 트레이 | 시제품을 정리해서 전달합니다 |

**1개만 필요해도 됩니다.** 부품이 바뀌면 포켓만 고쳐 다시 뽑습니다. 사출 금형을 다시 열 필요가 없습니다.

도면이 없어도 됩니다. 부품 실물이나 사진을 주시면 포켓 형상을 설계해 드립니다.

# 소재와 비용

트레이는 하중이 적습니다. **FDM으로도 되는 경우가 많습니다.** FDM이 SLS보다 개당 비용이 낮습니다. 다만 포켓 안쪽 표면이 거칠어 외관이 중요한 부품에는 SLS가 낫습니다.

| 조건 | 소재 | 이유 |
| --- | --- | --- |
| 일반 정리·운반 | FDM ABS/PLA | 비용이 낮습니다. 포켓 정밀도가 크게 필요하지 않습니다 |
| 외관이 중요한 부품 | SLS 나일론(PA12) | 표면이 고릅니다. 부품에 자국이 남지 않습니다 |
| 세척이 잦은 환경 | SLS 나일론(PA12) | 내약품성이 있습니다. 물과 알코올에 강합니다 |
| 정전기 방지가 필요한 곳 | 전도성 소재 | 반도체·전자 부품에 쓰입니다 |

여러 트레이를 한 판에 함께 뽑을 수 있습니다. **개당 비용이 줄어듭니다.** SLS는 빌드 안에 쌓는 만큼 장비 시간을 나눠 쓸 수 있습니다. 비용이 어떻게 나뉘는지는 [같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)에 정리했습니다.

어긋나면 포켓만 수정해서 당일 다시 출력합니다. 금형을 다시 여는 것과는 일정이 다릅니다.

# 맞는 경우와 다시 봐야 할 경우

| 구분 | 내용 |
| --- | --- |
| 잘 맞는 경우 | 수량 100개 이하 / 부품 형상이 자주 바뀌는 시제품 단계 / 소형 정밀 부품 정리 / 고객 납품용 전용 트레이 |
| 다시 봐야 할 경우 | **트레이가 300mm를 넘는 경우** — SLS 빌드 크기를 확인해야 합니다. 나눠 뽑아 조립할 수 있습니다 / **수량이 500개를 넘는 경우** — 사출 금형이 개당 단가에서 이깁니다 / **정전기 방지가 필요한 경우** — 기본 나일론은 정전기를 막지 못합니다. 전도성 소재를 봐야 합니다 |

비슷한 형태의 부품인 [현장 지그](/blog/3d프린팅-지그-고정구-사례-4건/)도 같은 방식으로 만듭니다. 트레이는 지그보다 하중이 적어 FDM으로도 되는 경우가 많습니다.

# 담당자가 확인할 것

1. **담을 부품의 크기와 개수**를 알려주십시오. 그것이 트레이 크기를 정합니다.
2. **용도**를 정합니다. 조립용인지, 검사용인지, 운반용인지에 따라 포켓 깊이와 여유 간격이 달라집니다.
3. **사용 환경**을 확인합니다. 세척이 필요하면 내약품성 소재를 봐야 합니다.
4. **수량**을 알려주십시오. 트레이 몇 개가 필요한지에 따라 SLS와 FDM이 갈립니다.

# 자주 묻는 질문

## 트레이를 쌓을 수 있나요

됩니다. 트레이 바닥에 쌓임 구조를 넣으면 보관 공간이 줍니다. 설계할 때 미리 반영합니다.

## 포켓 하나를 바꾸면 전체를 다시 만들어야 하나요

파일만 고치면 됩니다. 바뀐 포켓만 수정해서 당일 다시 출력합니다. 나머지 포켓은 그대로 둡니다.

## 트레이에 부품 이름을 넣을 수 있나요

가능합니다. 포켓 옆에 품번이나 이름을 양각으로 넣습니다. 스티커를 붙일 필요가 없습니다. 부품이 바뀌면 글자도 함께 고칩니다.

먼저 정할 것은 트레이 크기가 아닙니다. **안에 무엇이 들어가는가**입니다. 담을 부품이 정해져 있으면 트레이는 거기에 맞춰 설계하면 됩니다.

부품 목록을 알려주시면 포켓 배치를 잡아 드립니다.
