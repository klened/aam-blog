항공과 방산에서 3D프린팅을 검토하면 곧 벽을 만납니다. 부품이 잘 나오느냐가 아니라 **그것을 어떻게 증명하느냐**입니다.

다른 산업에서는 부품이 제 역할을 하면 끝입니다. 여기서는 하나가 더 붙습니다. 어떤 소재로, 어떤 장비에서, 어떤 조건으로 만들었는지가 서류로 남아야 합니다.

이 차이를 먼저 잡고 시작하시면 헛걸음이 줄어듭니다.

# 무엇을 증명해야 하나

요구는 발주처와 부품 등급에 따라 다릅니다. 다만 공통으로 걸리는 항목이 있습니다.

| 공정 기록 | 출력 조건과 장비 상태 |
| 장비 이력 | 점검·보정 기록 |
| 검사 성적 | 치수와 물성 측정값 |
| 작업자 | 누가 어느 단계를 맡았는지 |

![고온 소재 출력 부품과 시험편의 이력을 구분하고 치수를 검사하는 모습](/images/항공-방산-3d프린팅/2.webp)

**범용 소재와 데스크탑 장비로는 이 요구를 맞추기 어렵습니다.** 소재에 로트 번호가 없고, 출력 조건이 기록으로 남지 않기 때문입니다.

산업용 장비가 필요한 이유가 여기 있습니다. 무엇이 다른지는 [스트라타시스 산업용 3D프린터, 언제부터 필요한가](/blog/스트라타시스-산업용-3d프린터/)에 정리했습니다.

# 소재부터 정해집니다

항공에서 쓰이는 3D프린팅 소재는 범위가 좁습니다. 인증 이력이 있는 소재로 한정되기 때문입니다.

| 소재 | 특징 | 쓰는 곳 |
| --- | --- | --- |
| ULTEM 9085 | 난연·내열·강도 | 기내 부품, 덕트 |
| ULTEM 1010 | 더 높은 내열 | 엔진 주변 |
| PEEK | 금속 대체 수준 | 구조 부품 |
| 나일론 CF | 경량 고강성 | 지그, 비구조 부품 |
| 티타늄 | 금속 구조재 | 하중 부품 |

**ULTEM 9085가 항공에서 가장 널리 쓰입니다.** 난연 요구를 맞추면서 무게를 줄일 수 있기 때문입니다.

고온 소재를 금속 대신 쓴 사례는 [ULTEM·PEEK 3D프린팅, 금속 대신 쓸 때](/blog/ultem-peek-3d프린팅-사례-4건/)에, 난연 요구는 [난연 부품을 3D프린팅할 때 확인할 것](/blog/난연-부품-3d프린팅/)에 정리했습니다.

금속 부품은 [금속 부품, 3D프린팅·CNC·주조 중 무엇으로 만드나](/blog/금속-3d프린팅-판단-기준/)를 보시면 판단 순서가 나옵니다.

# 인증 부담이 없는 곳부터 시작합니다

항공기에 올라가지 않는 부품이 많습니다. 여기서는 인증 절차가 걸리지 않습니다.

| 쓰는 곳 | 얻는 것 |
| --- | --- |
| 조립·정비 지그 | 작업 위치를 잡습니다 |
| 검사 게이지 | 치수를 빠르게 확인합니다 |
| 보호 커버 | 정비 중 부품 손상을 막습니다 |
| 전용 공구 | 손이 안 닿는 곳에 씁니다 |
| 훈련용 모형 | 실물 없이 교육합니다 |

![항공기 정비 현장에서 출력한 위치 결정 지그를 사용하는 모습](/images/항공-방산-3d프린팅/3.webp)

*설명을 위한 생성 이미지입니다.*

**효과가 바로 보이고 실패해도 손실이 작습니다.** 지그 사례는 [현장 지그를 3D프린팅으로 바꾸면](/blog/3d프린팅-지그-고정구-사례-4건/)에, 대형 지그는 [FDM으로 대형 위치 결정 지그를 한 번에 만든 사례](/blog/fdm-대형-지그-사례/)에 있습니다.

검사 게이지는 [검사 게이지를 3D프린팅으로 만드는 경우](/blog/검사-게이지-3d프린팅/)를 보시면 됩니다.

# 실제로 항공기에 올라간 사례

기내 비구조 부품은 승인을 거쳐 실제 운항에 쓰입니다.

C-17 수송기 부품을 3D프린팅으로 바꿔 1만 달러짜리를 1,200달러에 만든 사례가 있습니다. 소재를 한 번에 정하지 않고 단계적으로 검증했고, 부품 승인과 항공기별 기록을 나눠 관리했습니다.

자세한 진행 과정은 [FDM C-17 부품, 비용을 88% 줄인 사례](/blog/fdm-c17-항공기-부품-사례/)에 정리했습니다.

**여기서 볼 점은 금액이 아니라 순서입니다.** 소재를 정하고, 승인을 받고, 기록 체계를 만드는 순서가 먼저였습니다.

# 단종 부품이 자주 걸립니다

방산 장비는 운용 기간이 깁니다. 수십 년 쓰는 장비의 부품이 단종되는 경우가 나옵니다.

- 제조사가 없어졌거나 생산을 접었습니다
- 금형이 폐기됐습니다
- 수량이 적어 재생산이 어렵습니다

이때 3D프린팅이 유일한 방법인 경우가 있습니다. 도면이 없어도 실물로 만들 수 있습니다.

같은 사정의 철도 사례는 [FDM으로 단종된 열차 부품을 1주 만에 만든 사례](/blog/fdm-열차-단종-부품-사례/)에 있습니다. 도면이 없을 때 진행 방법은 [도면 없는 부품, 실물만 보내도 제작할 수 있나](/blog/도면-없는-부품-제작/)에 정리했습니다.

# 경량화가 성능이 되는 곳

무게가 곧 연료이고 항속거리입니다. 격자 구조로 속을 비우거나 여러 부품을 하나로 합쳐 무게를 줄입니다.

- 부품 여러 개를 한 덩어리로 다시 설계합니다
- 하중이 지나는 경로만 남기고 나머지를 덜어냅니다
- 탄소섬유 복합 소재로 강성을 유지합니다

무게가 성능으로 직결되는 사례는 [드론 부품은 무게가 곧 성능입니다](/blog/드론-부품-3d프린팅-사례-2건/)에, 섬유 강화 소재는 [섬유를 섞은 소재는 언제 쓰나](/blog/카본파이버-소재/)에 있습니다.

# 도면 보안

방산 부품은 형상 자체가 기밀인 경우가 많습니다. 외부 발주 전에 확인하실 항목입니다.

1. **비밀유지계약** 체결 여부
2. **데이터 보관과 폐기** 방침
3. **작업 인력 범위** — 누가 파일에 접근하는지
4. **재하도급 여부** — 다른 업체로 넘어가는지

보안 요구가 강하면 사내 장비 도입을 검토하게 됩니다. 판단 기준은 [3D프린터, 사는 게 맞는 경우 3가지](/blog/3d프린터-구매-출력대행-비교/)에 정리했습니다.

# 시작하는 순서

1. **지상 지원 장비와 지그**로 시작합니다. 인증이 걸리지 않습니다
2. 효과를 확인한 뒤 **단종·소량 부품**으로 넓힙니다
3. **기내 비구조 부품**은 소재 등급과 승인 절차를 먼저 확인합니다
4. **구조 부품**은 발주처 요구를 정리한 뒤 검토합니다

**3번과 4번을 처음부터 노리면 대부분 검토 단계에서 멈춥니다.** 인증 절차에 걸리는 기간과 비용이 크기 때문입니다.

# 자주 묻는 질문

:::faq
3D프린팅 부품을 항공기에 쓸 수 있나요
쓸 수 있습니다. 실제로 운항 중인 항공기에 3D프린팅 부품이 들어가 있습니다. 다만 부품 등급에 따라 승인 절차가 다르므로 발주처 요구를 먼저 확인해야 합니다.
:::

:::faq
소재 로트 추적이 왜 필요한가요
문제가 생겼을 때 어느 범위까지 영향을 받는지 확인해야 하기 때문입니다. 같은 로트로 만든 부품을 찾아낼 수 있어야 합니다. 이것이 되는 소재와 장비를 써야 합니다.
:::

:::faq
어떤 소재부터 검토하면 되나요
기내 부품이면 ULTEM 9085를 먼저 보십시오. 난연 요구를 맞추면서 무게를 줄일 수 있습니다. 더 높은 내열이 필요하면 ULTEM 1010이나 PEEK를 검토합니다.
:::

:::faq
단종된 방산 부품을 만들 수 있나요
가능합니다. 실물이 하나 있으면 형상을 만들어 출력합니다. 도면이나 파일이 없어도 진행할 수 있습니다. 소재 요구 조건을 함께 알려주시면 맞춰 드립니다.
:::

:::faq
보안이 필요한 부품도 맡길 수 있나요
비밀유지계약을 체결한 뒤 진행합니다. 데이터 보관 기간과 접근 범위도 함께 정합니다. 요구 조건이 있으면 문의 시 말씀해 주시면 됩니다.
:::
