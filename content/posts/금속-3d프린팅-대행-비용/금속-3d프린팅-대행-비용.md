*금속 부품 안에 격자 구조가 들어간 모습을 나타낸 설명용 이미지입니다.*

금속 부품을 3D프린팅으로 만들기로 정하셨다면, 남은 질문은 3가지입니다. 어떤 금속으로 뽑는지, 얼마쯤 드는지, 어떻게 넘기면 되는지입니다.

먼저 결론입니다. **금속 3D프린팅은 금형 없이 1개부터 뽑습니다.** 그래서 소량 시제품을 실제 소재로 먼저 확인하실 수 있습니다. 비용은 출력보다 후처리에서 정해집니다.

깎아서 되는 형상이면 CNC가 쌉니다. 그 판단은 [금속 부품, 3D프린팅·CNC·주조 중 무엇으로 만드나](/blog/금속-3d프린팅-판단-기준/)에 정리했습니다. 이 글은 **3D프린팅으로 정한 뒤**를 다룹니다.

# 어떤 금속을 뽑나

용도를 들으면 소재부터 좁힙니다. 부품이 받는 조건이 소재를 정하기 때문입니다.

| 소재 | 자주 쓰는 곳 |
| --- | --- |
| 알루미늄(AlSi10Mg) | 가벼운 구조 부품, 방열 |
| 스테인리스(SUS316L) | 내식·범용 기계 부품 |
| 티타늄(Ti64) | 가볍고 강한 부품, 몸에 닿는 부품 |
| CoCrMo | 생체 적합·내마모, 의료 |
| 인코넬 | 고온·고압 부품 |
| 공구강 | 금형 인서트, 마모 부위 |

![금속 3D프린팅 직후 빌드 플레이트에 서포트와 함께 붙어 있는 부품](/images/금속-3d프린팅-대행-비용/2.webp)

몸에 닿는 부품은 소재가 좁혀집니다. 실제로 티타늄 Ti64와 CoCrMo로 뽑은 부품이 있습니다. [금속 3D프린팅, 깎을 수 없는 형상 (사례 3건)](/blog/금속-3d프린팅-사례-3건/)에 부품과 소재를 정리했습니다.

**깎기 어려운 소재일수록 3D프린팅이 상대적으로 유리합니다.** 티타늄이나 인코넬은 절삭하면 공구가 빨리 닳고 시간도 오래 걸립니다.

# 비용은 후처리에서 정해집니다

금속은 뽑고 끝나지 않습니다. 출력한 뒤에 서포트 제거, 열처리, 표면 처리, 정밀면 가공이 이어집니다. **이 뒤쪽 공정이 금액의 절반 가까이를 차지합니다.**

# 맡길 때 넘기면 되는 것과 진행 순서

**도면이 없어도 됩니다.** 실물이나 부품 샘플이 있으면 역설계로 데이터를 먼저 만듭니다. 준비할 것과 비용은 [도면 없는 부품, 역설계 비용은 얼마인가](/blog/역설계-비용-사례-4건/)에 정리했습니다.

넘겨주시면 되는 것은 4가지입니다.

| 넘기는 것 | 왜 필요한가 |
| --- | --- |
| 실물 또는 도면 | 없으면 역설계로 데이터를 만듭니다 |
| 하중 방향 | 적층 방향으로는 약해, 세우는 방향을 맞춥니다 |
| 꼭 지킬 치수·정밀면 | 그 면만 CNC로 마무리합니다 |
| 후처리 범위 | 어디까지 다듬느냐로 금액이 달라집니다 |

# 왜 금형 없이 뽑는 것이 유리한가

주조는 형틀을 먼저 만듭니다. 그 비용과 시간이 앞에 듭니다. 3D프린팅은 형틀 없이 파일에서 바로 뽑습니다.

- **빠릅니다.** 형틀 제작 단계가 없어 바로 출력에 들어갑니다.
- **소량을 싸게 확인합니다.** 1~2개를 실제 소재로 먼저 뽑아 강도와 핏을 현장에서 봅니다.
- **깎을 수 없는 형상이 됩니다.** 내부 유로, 격자 경량화, 부품 일체화가 가능합니다.

설계를 고쳐야 하면 모델만 수정해 다시 뽑습니다. 형틀을 다시 만들 필요가 없습니다.

# 다시 봐야 할 경우

| 구분 | 내용 |
| --- | --- |
| 맞는 경우 | 깎을 수 없는 형상 / 1~2개 정밀 부품 / 깎기 어려운 소재(티타늄·인코넬) / 몸에 닿아 소재가 정해진 부품 |
| 다시 봐야 합니다 | **단순한 형상** — 깎는 편이 쌉니다 / **큰 부품** — 소재값과 장비 시간이 빠르게 오릅니다 / **수량이 많은 부품** — 주조·사출과 비교하십시오 / **매우 매끈한 면** — 후가공이 따로 붙습니다 |

수백 개를 넘으면 주조가 쌉니다. 개당 단가에서 앞서기 때문입니다. 소량이라면 주조 원형을 3D프린팅으로 만드는 방법도 있습니다. [SLA 주조 원형으로 금속 부품 20개를 만든 사례](/blog/sla-정밀주조-원형-사례/)에 정리했습니다.

# 담당자가 확인할 것

1. **깎아서 되는 형상인지** 먼저 봅니다. 되면 대개 그쪽이 쌉니다.
2. **부품이 받는 조건**을 알려주십시오. 하중·온도·접촉으로 소재가 좁혀집니다.
3. **꼭 지킬 치수와 정밀면**을 표시합니다. 그 면만 따로 가공합니다.
4. **후처리를 어디까지 할지** 정합니다. 금액이 여기서 크게 달라집니다.
5. **수량**을 알려주십시오. 많으면 다른 공법과 비교해 드립니다.
