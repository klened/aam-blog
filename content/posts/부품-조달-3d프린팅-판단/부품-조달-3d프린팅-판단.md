3D프린팅은 처음부터 선택하는 제작 방식이 아닙니다. CNC·금형·기존 외주로 공급하던 부품이 납기·단종·가격·형상 문제로 막혔을 때 대체안으로 검토합니다. 먼저 부품 단가가 아니라 기존 방식이 돌아올 때까지 발생하는 손실을 적어 보세요.

설비 옆에는 파손된 가이드가 놓여 있고, 공급사는 3주 뒤 납품이 가능하다고 합니다. 구매팀은 견적을 묻지만 생산팀이 먼저 묻는 것은 따로 있습니다.

**언제 다시 돌릴 수 있습니까.**

이 글은 5단계를 한 번에 보는 안내서입니다. 공정별 세부 기준은 기존 글로 연결합니다.

# 1. 처음에는 기존 방식이 맞았습니다

![CNC 가공 부품과 사출 금형, 외주 납품 부품이 작업대에 놓인 모습](/images/부품-조달-3d프린팅-판단/4.webp)

CNC는 정밀도와 실소재가 필요할 때 알맞습니다. 사출 금형은 같은 부품을 많이 만들수록 단가가 낮아집니다. 오랫동안 거래한 외주 업체라면 도면과 검사 기준도 이미 맞춰져 있습니다.

문제가 없는데 3D프린팅으로 바꿀 이유는 없습니다. [CNC와 3D프린팅을 비교하는 기준](/blog/cnc-3d프린팅-비교/)도 정밀도·소재·형상·수량에서 시작합니다.

# 2. 기존 조달 경로가 막힙니다

![비어 있는 부품 선반과 파손 부품, 멈춘 생산 설비가 함께 보이는 현장](/images/부품-조달-3d프린팅-판단/5.webp)

3D프린팅 문의는 보통 여기에서 시작합니다.

- 공급사는 만들 수 있지만 납기가 너무 깁니다.
- 부품이나 장비가 단종되어 주문할 곳이 없습니다.
- 필요한 것은 1개인데 최소 주문 수량과 금형비가 붙습니다.
- 절삭 공구가 들어가지 않는 내부 유로나 일체형 구조가 필요합니다.
- 설계가 계속 바뀌어 금형을 확정하기 어렵습니다.

가격이 올랐다는 이유만으로 바로 바꾸지는 않습니다. 기존 부품이 싸고 충분히 빨리 들어온다면 그대로 사는 편이 낫습니다.

# 3. 기존 공정이 아니라 필요한 기능을 옮깁니다

![파손된 기존 부품을 캘리퍼와 3D 스캐너로 측정해 형상을 복원하는 작업](/images/부품-조달-3d프린팅-판단/2.webp)

금속으로 깎았던 부품을 그대로 플라스틱으로 복제하면 실패할 수 있습니다. 먼저 부품이 맡던 일을 적습니다.

| 확인할 조건 | 담당자가 답할 내용 |
| --- | --- |
| 하중 | 누르는 힘, 당기는 힘, 충격 중 무엇을 받는가 |
| 온도 | 평상시와 순간 최고 온도는 몇 도인가 |
| 접촉 | 물·오일·세정제·식품과 닿는가 |
| 수명 | 임시 복구용인가, 반복해서 계속 쓸 것인가 |
| 정밀도 | 조립에 필요한 치수와 허용 공차는 얼마인가 |
| 승인 | 안전·난연·의료·고객 규격 확인이 필요한가 |

도면이 없다면 정상 부품이나 파손된 실물로 형상을 복원합니다. 파손 부위는 그대로 복사하지 않고 주변 구조와 상대 부품을 함께 봐야 합니다. 준비 방법은 [도면 없는 부품을 다시 만드는 순서](/blog/도면-없는-부품-제작/)에 정리했습니다.

# 4. 되나·얼마·언제를 한 번에 묻습니다

3D프린팅 업체가 답해야 하는 질문은 3가지입니다.

![3D프린팅 견적에서 제작 가능 여부와 총비용, 실제 사용 가능일을 함께 확인하는 도식](/images/부품-조달-3d프린팅-판단/6.svg)

| 질문 | 확인할 근거 |
| --- | --- |
| 제작할 수 있나 | 형상, 소재, 하중, 온도, 공차, 승인 조건 |
| 총비용은 얼마인가 | 모델링, 출력, 후처리, 검사, 배송 포함 범위 |
| 언제 사용할 수 있나 | 파일 검토, 시험 출력, 본 제작, 검수, 배송 일정 |

출력 시간만 듣고 납기를 정하면 안 됩니다. 역설계와 시험 장착이 필요하면 그 시간도 포함해야 합니다. 일반적인 진행은 [견적부터 납품까지 5단계](/blog/3d프린팅-출력대행-절차/)에서 확인할 수 있습니다.

# 5. 단가가 아니라 회복하는 시간을 계산합니다

예를 들어 기존 부품은 8일 뒤에 15만 원으로 들어오고, 3D프린팅 부품은 검증을 포함해 2일 뒤에 42만 원으로 받을 수 있다고 하겠습니다.

- 3D프린팅으로 줄이는 시간: 6일
- 추가 제작비: 27만 원
- 설비 정지 손실: 하루 100만 원이라고 가정
- 회복하는 시간의 값: 600만 원

![기존 방식의 8일 15만 원과 3D프린팅의 2일 42만 원을 비교해 회복 시간의 가치를 계산한 예시](/images/부품-조달-3d프린팅-판단/7.svg)

계산 예시에서는 27만 원을 아끼기 위해 6일을 기다리는 편이 더 비쌉니다. 다만 3D프린팅 부품이 하중과 온도를 견딘다는 검증이 먼저 끝나야 합니다.

정지 손실에는 생산하지 못한 물량만 들어가지 않습니다. 대기 인력, 납품 지연, 긴급 운송, 다른 설비로 옮기는 작업도 함께 적습니다.

# 그래도 바로 설치하면 안 되는 부품이 있습니다

![기술자가 검증을 마친 3D프린팅 교체 부품을 멈춘 생산 설비에 장착하는 모습](/images/부품-조달-3d프린팅-판단/3.webp)

다음 부품은 제작 가능 여부와 별도로 승인 절차를 확인해야 합니다.

- 사람이 다치거나 설비가 크게 파손될 수 있는 안전 부품
- 압력·전기·화재와 관련된 부품
- 의료·식품·항공·철도 규격이 적용되는 부품
- 치수가 조금만 달라도 다른 장치를 손상시키는 부품

이때 3D프린팅은 시험 장착이나 임시 복구에만 쓰고, 승인된 최종 부품이 올 때까지 운전 조건을 제한할 수 있습니다. 소재 등급이 맞더라도 완성 부품의 승인까지 자동으로 끝나는 것은 아닙니다.

# 실제 사례에서도 시간부터 달라졌습니다

Eaton은 잃어버리거나 닳을 때마다 1주를 기다리던 가공 나일론 부품을 SLS 스냅핏으로 바꿨습니다. 교체 부품을 다음 날 받을 수 있게 된 과정은 [SLS로 교체용 스냅핏 부품을 밤새 만든 사례](/blog/sls-스냅핏-부품-사례/)에 있습니다.

Angel Trains는 단종된 열차 팔걸이 11개를 기존 방식으로 만들면 약 4개월이 필요했지만, 승인 시험을 거친 FDM 부품은 1주 안에 제작했습니다. [단종된 열차 부품 제작 사례](/blog/fdm-열차-단종-부품-사례/)에서 소재와 승인 범위를 함께 볼 수 있습니다.

GKN은 제조사 납품을 기다리는 대신 케이블 브래킷을 출력해 생산 설비에 적용했습니다. [Stratasys가 공개한 GKN 사례](https://www.stratasys.com/uk/resources/case-studies/gkn-group/)에서 빠른 대체 제작이 설비 정지 시간을 줄인 배경을 확인할 수 있습니다.

# 담당자가 처음 보낼 자료

1. 부품 사진과 전체 크기
2. 3D 파일이나 도면, 없으면 파손된 실물
3. 필요한 수량과 반드시 받아야 하는 날짜
4. 부품이 받는 힘·열·약품 조건
5. 임시 복구용인지 계속 사용할 부품인지
6. 검사와 승인에 필요한 항목

도면이나 사용 조건을 모두 정리하지 못했다면 현재 확보한 자료부터 보냅니다. 제작 방식을 미리 정할 필요도 없습니다. 부품이 필요한 이유와 설비를 다시 가동해야 하는 날짜를 먼저 알려주세요.

# 자주 묻는 질문

:::faq
3D프린팅이 CNC보다 비싸도 진행할 수 있나요
가능합니다. 3D프린팅으로 줄이는 정지 시간의 값이 추가 제작비보다 크고, 필요한 기능과 안전 조건을 검증할 수 있다면 전체 비용은 오히려 낮아질 수 있습니다.
:::

:::faq
단종된 부품은 원본 파일이 없어도 만들 수 있나요
정상 부품이나 파손된 실물을 측정해 3D 데이터를 만들 수 있습니다. 파손 전 형상을 추정해야 하므로 상대 부품과 장착 위치도 함께 확인합니다.
:::

:::faq
출력 부품을 정식 부품이 올 때까지만 써도 되나요
임시 복구용으로 검토할 수 있습니다. 다만 하중·온도·안전 조건을 시험하고 사용 기간과 운전 조건을 정해야 합니다. 안전과 인증이 필요한 부품은 담당 부서의 승인이 먼저입니다.
:::

:::faq
사진만 보내도 제작 가능 여부를 알 수 있나요
사진으로 공정 후보와 확인할 항목을 정할 수 있습니다. 정확한 견적과 제작에는 크기, 수량, 사용 조건과 3D 파일 또는 실물 측정이 추가로 필요합니다.
:::
