*FDM 인필과 강도의 관계를 설명하기 위한 이미지입니다.*

“튼튼하게 100%로 채워 주세요”라는 요청을 자주 받습니다. 인필을 늘리면 재료는 더 들어갑니다. 그러나 강도가 같은 비율로 늘지는 않습니다.

인필 숫자보다 **힘이 어디로 지나가는지**를 먼저 봐야 합니다.

# 인필은 부품 안쪽의 구조입니다

![밀도가 다른 FDM 인필 구조를 절단면으로 비교한 시편](/images/fdm-인필-강도-비용/2.webp)

FDM은 외벽을 만든 뒤 내부를 격자나 선 구조로 채웁니다. 인필 20%는 내부 공간의 일부만 채우고, 100%는 빈 공간을 거의 남기지 않는 설정입니다.

| 항목 | 낮은 인필 | 높은 인필 |
| --- | --- | --- |
| 재료 사용량 | 적습니다 | 많습니다 |
| 출력 시간 | 짧습니다 | 길어집니다 |
| 무게 | 가볍습니다 | 무거워집니다 |
| 압축 하중 | 내부 지지가 적습니다 | 내부 지지가 늘어납니다 |
| 열 축적 | 비교적 적습니다 | 변형 위험을 따로 봐야 합니다 |

수치는 슬라이서와 형상에 따라 달라집니다. 인필 20%와 100%의 가격 차이를 고정 배수로 말할 수 없는 이유입니다.

# 벽이 먼저 힘을 받습니다

![벽 두께와 인필 구조가 다른 FDM 시편을 압축 시험하는 모습](/images/fdm-인필-강도-비용/3.webp)

굽힘을 받는 부품은 바깥쪽 벽에 큰 응력이 생깁니다. 이때 인필을 조금 높이는 것보다 벽 수를 늘리는 편이 더 유리할 수 있습니다.

나사 구멍과 보스, 얇은 목처럼 힘이 모이는 구간도 따로 봐야 합니다. 전체를 100%로 채워도 모서리에서 깨지거나 적층면이 벌어질 수 있습니다.

출력 방향이 강도에 미치는 영향은 [출력 방향이 강도를 바꿉니다](/blog/출력-방향과-강도/)에서 확인할 수 있습니다.

# 100%가 항상 좋은 설정은 아닙니다

인필 100%는 압축 지지와 무게가 필요한 부품에 쓸 수 있습니다. 반면 큰 부품에서는 출력 시간이 크게 늘고 내부 열이 빠져나가기 어려워 변형이 생길 수 있습니다.

완전 충전처럼 보여도 출력선 사이에는 경계가 남습니다. 절삭 가공한 덩어리 소재와 같은 구조로 보면 안 됩니다.

| 부품 조건 | 먼저 조정할 항목 |
| --- | --- |
| 휘어지는 브라켓 | 벽 수와 리브, 출력 방향 |
| 나사 체결부 | 보스 두께와 국부 인필 |
| 위에서 눌리는 받침 | 인필 패턴과 밀도 |
| 가벼워야 하는 커버 | 낮은 인필과 충분한 외벽 |
| 가공할 면이 있는 부품 | 가공 여유 구간의 국부 보강 |

# 비용은 재료량만으로 정해지지 않습니다

인필을 높이면 재료와 장비 시간이 늘어납니다. 다만 견적에는 장비 준비와 후처리, 최소 작업비도 포함됩니다. 작은 부품 1개의 인필을 바꿨다고 총액이 같은 비율로 변하지는 않습니다.

3D프린팅 견적의 항목은 [같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)에서 자세히 볼 수 있습니다.

# 시험할 때 정할 것

1. 실제로 받는 힘의 방향을 표시합니다.
2. 벽 수와 위·아래 면의 두께를 먼저 정합니다.
3. 인필 패턴과 비율을 고릅니다.
4. 나사 보스와 모서리를 국부 보강합니다.
5. 같은 조건의 시험편을 파손 또는 변형 시험으로 비교합니다.

FDM이 아닌 매끈한 시제품이 목적이라면 [FDM과 SLA, 어떤 걸 쓸지 정하는 기준](/blog/fdm-sla-비교/)을 먼저 확인하십시오.

# 자주 묻는 질문

:::faq
인필 100%는 20%보다 5배 강한가요
그렇게 계산할 수 없습니다. 하중 방향과 벽 수, 인필 패턴, 적층 방향에 따라 차이가 달라집니다.
:::

:::faq
강도를 높이려면 인필부터 올려야 하나요
굽힘과 충격을 받는 부품은 벽 수와 출력 방향을 먼저 검토합니다. 힘이 모이는 구간만 인필을 높이는 방법도 있습니다.
:::

:::faq
인필 100%면 물이 새지 않나요
인필과 기밀성은 다른 항목입니다. 출력선과 층 사이에 틈이 남을 수 있으므로 벽 두께와 공정 조건, 밀폐 시험을 따로 정해야 합니다.
:::

:::faq
견적 요청 때 인필을 지정해야 하나요
정해진 사내 기준이 있으면 적어 주십시오. 기준이 없다면 부품 용도와 하중, 목표 무게를 알려주면 벽과 인필 조건을 함께 제안할 수 있습니다.
:::

인필 100%는 강도를 보장하는 문구가 아닙니다. 벽과 방향, 하중 경로를 설계한 뒤 필요한 만큼 채워야 합니다.
