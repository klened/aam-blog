3D프린팅 업체를 검색하면 많이 나옵니다. 가격부터 비교하고 싶어지지만, 견적만 보고 정하면 문제가 생길 수 있습니다.

같은 "3D프린팅 서비스"라도 업체마다 할 수 있는 범위가 다릅니다. 어떤 곳은 FDM만 되고, 어떤 곳은 SLA·SLS·FDM 전부 됩니다. 후처리가 포함된 곳이 있고, 출력만 하는 곳이 있습니다.

세 가지를 먼저 확인하면 맞는 업체를 고를 수 있습니다.

# 1. 장비 보유 범위

가장 먼저 봐야 합니다. 3D프린팅은 방식마다 쓸 수 있는 소재와 품질이 다릅니다.

| 방식 | 특징 | 주요 소재 |
| --- | --- | --- |
| FDM | 가장 저렴, 형상 확인용 | ABS, PLA, PETG, 나일론 |
| SLA | 매끈한 표면, 높은 정밀도 | 표준 레진, 터프 레진, 고온 레진 |
| SLS | 서포트 없음, 기능성 부품 | PA12, PA11, TPU, GF 복합 |
| MJF | SLS와 비슷, 생산성 높음 | PA12 |
| PolyJet | 풀컬러, 멀티소재 | 포토폴리머 |
| DMLS | 금속 출력 | Ti, SUS, 인코넬 |

방식별 차이는 [산업용 3D프린터 방식 4가지](/blog/산업용-3d프린터-방식-4가지/)에 정리했습니다.

**왜 중요한가.** 처음에는 FDM으로 형상만 확인하면 충분했는데, 다음에는 기능 테스트를 위해 SLS가 필요해질 수 있습니다. 이때 업체를 바꿔야 하면 소통 비용이 다시 발생합니다.

여러 방식을 보유한 업체를 쓰면 같은 부품을 용도에 따라 방식만 바꿔 제작할 수 있습니다. 파일을 다시 보내고, 요구 사항을 다시 설명할 필요가 없습니다.

![같은 형상을 FDM SLA SLS로 만든 샘플을 비교하는 모습](/images/3d프린팅-업체-선정-기준/2.webp)

# 2. 후처리 포함 여부

견적에 **후처리가 포함되어 있는지** 반드시 확인합니다. 같은 금액이라도 포함된 항목이 다르면 최종 비용이 달라집니다.

| 후처리 항목 | 설명 | 빠지면 생기는 일 |
| --- | --- | --- |
| 서포트 제거 | SLA·FDM의 지지대 제거 | 직접 떼어내야 합니다 |
| 세척·경화 | SLA 레진 부품의 필수 공정 | 미세척 시 물성 저하 |
| 연마·샌딩 | 표면 다듬기 | 거친 표면 그대로 받습니다 |
| 도색·도금 | 외관 마감 | 별도 도장 업체를 찾아야 합니다 |
| 조립·접합 | 분할 출력 후 조립 | 직접 붙여야 합니다 |

후처리 종류와 필요한 경우는 [3D프린팅 후처리 종류](/blog/3d프린팅-후처리-종류/)에서 정리했습니다.

**확인 방법.** 견적서에 "후처리 포함"이라고만 쓰여 있으면 범위를 물어봅니다. 서포트 제거만 포함인지, 연마까지 포함인지에 따라 결과물이 다릅니다.

![출력 부품의 후처리와 치수 검사를 함께 진행하는 모습](/images/3d프린팅-업체-선정-기준/3.webp)

# 3. 기술 상담 가능 여부

이것이 가장 차이가 큽니다.

파일을 보내면 그대로 출력만 해주는 곳이 있고, **어떤 방식과 소재가 맞는지 먼저 살펴주는 곳**이 있습니다. 둘은 결과가 다릅니다.

기술 상담이 가능한 업체는 이런 것을 해줍니다.

- 파일을 보고 **출력에 적합한 방향과 배치**를 잡아줍니다
- 소재별 장단점을 **용도에 맞춰** 안내합니다
- 형상에 따라 **방식 변경을 제안**합니다
- 후처리 범위와 정밀도를 **사전에 합의**합니다

출력만 해주는 곳에서는 결과물을 받고 나서 "이건 왜 이렇게 나왔지"라는 상황이 생길 수 있습니다. 그때 수정 출력을 하면 비용이 두 배가 됩니다.

# 업체 유형별 비교

3D프린팅 업체는 크게 세 가지 유형입니다.

| 유형 | 특징 | 맞는 경우 |
| --- | --- | --- |
| 플랫폼 | 가격 비교·중개 | 단순 출력, 가격 우선 |
| 출력 전문 | 장비 직접 보유·운영 | 품질 관리, 기술 상담 필요 |
| 장비 판매 겸 서비스 | 장비 판매 + 출력대행 | 도입 검토와 출력을 같이 진행 |

**플랫폼**은 여러 업체의 견적을 한 번에 받을 수 있어 편리합니다. 대신 실제 출력은 어떤 업체에서 하는지 모를 수 있고, 기술 상담이 어렵습니다.

**출력 전문 업체**는 장비를 직접 운영하므로 품질 관리가 됩니다. 다만 보유 장비 범위가 좁은 경우가 있으므로 어떤 방식을 갖추고 있는지 확인합니다.

**장비 판매 겸 서비스 업체**는 장비를 알기 때문에 소재·방식 선택을 정확하게 안내할 수 있습니다. 나중에 장비 도입을 검토할 때도 같은 곳에서 상담을 이어갈 수 있습니다. 더블에이엠이 여기에 해당합니다.

장비 도입 여부를 함께 고민하고 계시면 [3D프린터, 사는 게 맞는 경우 3가지](/blog/3d프린터-구매-출력대행-비교/)를 참고하시면 됩니다.

# 견적 비교할 때 체크리스트

같은 부품으로 여러 곳에 견적을 받을 때 아래 항목을 나란히 놓고 비교합니다.

| 항목 | 확인할 것 |
| --- | --- |
| 방식 | FDM인지, SLA인지, SLS인지 |
| 소재 | 정확한 소재명(예: PA12, Tough 2000) |
| 정밀도 | 보증 공차가 몇 mm인지 |
| 후처리 | 어디까지 포함인지 |
| 납기 | 출력 시작일과 수령일 |
| 배송비 | 포함인지 별도인지 |
| 수정 출력 | 불량 시 재출력 정책 |

견적 요청 전에 준비할 것은 [견적 전에 정할 것](/blog/견적-전에-정할-것/)에 정리했습니다.

[같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)를 함께 보시면 견적 금액의 차이가 왜 생기는지 이해하기 쉽습니다.

# 자주 묻는 질문

:::faq
3D 파일이 없어도 의뢰할 수 있나요
가능합니다. 실물이나 스케치를 기준으로 3D 모델링을 한 뒤 출력합니다. 모델링까지 해주는 업체인지 확인하시면 됩니다. 더블에이엠은 역설계와 모델링을 포함해 진행합니다.
:::

:::faq
시제품 1개만도 맡길 수 있나요
됩니다. 3D프린팅은 1개부터 가능합니다. 최소 수량 제한이 없는 업체를 선택하시면 됩니다.
:::

:::faq
같은 파일로 여러 방식을 비교해볼 수 있나요
가능합니다. FDM·SLA·SLS 각각으로 출력해서 표면·강도·정밀도를 직접 비교하는 방법입니다. 여러 방식을 보유한 업체에 맡기면 한 번에 비교할 수 있습니다. [같은 부품 방식별 비교](/blog/같은-부품-방식별-비교-사례-3건/)에서 실물 비교 사례를 확인하실 수 있습니다.
:::

:::faq
도면 보안이 걱정됩니다
NDA(비밀유지계약)를 요청하시면 됩니다. 보안이 중요한 부품이라면 NDA 체결 후 진행하는 업체를 선택합니다.
:::
