의수와 의족은 사용자마다 체형이 다릅니다. 절단 부위, 잔존 길이, 체중이 전부 다릅니다.

**하나씩 맞춰 만들어야 합니다.** 이 점이 3D프린팅에 맞습니다.

# 기존 방식의 문제

| 기존 방식 | 문제 |
| --- | --- |
| 석고 본뜨기 | 사용자가 불편합니다. 석고가 굳을 때까지 기다려야 합니다 |
| 수작업 성형 | 숙련 기술자가 필요합니다. 작업 시간이 깁니다 |
| 제작 기간 | 2~4주가 보통입니다 |
| 수정 | 소켓이 안 맞으면 처음부터 다시 만드는 경우가 있습니다 |
| 디자인 | 피부색 스타킹이 기본입니다. 개인 취향을 반영하기 어렵습니다 |

# 3D프린팅이 바꾸는 것

## 측정: 스캔으로 대체

석고 대신 3D스캐너로 잔존 부위를 스캔합니다. 비접촉이라 불편함이 없고, 데이터가 디지털로 남습니다. 원격 측정도 가능합니다.

## 설계: 디지털로 수정

스캔 데이터를 CAD에서 수정합니다. 소켓 형상을 0.1 mm 단위로 조절할 수 있습니다. 수정할 때 처음부터 다시 만들 필요가 없습니다.

## 출력: 하루 안에 완성

SLS 나일론이나 SLA 레진으로 소켓과 외장 커버를 출력합니다. 설계가 끝나면 하루 안에 부품이 나옵니다.

## 디자인: 자유로운 외관

격자 패턴, 기하학적 무늬, 원하는 색상을 넣을 수 있습니다. 기존 방식에서는 만들기 어려운 외관입니다.

# 출력 방식별 비교

| 항목 | SLS (나일론) | SLA (레진) |
| --- | --- | --- |
| 강도 | 충격에 강합니다. 일상 사용에 적합합니다 | 레진에 따라 다릅니다. 고강도 레진이면 가능합니다 |
| 무게 | 가볍습니다. 나일론 자체가 경량입니다 | 보통입니다 |
| 표면 | 약간 거칩니다. 후처리하면 매끄러워집니다 | 매끄럽습니다 |
| 용도 | 소켓·구조 부품 · 외장 커버 | 정밀 부품 · 외관 목업 |
| 유연성 | PA11이면 유연합니다 | 듀러블 레진이면 가능합니다 |

**구조 부품과 소켓은 SLS 나일론이 맞습니다.** 충격에 강하고 가볍습니다. 외관 확인용 목업은 SLA가 표면이 좋습니다.

나일론 소재 선택은 [나일론 11과 나일론 12 비교](/blog/나일론11-나일론12-비교/)에 정리했습니다.

# 적용 분야

## 의수 소켓

잔존 부위에 끼우는 소켓을 사용자 체형에 맞춰 출력합니다. 피부 접촉면을 0.1 mm 단위로 조절해 압박 분포를 최적화합니다.

## 의족 커버

의족 파이프 위에 씌우는 외장 커버를 출력합니다. 격자 구조를 넣으면 가벼우면서 통기성이 좋습니다. 원하는 디자인을 적용할 수 있습니다.

## 보조기(AFO·KAFO)

발목-발 보조기(AFO)나 무릎-발목-발 보조기(KAFO)의 외장을 출력합니다. SLS PA11이면 유연성이 좋아 착용감이 나아집니다.

## 손가락 의수

부분 절단 사용자를 위한 손가락 의수를 출력합니다. 크기가 작아 기존 방식으로는 정밀하게 만들기 어렵지만, SLA면 세밀한 형상이 가능합니다.

# 비용 비교

| 항목 | 기존 수작업 | 3D프린팅 |
| --- | --- | --- |
| 측정 | 석고 본뜨기 (1~2시간) | 3D스캔 (10~20분) |
| 제작 기간 | 2~4주 | 3~5일 (스캔·설계·출력·조립) |
| 소켓 수정 | 처음부터 재제작하는 경우 있음 | 디지털 수정 후 재출력 |
| 외관 커스터마이징 | 제한적 (피부색 스타킹) | 자유로움 (격자, 패턴, 색상) |

제작 기간이 2~4주에서 3~5일로 줄어듭니다. 수정이 나와도 디지털 파일을 고쳐 다시 뽑으면 됩니다.

# 맞는 경우와 안 맞는 경우

| 구분 | 내용 |
| --- | --- |
| 잘 맞는 경우 | 소켓·커버·보조기 외장처럼 체형에 맞춰야 하는 부품 / 디자인 커스터마이징이 필요한 경우 / 빠른 제작이 필요한 경우 |
| 안 맞는 경우 | **고하중 구조 부품** — 체중을 직접 지탱하는 파이프나 관절은 금속이 필요합니다 / **대량 생산** — 표준 규격 부품은 사출이 효율적입니다 |

3D프린팅은 체형 맞춤 외장과 소켓에 맞습니다. 관절 메커니즘이나 파이프 같은 고하중 부품은 금속 부품을 씁니다.

# 담당자가 확인할 것

1. **대상 부품**을 정합니다. 소켓, 외장 커버, 보조기 중 어디부터 적용할지 정합니다.
2. **3D스캐너 보유 여부**를 확인합니다. 없으면 핸드헬드 스캐너 도입을 함께 검토합니다.
3. **소재 요구**를 확인합니다. 충격이 가해지는 부품이면 SLS PA11, 정밀 외관이면 SLA입니다.
4. **인증 요구**를 확인합니다. 피부 접촉 부품이면 생체적합성 인증 소재가 필요합니다.

# 자주 묻는 질문

## 출력한 소켓이 체중을 버티나요

소켓은 잔존 부위를 감싸는 부품이라 직접 체중을 지탱하지 않습니다. 하중은 파이프와 발부가 받습니다. SLS 나일론 소켓은 일상 사용에 충분한 강도가 있습니다.

## 의료기기 인증이 필요한가요

용도에 따라 다릅니다. 의료기기로 분류되면 인증이 필요합니다. 보조기·의지 제작에 쓰는 소재는 생체적합성 시험(ISO 10993)을 통과한 것을 쓰는 것이 원칙입니다.

## 기존 의지 위에 커버만 씌우는 것도 되나요

됩니다. 가장 흔한 시작 방식입니다. 기존 의족의 파이프와 관절은 그대로 두고, 외장 커버만 3D프린팅으로 교체합니다. 구조적 변경이 없어 도입 부담이 적습니다.

부품 종류와 사용자 정보를 알려주시면 적합한 출력 방식을 안내해 드립니다.
