STL 파일을 열면 부품 모양이 보입니다. 그런데 출력 업체에서는 파일을 다시 보내거나 수정해야 한다고 답합니다.

보이는 것과 출력 가능한 것은 다릅니다. 슬라이서가 안과 밖을 구분할 수 있는 닫힌 입체여야 합니다.

# STL은 삼각형 면의 모음입니다

CAD 원본은 곡면과 치수 정보를 지닙니다. STL은 그 표면을 작은 삼각형으로 바꾼 파일입니다.

변환 과정에서 면이 빠지거나 겹칠 수 있습니다. 곡면을 너무 큰 삼각형으로 바꾸면 둥근 곳도 각져 보입니다. STL에는 단위 정보가 없어 프로그램 설정에 따라 크기가 달라질 수도 있습니다.

[어떤 파일을 보내야 하나](/blog/3d프린팅-파일-형식-정리/)에서는 STL과 STEP, OBJ의 역할을 비교했습니다. 이 글은 STL을 받은 뒤 무엇을 검사하는지에 집중합니다.

# 자주 발견하는 오류 6가지

| 오류 | 출력 준비에서 생기는 문제 |
| --- | --- |
| 열린 면과 틈 | 안과 밖을 구분하지 못합니다 |
| 겹친 셸 | 한 부품인지 여러 부품인지 판단하기 어렵습니다 |
| 자체 교차 | 내부와 외부가 같은 자리를 차지합니다 |
| 뒤집힌 면 | 재료를 채울 방향이 반대로 읽힐 수 있습니다 |
| 떠 있는 작은 조각 | 의도하지 않은 부품이 함께 배치됩니다 |
| 단위·배율 오류 | mm와 inch 해석에 따라 크기가 달라집니다 |

Formlabs도 STL 보정 단계로 구멍 닫기, 분리된 셸 확인, 교차 제거, 뒤집힌 면과 중복 면 정리를 안내합니다. 작은 오류는 자동으로 고칠 수 있습니다.

# 자동 보정이 끝이 아닌 이유

보정 프로그램은 열린 면을 막을 수 있습니다. 하지만 원래 구멍이었는지 손상된 면이었는지는 알지 못합니다.

내부 유로의 입구를 오류로 판단해 막거나, 얇은 틈을 붙여 버릴 수도 있습니다. 자동 보정 후에는 필수 구멍과 조립면이 남았는지 원본과 비교해야 합니다.

형상이 크게 달라졌다면 STL 삼각형을 직접 고치는 것보다 STEP 원본에서 다시 내보내는 편이 낫습니다. 수정 가능한 원본이 없으면 [도면 없는 부품, 실물만 보내도 제작할 수 있나](/blog/도면-없는-부품-제작/)처럼 역설계 범위를 검토합니다.

# 출력 전에 확인하는 순서

1. 파일의 단위와 전체 크기를 확인합니다.
2. 메시가 닫혀 있고 면 방향이 일정한지 검사합니다.
3. 분리된 셸과 떠 있는 조각을 찾습니다.
4. 얇은 벽과 작은 구멍이 장비 조건에 맞는지 봅니다.
5. 자동 보정 전후 형상을 겹쳐 비교합니다.

파일이 정상이어도 출력 조건 검토는 남습니다. 서포트, 출력 방향, 후처리 접근성은 메시 오류가 아닙니다. [3D프린팅 출력 대행, 파일을 보내면 어떤 순서로 진행되나](/blog/3d프린팅-출력대행-절차/)에서 다음 단계를 확인할 수 있습니다.

# 같이 보내면 좋은 자료

| 자료 | 필요한 이유 |
| --- | --- |
| STL | 실제 출력할 메시를 확인합니다 |
| STEP 또는 CAD 원본 | 치수 수정과 재변환에 씁니다 |
| 기준 치수 3곳 | 배율과 변환 오류를 확인합니다 |
| 조립 상대 부품 정보 | 없어지면 안 되는 구멍과 면을 찾습니다 |
| 수정 금지 위치 | 자동 보정 후 반드시 비교할 곳을 정합니다 |

원본이 없다고 접수를 못 하는 것은 아닙니다. 먼저 STL을 진단하고, 자동 보정으로 끝나는지 재모델링이 필요한지 구분할 수 있습니다.

# 맞는 경우와 다시 검토할 경우

| 파일 보정으로 진행하기 좋은 경우 | 원본부터 다시 볼 경우 |
| --- | --- |
| 작은 틈이나 중복 면이 몇 곳인 파일 | 전체에 자체 교차가 반복되는 파일 |
| 원본과 보정 결과를 비교할 수 있는 파일 | 기준 치수와 단위를 알 수 없는 파일 |
| 분리할 부품이 명확한 조립 파일 | 내부 형상을 확인할 자료가 없는 파일 |
| STEP 원본을 함께 받은 경우 | 얇은 면만 있고 두께가 없는 표면 모델 |

# 담당자가 확인할 것

1. **사용한 단위를 적습니다.** mm인지 inch인지 파일과 함께 보냅니다.
2. **기준 치수 3곳을 표시합니다.** 전체 크기와 구멍 간 거리를 확인합니다.
3. **STEP 원본을 함께 보냅니다.** 수정과 재변환 시간을 줄일 수 있습니다.
4. **부품 개수를 알립니다.** 붙일 셸과 분리할 셸을 구분합니다.
5. **수정하면 안 되는 면을 표시합니다.** 유로와 조립면을 보호합니다.

# 자주 묻는 질문

## STL이 뷰어에서 열리면 정상 파일 아닌가요

뷰어는 열린 면이나 겹친 면도 화면에 표시할 수 있습니다. 슬라이서가 닫힌 부피를 계산할 수 있는지는 별도로 검사해야 합니다.

## 자동 보정하면 형상이 달라지나요

작은 틈을 닫는 정도로 끝날 수 있습니다. 오류가 크면 구멍이나 얇은 틈이 사라질 수 있어 보정 전후 비교가 필요합니다.

## STL만 있어도 출력 견적을 받을 수 있나요

형상과 크기를 읽을 수 있으면 1차 검토가 가능합니다. 치수 수정이나 오류가 발견되면 STEP 원본이나 기준 치수를 추가로 요청할 수 있습니다.

## 삼각형 수가 많을수록 좋은가요

너무 적으면 곡면이 각져 보입니다. 지나치게 많으면 파일만 무거워질 수 있으므로 필요한 표면 품질에 맞춰 변환해야 합니다.

STL 보정의 목표는 경고 문구를 없애는 데 있지 않습니다. 설계자가 의도한 구멍과 면을 남긴 채 닫힌 입체를 만드는 데 있습니다. 원본과 기준 치수를 함께 보내면 확인할 곳을 먼저 정할 수 있습니다.
