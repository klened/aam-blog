SLS 3D프린팅에서 가장 많이 쓰는 소재가 나일론 12(PA12)와 나일론 11(PA11)입니다. 둘 다 나일론이라 비슷해 보이지만 특성이 다릅니다.

**어느 쪽이 맞는지는 부품이 정합니다.**

# 핵심 차이

| 항목 | PA12 | PA11 |
| --- | --- | --- |
| 원료 | 석유 기반 | 피마자유 기반 (바이오) |
| 인장 강도 | 약 48 MPa | 약 46 MPa |
| 파단 연신율 | 약 11% | 약 40% |
| 충격 강도(아이조드) | 약 32 J/m | 약 110 J/m |
| 열변형 온도(HDT) | 약 175°C | 약 180°C |
| 치수 안정성 | 우수 (수축 적음) | 보통 (PA12보다 수축 큼) |
| 흡습성 | 낮음 | PA12보다 약간 높음 |
| 가격 | 상대적으로 낮음 | PA12보다 약 20~30% 높음 |

**파단 연신율이 가장 큰 차이입니다.** PA11은 PA12보다 약 4배 더 늘어납니다. 충격 강도는 약 3배입니다.

![같은 형상의 PA12와 PA11 시편을 나란히 놓고 굽힘 차이를 비교하는 모습](/images/나일론11-나일론12-비교/2.webp)

# 이 부품이면 PA12

| 용도 | 이유 |
| --- | --- |
| 조립 검증용 시제품 | 치수가 정확합니다. 조립 확인에 좋습니다 |
| 하우징·케이스 | 표면이 깨끗하고 치수 안정성이 좋습니다 |
| 정밀 지그·고정구 | 반복 사용 중 치수 변화가 적습니다 |
| 대량 적재(소량 양산) | 단가가 PA11보다 낮습니다 |
| 고온 환경 부품 | 내열성이 좋고 흡습이 적습니다 |

치수 정확도와 비용을 우선하면 PA12를 검토합니다.

![PA12로 출력한 하우징 여러 개의 치수와 조립 상태를 확인하는 엔지니어](/images/나일론11-나일론12-비교/3.webp)

# 이 부품이면 PA11

| 용도 | 이유 |
| --- | --- |
| 스냅핏·래치 | 반복 탈착에 유리합니다 |
| 충격 받는 부품 | PA12보다 충격에 잘 견딥니다 |
| 힌지·리빙힌지 | 유연해서 반복 굴곡에 버팁니다 |
| 보호 케이스·범퍼 | 충격 흡수가 필요한 곳에 맞습니다 |
| 의수·보조기 장치 | 착용 중 충격에 따른 파손 위험을 줄입니다 |

충격을 견디거나 반복해서 구부러져야 하면 PA11을 검토합니다.

![PA11로 출력한 스냅핏 고리를 반복해서 구부려 확인하는 모습](/images/나일론11-나일론12-비교/4.webp)

# 비용 비교

| 항목 | PA12 | PA11 |
| --- | --- | --- |
| 분말 가격 | 기준 | PA12 대비 약 20~30% 높음 |
| 출력 단가 | 낮음 | 보통 |
| 재활용률 | 약 50% | 약 30~40% |

PA12는 미사용 분말 재활용률이 높습니다. 같은 양의 분말로 더 오래 씁니다. PA11은 재활용률이 조금 낮아 분말 소모가 빠릅니다.

**비용만 보면 PA12가 유리합니다.** PA11을 쓸 이유가 있으려면 부품에 내충격성이나 유연성이 필요해야 합니다.

![SLS 장비에서 여러 나일론 부품의 분말을 제거하는 배치 생산 현장](/images/나일론11-나일론12-비교/5.webp)

# 표면과 후처리

| 항목 | PA12 | PA11 |
| --- | --- | --- |
| 출력 직후 표면 | 약간 거친 분말 질감 | PA12와 비슷 |
| 염색 | 잘 됩니다 | 잘 됩니다 |
| 증기 연마 | 가능 (표면 매끄러워짐) | 가능 |
| 도장 | 가능 | 가능 |

표면은 둘 다 비슷합니다. 후처리 방법도 같습니다. 표면 때문에 소재를 바꿀 필요는 없습니다.

후처리 종류와 비용은 [후처리 종류와 언제 필요한가](/blog/3d프린팅-후처리-종류/)에 정리했습니다.

# 둘 다 되는 경우

부품에 따라 PA12와 PA11 둘 다 가능한 경우가 있습니다.

| 상황 | 추천 |
| --- | --- |
| 떨어뜨릴 일이 없는 내부 부품 | PA12 (가격·치수 유리) |
| 현장에서 다루는 공구·지그 | PA11 (떨어뜨려도 안 깨짐) |
| 정밀 조립이 핵심인 시제품 | PA12 (치수 안정성) |
| 착용하거나 몸에 닿는 부품 | PA11 (충격에 안전) |
| 비용이 가장 중요한 소량 양산 | PA12 (단가 낮음) |

확실하지 않으면 같은 부품을 PA12·PA11 각각 뽑아 비교하는 방법도 있습니다.

# 담당자가 확인할 것

1. **부품 용도**를 알려주십시오. 충격이 가해지는 환경이면 PA11, 아니면 PA12가 기본입니다.
2. **유연성이 필요한지** 확인합니다. 스냅핏·힌지가 있으면 PA11이 맞습니다.
3. **치수 공차**를 확인합니다. 조립 공차가 중요하면 PA12가 유리합니다.
4. **수량**을 알려주십시오. 수량이 많으면 PA12의 단가 이점이 커집니다.

# 자주 묻는 질문

## PA11이 바이오 소재라면 약하지 않나요

아닙니다. 바이오 기반은 원료가 식물성이라는 뜻이지 약하다는 뜻이 아닙니다. 위 표에 인용한 수치에서 PA11의 충격 강도는 PA12의 약 3배입니다.

## PA12로 스냅핏을 만들면 안 되나요

몇 번 탈착이면 됩니다. 하지만 반복 탈착하면 PA12는 깨질 수 있습니다. 파단 연신율이 PA11의 1/4 수준이라 반복 굴곡에 약합니다. 스냅핏이 핵심 기능이면 PA11을 쓰십시오.

## 두 소재를 섞어 쓸 수 있나요

한 부품에 섞을 수는 없습니다. 하지만 조립품에서 부품별로 소재를 나누는 것은 가능합니다. 외장은 PA11, 내부 구조는 PA12로 나눠 뽑는 경우가 있습니다.

부품 용도와 도면을 알려주시면 어느 소재가 맞는지 확인해 드립니다.
