*베이퍼 스무딩과 표면의 수밀성을 설명하기 위한 이미지입니다.*

SLS로 만든 부품에 물을 담으면 새는 경우가 있습니다. 겉보기에는 막혀 있어도 표면에 미세한 기공이 남을 수 있기 때문입니다.

기공은 후처리로 줄일 수 있습니다. 다만 처리만으로 특정 방수 등급을 보장하지는 않습니다.

# 거친 표면 안에 미세한 틈이 있습니다

SLS는 분말을 레이저로 녹여 쌓습니다. 출력 직후 표면에는 덜 녹은 분말과 작은 요철이 남습니다.

눈에 보이는 거칠기만 문제가 아닙니다. 표면 가까이에 이어진 미세한 틈이 있으면 물, 오일, 공기가 스며들 수 있습니다.

아래 부품에서 먼저 확인해야 합니다.

- 액체나 기체가 지나는 매니폴드
- 내부에 압력이 걸리는 하우징
- 세척해서 반복 사용하는 지그
- 오염이 남으면 안 되는 격자 구조

# 베이퍼 스무딩은 표면을 다시 흐르게 합니다

표면층을 얇게 녹입니다. 부품을 제어된 증기 환경에 넣으면 요철이 완만해집니다. 열린 기공도 줄어듭니다. 공정 뒤에는 표면이 다시 굳습니다.

AMT는 PostPro가 표면을 매끄럽고 밀봉된 상태로 만든다고 설명합니다. 내수성도 좋아집니다. SLS와 MJF의 PA11, PA12, TPU 등은 대표적인 적용 소재입니다.

깎아내는 사포와는 방식이 다릅니다. 증기가 닿는 면 전체를 처리하므로 손이 들어가지 않는 내부와 격자에도 적용할 수 있습니다.

# 형상이 복잡할수록 차이가 큽니다

격자, 내부 유로, 깊은 홈은 사람이 모든 면을 연마하기 어렵습니다. 텀블링은 얇은 구조에 충격을 줄 수 있습니다.

조건은 형상마다 다릅니다. 증기가 고이거나 빠져나오기 어려운 구조는 부품 방향과 공정 조건을 조정해야 합니다. 작은 구멍과 빠듯한 끼움은 시험 처리가 필요합니다.

# 표면이 닫히면 달라지는 것

| 변화 | 기대할 수 있는 효과 |
| --- | --- |
| 표면 기공 감소 | 액체와 기체의 침투가 줄어듭니다 |
| 거칠기 감소 | 오염이 덜 남고 세척하기 쉬워집니다 |
| 전체 면 처리 | 내부 유로와 격자도 같은 공정으로 다룰 수 있습니다 |
| 표면 균일화 | 도색과 염색의 바탕을 일정하게 만들 수 있습니다 |

치수 변화는 공정과 소재, 형상에 따라 확인해야 합니다. 공차가 빠듯하면 1개를 처리해 전후 치수를 재는 편이 확실합니다.

# 맞는 경우와 다시 검토할 경우

| 잘 맞는 경우 | 다시 검토할 경우 |
| --- | --- |
| 액체나 기체가 지나는 나일론 부품 | 소재가 공정과 맞지 않는 경우 |
| 세척해서 반복 사용하는 부품 | 작은 구멍과 끼움 공차가 매우 빠듯한 경우 |
| 사포가 닿지 않는 격자와 내부 유로 | 증기가 빠져나오기 어려운 막힌 내부 구조 |
| 손에 자주 닿는 최종 사용 부품 | 방수·기밀 등급이 납품 조건인 경우 |

마지막 조건은 별도 시험이 필요합니다. 표면이 닫히는 공정 원리와 IP 등급이나 압력 시험의 합격은 다른 판단입니다.

# 담당자가 확인할 것

1. **통과하는 물질을 적습니다.** 물, 오일, 공기, 약품은 조건이 다릅니다.
2. **온도와 압력을 확인합니다.** 상온 세척과 압력 유로는 시험 범위가 다릅니다.
3. **소재를 확인합니다.** PA11, PA12, TPU 등 장비별 호환성을 봅니다.
4. **필수 치수와 작은 구멍을 표시합니다.** 1개 시험 처리 후 측정할 수 있습니다.
5. **요구 규격을 전달합니다.** 시험 압력, 시간, 합격 기준을 제작 전에 정합니다.

소재 선택이 먼저 필요한 경우에는 [방수 하우징을 3D프린팅할 때 어떤 소재가 좋을까](/blog/방수-하우징-소재-비교/)를 함께 확인하십시오.

# 자주 묻는 질문

## 베이퍼 스무딩을 하면 완전히 방수가 되나요

표면 기공이 줄어 물이 덜 스며듭니다. 특정 방수 등급이나 압력 조건은 완성 부품으로 시험해야 합니다.

## 부품 안쪽도 처리되나요

증기가 드나들 수 있는 구조라면 안쪽 면에도 닿습니다. 막힌 공간과 매우 좁은 유로는 형상을 확인한 뒤 가능 여부를 판단합니다.

## 치수가 줄어드나요

표면층이 다시 흐르는 공정이라 변화가 생길 수 있습니다. 공차가 빠듯한 부품은 1개를 처리해 전후 치수를 확인합니다.

## 모든 SLS 소재에 적용할 수 있나요

아닙니다. 소재와 공정 장비의 호환성을 확인해야 합니다. 복합 소재도 충전재와 조건에 따라 결과가 달라질 수 있습니다.

기밀성은 표면 마감으로 확정하지 않습니다. 사용 조건을 정하고 시험 결과로 확인해야 합니다.
