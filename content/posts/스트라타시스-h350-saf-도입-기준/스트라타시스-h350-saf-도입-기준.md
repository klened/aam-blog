**그 지점부터 H350입니다.** 스트라타시스의 SAF 방식 분말 양산 장비이고, Fuse 위 단계입니다.

# SAF는 SLS와 무엇이 다른가

Fuse는 **레이저**로 분말을 한 점씩 녹입니다. SAF(H350)는 다릅니다. 층 전체에 적외선 흡수액을 분사한 뒤 **적외선 램프로 한 번에 융착**합니다. HP의 MJF와 원리가 비슷합니다.

이 차이가 양산에서 값을 합니다.

- **시간이 고정됩니다.** 부품이 1개든 300개든 한 층을 굳히는 시간이 같습니다. 개수가 늘어도 시간이 안 늘어납니다.
- **일관성이 높습니다.** 조형판 어디에 놓든, 여러 대에서 뽑든 같은 치수가 나옵니다.
- **네스팅이 촘촘합니다.** 조형통을 40% 넘게 채워도 품질이 유지됩니다. 한 번에 더 많이 뽑습니다.

SLS와 MJF, SAF의 원리 차이는 [SLS와 MJF, 둘 다 나일론인데 뭐가 다른가](/blog/sls-mjf-차이/)에 정리했습니다.

# Fuse와 H350, 정면 비교

![H350 SAF로 양산한 PP 부품](/images/스트라타시스-h350-saf-도입-기준/2.webp)

같은 분말 방식이지만 자리가 다릅니다.

| 항목 | 폼랩 Fuse 1+ 30W | 스트라타시스 H350 (SAF) |
| --- | --- | --- |
| 방식 | 레이저 SLS | SAF (적외선 융착) |
| 자리 | 벤치탑·진입·다품종 | 산업 양산·시리즈 생산 |
| 조형 크기 | 165 × 165 × 300mm | 315 × 208 × 293mm |
| 생산성 | 부품마다 레이저가 스캔 | 고정 시간, 빌드당 수백 개 |
| 분말 처리 | Fuse Sift로 수동 회수 | PowderEase 자동, 1인이 여러 대 |
| 소재 | PA12·11·CF·GF·TPU | PA12·PA11·PP·ReLife |
| 맞는 물량 | 같은 부품 수십 개까지 | 같은 부품 수백~수천 개 |

**운영 방식이 특히 다릅니다.** Fuse는 출력 뒤 Fuse Sift로 분말을 회수합니다. H350은 PowderEase가 부품 분리·체질·투입을 자동으로 하므로 **한 사람이 여러 대를 돌립니다.** 양산에서는 이 운영비 차이가 큽니다.

# 사양·생산성을 실무 기준으로 옮기면

| 항목 | 값 | 실무에서 뜻하는 것 |
| --- | --- | --- |
| 조형 크기 | 315 × 208 × 293mm | 빌드당 소형 부품 수백 개 |
| 생산성 | 빌드당 수백 개 · 12시간 내 | 개수와 무관하게 고정 시간 |
| 일관성 | 빌드·장비 간 동일 | 여러 대로 늘려도 품질이 같습니다 |
| 분말 운영 | PowderEase 자동화 | 1인이 여러 대, 폐기물 최소 |
| 소프트웨어 | GrabCAD Print Pro | 네스팅·두께 분석으로 단가 최적화 |

양산에서 개당 단가를 정하는 것은 **네스팅(한 통에 몇 개를 넣느냐)**입니다. 같은 원리를 소량에서 보는 법은 [100개 견적은 1개의 100배가 아닙니다](/blog/3d프린팅-소량생산-단가/)에, 반복 주문의 품질을 맞추는 법은 [첫 주문과 다음 주문을 같게 맞추는 법](/blog/3d프린팅-반복-생산/)에 정리했습니다.

# 어떤 부품이 H350으로 가나

같은 부품을 꾸준히, 많이 쓰는 자리에 맞습니다.

- **로봇 그리퍼·엔드이펙터** — 가볍고 자주 바꾸는 [로봇 그리퍼](/blog/로봇-그리퍼-3d프린팅/)
- **와이어 하네스 지그·검사 고정구** — 라인마다 다른 대량 지그
- **맞춤 보조기구** — 환자마다 다른 [보조기구를 양산](/blog/맞춤-보조기구-3d프린팅/)
- **소형 커넥터·클립·브라켓** — [개당 단가를 낮춘 소형 부품 양산](/blog/sls-소형-클립-생산-사례/)

금형 없이 소량~중량을 넘기는 방법 전체는 [금형 없이 소량 생산하는 3가지 방법](/blog/금형-없이-소량-생산/)에 있습니다. 스트라타시스 계열 전체에서 SAF의 자리는 [스트라타시스 산업용 3D프린터, 언제부터 필요한가](/blog/스트라타시스-산업용-3d프린터/)에 정리했습니다.

# 가격은 어떻게 잡나

H350은 공개 정가가 없습니다. 소재 구성, 분말 자동화 장비(PowderEase), 서비스 계약이 함께 묶이고 환율도 타기 때문입니다. **만들 부품과 소재, 연간 수량을 알려주시면 구성과 견적을 함께 잡아 드립니다.**

견적을 받기 전에 회수 기준을 잡아 보시면 판단이 빨라집니다.

1. 같은 부품을 연간 몇 개 뽑는지 셉니다.
2. 지금 그 부품을 어떻게(외주·Fuse·사출) 만드는지, 개당 얼마인지 셉니다.
3. H350의 네스팅으로 개당 단가가 얼마까지 내려가는지 잡습니다.
4. 그 물량이 H350 한 대의 가동률을 채우는지 봅니다.

물량이 적으면 회수가 어렵습니다. 사는 쪽이 맞는지부터 검토 중이시면 [3D프린터, 사는 게 맞는 경우 3가지](/blog/3d프린터-구매-출력대행-비교/)를 먼저 보시면 됩니다.

# 사기 전에 확인할 것

1. **같은 부품의 연간 물량**을 셉니다. 수십 개면 [Fuse](/blog/폼랩-fuse1-도입-기준/)로 충분합니다.
2. **일관성 요구가 있는지** 봅니다. 여러 대·여러 빌드에서 같은 치수가 필요하면 H350입니다.
3. **소재**를 정합니다. PP나 재생 소재가 필요하면 SAF가 유리합니다.
4. **분말 운영 여건**을 봅니다. 자동화(PowderEase) 공간과 환기, 담당자를 확인합니다.
5. **우리 부품으로 시험 출력**을 받아봅니다.

5번이 가장 확실합니다. 파일을 보내주시면 H350으로 뽑은 실물과 개당 단가를 함께 드립니다. 지금 만드는 방식과 나란히 놓으면 판단이 빨라집니다.

# 자주 묻는 질문

:::faq
Fuse와 H350 중 무엇을 사야 하나요
물량과 일관성으로 정해집니다. 다품종을 소량씩 뽑으면 Fuse입니다. 같은 부품을 수백~수천 개, 여러 대에서 같은 품질로 뽑아야 하면 H350입니다. 둘 다 필요하면 Fuse로 시작해 물량이 오를 때 H350으로 올리는 방법이 있습니다.
:::

:::faq
SAF는 SLS·MJF와 무엇이 다른가요
분말을 굳히는 방법이 다릅니다. SLS는 레이저로 한 점씩, MJF와 SAF는 흡수액을 뿌린 뒤 적외선으로 층 전체를 한 번에 굳힙니다. SAF는 스트라타시스 방식으로, 높은 네스팅과 빌드·장비 간 일관성을 강점으로 내세웁니다.
:::

:::faq
H350으로 PP를 양산할 수 있나요
됩니다. SAF는 PP를 다룹니다. 내약품성이 있고 1mm 벽에서도 누수 없이 기밀이 나옵니다. 사출에서 쓰던 PP 부품을 금형 없이 소량~중량으로 만드는 데 씁니다.
:::

:::faq
물량이 많지 않은데 H350이 필요한가요
아닙니다. 같은 부품이 수십 개 수준이면 Fuse나 출력대행이 낫습니다. H350은 가동률을 채워야 개당 단가가 값을 합니다. 연간 물량을 알려주시면 어느 쪽이 유리한지 계산해 드립니다.
:::

:::faq
사기 전에 우리 부품으로 샘플을 받을 수 있나요
가능합니다. 파일을 보내주시면 H350으로 출력한 샘플과 개당 단가를 함께 드립니다. 표면·강도·정밀도와 네스팅에 따른 단가를 직접 확인하신 뒤 정하시면 됩니다.
:::
