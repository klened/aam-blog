![기술자가 검은색 3D프린팅 하우징에 황동 나사 인서트를 삽입하는 모습](/images/3d프린팅-나사산-인서트/1.webp)

하우징을 한 번 조립했을 때는 문제가 없습니다. 나사를 여러 번 풀고 조이면 플라스틱 나사산이 닳거나 보스가 깨질 수 있습니다.

직접 출력할지 인서트를 넣을지는 나사 규격보다 쓰는 횟수와 조임 힘으로 정합니다.

# 체결 방법은 4가지입니다

| 방법 | 잘 맞는 용도 | 먼저 볼 조건 |
| --- | --- | --- |
| 나사산 직접 출력 | 큰 규격, 가벼운 체결, 형상 확인 | 출력 방향과 최소 형상 |
| 파일럿 구멍 후 탭 가공 | 소량 시제품, 공구가 닿는 구멍 | 보스 두께와 칩 제거 |
| 금속 인서트 | 반복 조립, 일정한 체결력 | 삽입 방식과 열·압력 |
| 캡처 너트 | 큰 힘, 현장에서 교체할 체결부 | 너트 삽입 공간과 빠짐 방지 |

Stratasys의 SAF 설계 지침도 출력 나사산을 가벼운 용도로 설명하고, 기능 체결에는 금속 인서트를 검토하도록 안내합니다. 어떤 방식이든 첫 부품에서 실제 나사로 확인해야 합니다.

![직접 출력·탭 가공·금속 인서트·캡처 너트 체결 방식을 나란히 비교한 시편](/images/3d프린팅-나사산-인서트/2.webp)

# 직접 출력한 나사산이 맞는 경우

나사산이 크고 한두 번만 조립하는 시제품이라면 직접 출력할 수 있습니다. 부품 수가 줄고 별도 하드웨어가 필요하지 않습니다.

작은 나사산은 층과 표면 거칠기의 영향을 크게 받습니다. 나사가 처음부터 비스듬히 들어가면 입구가 손상됩니다. 체결 방향과 출력 방향도 함께 봐야 합니다.

직접 출력은 형상 확인에 유리합니다. 내구 시험을 통과했다는 뜻은 아닙니다.

![큰 출력 나사산과 작은 출력 나사산에 실제 나사를 체결해 보는 모습](/images/3d프린팅-나사산-인서트/3.webp)

# 반복 조립에는 금속 체결부를 봅니다

인서트는 플라스틱 안에 금속 나사산을 만듭니다. 커버를 정비할 때마다 여닫거나 일정한 조임 힘이 필요한 곳에 적합합니다.

열 삽입 인서트는 가열한 인서트를 열가소성 부품에 넣습니다. 압입형과 접착형은 소재와 형상에 맞춰 선택합니다. 레진 부품에 열 삽입 방식을 그대로 적용하면 균열이나 변형이 생길 수 있습니다.

캡처 너트는 일반 금속 너트를 부품 안에 가둡니다. 큰 힘을 받거나 너트를 교체해야 할 때 유리합니다. 대신 너트를 넣을 통로와 공구 공간이 필요합니다.

![3D프린팅 지그의 캡처 너트 홈에 육각 너트를 삽입하는 모습](/images/3d프린팅-나사산-인서트/4.webp)

# 보스 설계가 체결력을 좌우합니다

인서트만 정해도 끝나지 않습니다. 인서트 둘레에 충분한 재료가 있어야 하고, 보스 뿌리에는 급격한 모서리를 피해야 합니다.

| 설계 항목 | 확인할 이유 |
| --- | --- |
| 보스 바깥지름 | 인서트 삽입 중 벽이 벌어지는 것을 줄입니다 |
| 바닥 두께 | 나사가 깊게 들어가 반대쪽을 뚫지 않게 합니다 |
| 모서리 연결 | 체결 하중이 뿌리에 집중되는 것을 줄입니다 |
| 공구 접근 | 인서트와 나사를 수직으로 넣을 공간을 확보합니다 |

공차도 필요합니다. 구멍이 너무 작으면 보스가 깨지고, 너무 크면 인서트가 헛돕니다. [끼워 맞추는 부품, 공차는 어떻게 잡나](/blog/3d프린팅-조립-공차/)에서 시험값을 정하는 방법을 확인할 수 있습니다.

![벽 두께가 다른 나사 보스를 토크 공구로 시험하는 모습](/images/3d프린팅-나사산-인서트/5.webp)

# 첫 부품에서 확인할 것

1개를 먼저 출력해 인서트를 삽입합니다. 그 뒤 실제 나사와 공구로 조립과 분해를 반복합니다. 필요한 조임 힘이 정해져 있다면 토크 조건도 기록합니다.

나사 규격만 같아도 인서트 제조사와 형상에 따라 권장 구멍이 다릅니다. 사용하려는 인서트 실물을 기준으로 구멍을 설계하는 편이 정확합니다.

# 맞는 경우와 다시 검토할 경우

| 직접 출력하거나 인서트를 쓰기 좋은 경우 | 먼저 다시 검토할 경우 |
| --- | --- |
| 형상 확인용으로 1~2번 조립하는 시제품 | 안전 기능을 맡는 고하중 체결부 |
| 공구가 수직으로 접근하는 보스 | 얇은 벽 끝에 인서트가 있는 구조 |
| 실제 나사와 인서트로 시험할 수 있는 부품 | 고온에서 조임 힘을 계속 유지해야 하는 부품 |
| 마모 시 인서트를 교체할 수 있는 지그 | 체결 토크 성적이 규격으로 필요한 납품 부품 |

소재 선택은 별도 판단입니다. [나사 체결 부품을 3D프린팅할 때 어떤 소재가 좋을까](/blog/나사-체결-소재-비교/)에서 나일론과 레진, 고성능 열가소성 수지를 비교했습니다.

# 담당자가 확인할 것

1. **조립 횟수를 적습니다.** 1회 조립인지 정비 때마다 여는지 구분합니다.
2. **나사와 인서트 규격을 정합니다.** 실물을 함께 준비하면 확인이 빠릅니다.
3. **필요한 조임 힘을 확인합니다.** 손 조임과 토크 공구 사용을 구분합니다.
4. **보스 주변 두께를 표시합니다.** 벽과 모서리까지 거리를 봅니다.
5. **삽입 공구 공간을 확보합니다.** 수직으로 접근할 수 있어야 합니다.

# 자주 묻는 질문

## 작은 나사산도 직접 출력할 수 있나요

공정과 방향에 따라 형상은 나올 수 있습니다. 반복 체결이나 정확한 조임 힘이 필요하면 탭 가공이나 금속 인서트를 먼저 검토하십시오.

## 황동 인서트는 모든 소재에 넣을 수 있나요

삽입 방법이 다릅니다. 열가소성 수지는 열 삽입을 쓸 수 있지만 레진과 열에 약한 소재는 압입이나 접착, 캡처 너트를 따로 검토해야 합니다.

## 셀프 태핑 나사를 바로 조여도 되나요

소량 시제품에는 쓸 수 있습니다. 반복 조립하면 구멍이 마모될 수 있어 시험 횟수와 교체 가능성을 확인해야 합니다.

## 인서트 구멍은 도면 규격대로 출력하면 되나요

인서트 제조사가 제시한 홀 조건을 먼저 봅니다. 출력 공정의 치수 차이를 반영하려면 후보 구멍을 시험한 뒤 보정하는 편이 안전합니다.

나사산 선택의 기준은 처음 체결되느냐가 아닙니다. 필요한 횟수만큼 풀고 조여도 기능을 유지해야 합니다. 나사와 인서트 규격, 조립 횟수를 알려주면 시험할 체결 방식을 좁힐 수 있습니다.
