*나일론으로 자주 만드는 기능성 부품을 나타낸 설명용 이미지입니다.*

기능성 부품에 가장 많이 쓰는 3D프린팅 플라스틱이 나일론(PA)입니다. 질기고, 반복해서 구부러져도 버티고, 기름과 약품에 강합니다.

먼저 결론입니다. **나일론은 SLS·MJF·FDM 3가지로 뽑고, 대부분 PA12가 기본입니다.** 무엇을 정해야 하는지는 소재 이름이 아닙니다. 용도와 수량입니다. 이 둘을 들으면 공정과 등급이 따라옵니다.

AAM은 나일론을 SLS와 FDM으로 직접 뽑고, 소량 양산은 MJF로 갑니다.

# 왜 나일론이 기능성 부품의 기본인가

플라스틱마다 강점이 다릅니다. 나일론은 한쪽으로 치우치지 않습니다.

- **질깁니다.** 잘 안 깨지고 반복 하중에 버팁니다.
- **구부러졌다 돌아옵니다.** 스냅핏이나 힌지에 맞습니다.
- **기름·약품에 강합니다.** 공장 환경에서 오래 갑니다.

그래서 클립, 스냅핏, 덕트, 브래킷, 지그처럼 실제로 쓰는 부품에 두루 들어갑니다.

# 공정 3가지 — SLS·MJF·FDM

같은 나일론이라도 뽑는 방식이 다릅니다. 형상과 수량으로 정해집니다.

| 공정 | 방식 | 강점 | 잘 맞는 것 |
| --- | --- | --- | --- |
| SLS | 분말을 레이저로 소결 | 서포트가 없어 복잡한 형상 · 사방으로 고른 강도 | 소량 다품종, 복잡한 기능 부품 |
| MJF | 분말에 결합제를 분사 | 표면이 촘촘하고 생산이 빠름 | 같은 부품 소량 양산 |
| FDM | 녹인 필라멘트를 쌓음 | 큰 부품을 싸게 · 단품에 유리 | 크고 단순한 단품 |

# 소재는 PA12가 기본, 충격이면 PA11

나일론 안에서도 등급이 나뉩니다. 대부분은 PA12로 충분합니다. 치수가 안정적이고 값이 낮습니다.

떨어뜨리거나 반복해서 탈착하는 부품이면 PA11을 봅니다. 충격 강도가 PA12의 약 3배입니다. 두 소재를 부품별로 고르는 기준은 [나일론 11과 나일론 12, 어디에 무엇을 쓰는가](/blog/나일론11-나일론12-비교/)에 있습니다.

강성이 더 필요하면 섬유를 섞습니다. 큰 지그가 힘을 받아 휘는 경우입니다. [섬유를 섞은 소재는 언제 쓰나](/blog/카본파이버-소재/)에 정리했습니다.

| 덕트·매니폴드 | 복잡한 유로를 한 덩어리로 뽑습니다 | [흡기 매니폴드 시험 사례](/blog/sls-흡기-매니폴드-시험-사례/) |

# 맡길 때 넘기면 되는 것

**도면이 없어도 됩니다.** 실물이나 샘플에서 역설계로 데이터를 먼저 만듭니다. 준비할 것과 비용은 [도면 없는 부품, 역설계 비용은 얼마인가](/blog/역설계-비용-사례-4건/)에 있습니다.

| 넘기는 것 | 왜 필요한가 |
| --- | --- |
| 부품 용도 | 클립인지 덕트인지로 공정이 정해집니다 |
| 충격 여부 | 떨어뜨리는 부품이면 PA11로 갑니다 |
| 수량 | 소량 다품종은 SLS, 소량 양산은 MJF입니다 |
| 실물 또는 도면 | 없으면 역설계로 만듭니다 |

| 구분 | 내용 |
| --- | --- |
| 맞는 경우 | 복잡한 기능 부품 / 반복 탈착·굴곡 / 기름·약품에 닿음 / 소량 다품종 |
| 다시 봐야 합니다 | **완전 투명이 필요** — [투명 레진](/blog/투명-3d프린팅-부품-소재-비교/)을 봅니다 / **200°C 초과** — [ULTEM·PEEK](/blog/ultem-peek-3d프린팅-사례-4건/)로 갑니다 / **거울처럼 매끈한 면** — 후가공이 붙습니다 / **수천 개 이상** — 사출과 비교합니다 |

나일론 표면은 분말 질감이 남습니다. 증기 연마나 염색으로 정리하지만, 광택 면이 필요하면 후처리를 계산에 넣으셔야 합니다.

# 담당자가 확인할 것

1. **부품 용도**를 알려주십시오. 클립·덕트·지그인지로 공정이 좁혀집니다.
2. **충격을 받는지** 봅니다. 받으면 PA11, 아니면 PA12가 기본입니다.
3. **수량**을 정합니다. 소량 다품종은 SLS, 같은 부품 소량 양산은 MJF입니다.
4. **광택이 필요한 면**이 있는지 표시합니다. 후처리가 따로 붙습니다.

# 자주 묻는 질문

:::faq
나일론이 왜 기능성 부품에 많이 쓰이나요
강도와 유연성, 내약품성이 한쪽으로 치우치지 않기 때문입니다. 클립이나 스냅핏처럼 휘었다 돌아와야 하는 구조에 맞습니다. SLS로 뽑으면 서포트가 없어 복잡한 형상도 한 번에 나옵니다.
:::

:::faq
SLS·MJF·FDM 중 무엇을 고르나요
형상과 수량으로 정해집니다. 복잡한 소량 다품종은 SLS, 같은 부품을 여러 개 뽑는 소량 양산은 MJF, 크고 단순한 단품은 FDM이 유리합니다. 부품과 수량을 알려주시면 골라 드립니다.
:::

:::faq
PA12와 PA11은 어떻게 다른가요
PA12가 기본입니다. 치수가 안정적이고 값이 낮습니다. 떨어뜨리거나 반복 탈착하는 부품이면 충격에 강한 PA11로 갑니다.
:::

:::faq
도면이 없어도 맡길 수 있나요
됩니다. 실물이나 샘플에서 역설계로 데이터를 만든 뒤 출력합니다. 용도와 수량을 함께 알려주시면 공정과 소재까지 잡아 드립니다.
:::

나일론으로 정했다면 남은 결정은 용도와 수량입니다. 이 둘을 들으면 공정과 나일론 등급이 정해집니다. 금형 없이 1개부터 실제 나일론으로 먼저 뽑아 기능을 현장에서 확인하시면 소량 양산 판단이 쉬워집니다.

클립부터 덕트, 지그까지 나일론 기능 부품을 뽑아 온 경험이 있습니다. 부품 사진과 쓰임, 수량을 알려주시면 공정과 소재를 함께 좁혀 드립니다.
