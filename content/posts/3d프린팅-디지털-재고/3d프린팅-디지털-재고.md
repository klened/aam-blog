*단종 부품을 디지털 재고로 전환하는 상황을 설명하기 위한 이미지입니다.*

디지털 재고는 STL 파일만 보관하는 일이 아닙니다. 같은 부품을 다시 만들려면 승인 파일과 소재·공정·후처리·검사 기준을 함께 남겨야 합니다. 지금 보관 중인 단종 부품 자료가 6가지 항목을 갖췄는지 확인하십시오.

# 창고에서 부품을 찾지 못할 때 시작합니다

![부품 창고에서 비어 있는 보관함과 남아 있는 단종 부품을 확인하는 엔지니어](/images/3d프린팅-디지털-재고/2.webp)

*부품 공급이 중단된 상황을 설명하기 위한 이미지입니다.*

설비는 계속 쓰는데 제조사가 부품 공급을 중단하는 경우가 있습니다. 서비스 부품 1개 때문에 최소 주문 수량을 맞추거나 몇 달을 기다리기도 합니다.

이때 모든 부품을 미리 쌓아둘 필요는 없습니다. 다시 만들 수 있는 부품은 승인된 제작 정보로 보관하고, 필요한 수량만 출력하는 방법을 검토할 수 있습니다.

Stratasys는 디지털 재고를 검증된 부품 파일로 물리 재고를 일부 대체하고 사용 장소와 가까운 곳에서 생산하는 방식으로 설명합니다. 다만 파일이 있다는 사실만으로 같은 부품이 자동으로 나오지는 않습니다.

# STL 파일만 남기면 다시 확인할 것이 많습니다

![STL 형상과 2D 도면, 주요 치수와 출력 부품을 함께 확인하는 엔지니어](/images/3d프린팅-디지털-재고/3.webp)

*STL 파일 외에 도면과 치수 기준이 필요한 이유를 설명하기 위한 이미지입니다.*

STL에는 주로 표면 형상이 들어 있습니다. 설계 치수와 공차, 소재 등급, 출력 방향, 후처리와 검사 기준은 별도로 남겨야 합니다.

| 파일만 남겼을 때 생기는 질문 | 함께 보관할 자료 |
| --- | --- |
| 어느 파일이 최종 승인본인가 | 파일명과 개정 번호 |
| 구멍과 끼움 치수는 얼마인가 | 2D 도면과 주요 치수 |
| 어떤 재료로 만들었나 | 소재 제조사와 정확한 등급 |
| 어느 방향으로 출력했나 | 공정·장비·출력 방향 |
| 색과 표면은 어떻게 맞췄나 | 후처리와 색상 기준 |
| 무엇을 측정해 합격시켰나 | 검사표와 승인 샘플 |

도면이 없는 부품은 실물에서 3D 데이터를 만들 수 있습니다. 다만 파손된 형상을 그대로 복사하지 않도록 상대 부품과 장착 위치를 함께 확인해야 합니다. 복원 순서는 [도면 없는 부품을 다시 만드는 방법](/blog/도면-없는-부품-제작/)에서 확인할 수 있습니다.

# 디지털 재고가 맞는 부품부터 고릅니다

![단종 부품 가운데 3D프린팅 대체 제작에 적합한 부품을 비교하는 엔지니어](/images/3d프린팅-디지털-재고/6.webp)

*디지털 재고에 등록할 부품과 추가 검토가 필요한 부품을 구분하는 상황을 설명하기 위한 이미지입니다.*

| 등록을 검토할 부품 | 먼저 다시 확인할 부품 |
| --- | --- |
| 단종됐지만 계속 사용하는 서비스 부품 | 안전과 법정 인증에 직접 영향을 주는 부품 |
| 주문 수량이 적고 사용 시점이 일정하지 않은 부품 | 금속 피로와 압력 수명을 입증해야 하는 부품 |
| 기존 납기가 길어 장기간 쌓아 두던 부품 | 설계가 계속 바뀌어 승인본이 없는 부품 |
| 형상과 검사 기준이 이미 확정된 부품 | 원본 권리와 제작 권한을 확인하지 못한 부품 |

모든 재고를 파일로 바꾸는 작업이 아닙니다. 보관 비용과 공급 중단 위험이 큰 부품부터 후보를 정해야 합니다. 부품 조달이 멈춘 뒤 3D프린팅을 검토하는 전체 순서는 [부품 조달이 막혔을 때 확인할 단계](/blog/부품-조달-3d프린팅-판단/)에서 볼 수 있습니다.

# 담당자가 확인할 것

![승인한 출력 부품과 소재 샘플, 검사표를 보관 상자에 정리하는 엔지니어](/images/3d프린팅-디지털-재고/7.webp)

*승인 파일과 제작 조건, 기준 부품을 함께 보관하는 마무리 절차를 설명하기 위한 이미지입니다.*

1. 현재 쓰는 부품 가운데 단종·장기 납기 품목을 먼저 고릅니다.
2. 부품 파일의 소유권과 다시 제작할 권한을 확인합니다.
3. STEP·STL·도면 가운데 남아 있는 자료를 모읍니다.
4. 시험 출력 1개로 조립과 주요 치수를 승인합니다.
5. 승인 파일과 소재·공정·후처리·검사 기준을 한 폴더에 묶습니다.

# 자주 묻는 질문

## STL 파일만 있으면 디지털 재고로 쓸 수 있나요

형상 확인과 시험 출력은 가능합니다. 반복 제작에 쓰려면 최종 승인 여부와 소재, 출력 방향, 후처리, 검사 기준을 추가로 남겨야 합니다.

## 도면이 없는 단종 부품도 등록할 수 있나요

실물 측정이나 3D 스캔으로 설계 데이터를 만들 수 있습니다. 파손 부위와 마모된 치수는 상대 부품과 정상 샘플을 보고 복원해야 합니다.

## 다른 출력업체에서도 같은 결과가 나오나요

파일만 전달하면 결과가 달라질 수 있습니다. 공정과 소재, 출력 방향, 후처리와 합격 기준까지 전달해야 업체가 바뀌어도 비교할 기준이 생깁니다.

## 승인한 뒤 소재가 단종되면 어떻게 하나요

대체 소재의 물성과 사용 조건을 비교한 뒤 시험 출력과 재승인을 진행해야 합니다. 소재 이름만 바꾸고 기존 승인 기록을 그대로 쓰면 안 됩니다.

단종 부품을 디지털 재고로 전환하려면 부품 사진과 남아 있는 도면·파일을 보내주세요. 담당 엔지니어가 복원 가능 여부와 시험 출력에 필요한 자료를 확인한 뒤 회신드리겠습니다.
