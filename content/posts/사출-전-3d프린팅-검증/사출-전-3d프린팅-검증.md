사출 금형은 비쌉니다. 간이 금형이 200만~500만 원, 양산 금형은 수천만 원입니다. 그런데 금형을 만든 뒤에 설계가 바뀌면 이 비용이 통째로 날아갑니다.

실제로 금형 수정은 흔합니다. 조립해보니 안 맞는다, 손에 쥐어보니 그립감이 다르다, 내부 부품이 간섭한다. 이런 문제는 도면으로는 알기 어렵습니다.

**금형을 파기 전에 3D프린팅으로 먼저 확인하면** 이 위험을 줄일 수 있습니다.

# 금형 수정이 비싼 이유

금형은 강철 덩어리를 정밀하게 깎아서 만듭니다. 한 번 깎은 형상을 되돌리기 어렵습니다.

| 수정 유형 | 비용 | 기간 |
| --- | --- | --- |
| 치수 미세 조정 | 30만~100만 원 | 3~5일 |
| 형상 변경 (일부) | 100만~300만 원 | 1~2주 |
| 설계 전면 변경 | 금형 재제작 | 3~6주 |

한 번 수정하면 비용과 일정이 함께 밀립니다. 두 번 수정하면 간이 금형 하나 값이 더 들 수 있습니다.

# 3D프린팅으로 검증할 수 있는 것

## 1단계: 형상 확인

가장 기본입니다. 화면 속 3D 모델을 실물로 만들어 손에 쥐어봅니다.

- 크기가 예상과 맞는가
- 곡면이 자연스러운가
- 손에 쥐었을 때 그립감이 맞는가
- 버튼 위치가 자연스러운가

**FDM으로 충분합니다.** 비용은 1만~10만 원, 납기는 당일~1일입니다. 정밀도를 따질 단계가 아닙니다. 가장 싼 방법이 맞습니다.

## 2단계: 조립 확인

부품이 여러 개인 제품이면 끼워봐야 합니다. 뚜껑이 닫히는지, 기판이 들어가는지, 나사 체결이 되는지를 확인합니다.

- 부품 간 간섭 여부
- 끼워 맞춤 공차
- 조립 순서와 작업성
- 커넥터·스위치와의 간섭

**SLA가 적합합니다.** FDM보다 정밀도가 높아 ±0.1mm 수준으로 맞출 수 있습니다. 비용은 3만~20만 원, 납기는 1~2일입니다.

조립 공차 설계가 처음이면 [3D프린팅 조립 공차 가이드](/blog/3d프린팅-조립-공차/)를 먼저 보시면 됩니다.

## 3단계: 기능 테스트

실제로 작동하는지 확인합니다. 기판을 넣고 전원을 켜보거나, 유체가 지나가는 부품에 물을 흘려봅니다.

- 내열성: 열이 가해지는 부품
- 내화학성: 약품에 닿는 부품
- 강도: 하중을 받는 브라켓
- 유연성: 스냅핏·래치 작동

**SLS 나일론이 가장 많이 쓰입니다.** PA12는 내열성과 강도가 높아 기능 테스트에 적합합니다. 비용은 5만~30만 원, 납기는 2~3일입니다.

강도가 더 필요하면 [카본파이버 소재](/blog/카본파이버-소재/)나 [출력 방향과 강도](/blog/출력-방향과-강도/)를 참고하시면 됩니다.

## 4단계: 소량 생산 테스트

금형 없이 10~50개를 만들어 시장에 내보는 단계입니다. 고객 반응을 확인하거나 전시회에 쓰는 용도입니다.

- 소량 선행 생산
- 전시용 샘플
- 고객 테스트 배포

이 수량이면 **진공주형**이 유리합니다. 3D프린팅으로 마스터 모델을 만들고 실리콘 틀을 떠서 복제합니다. 개당 단가가 3D프린팅 직접 출력보다 낮아지는 구간입니다.

비용은 [시제품 제작 비용](/blog/시제품-제작-비용/)에서 방법별로 비교했습니다.

# 검증 단계별 방식과 비용

| 단계 | 목적 | 방식 | 비용 (개당) | 납기 |
| --- | --- | --- | --- | --- |
| 형상 확인 | 크기·외관 | FDM | 1만~10만 원 | 당일~1일 |
| 조립 확인 | 끼워 맞춤·간섭 | SLA | 3만~20만 원 | 1~2일 |
| 기능 테스트 | 강도·내열·작동 | SLS | 5만~30만 원 | 2~3일 |
| 소량 생산 | 시장 테스트 | 진공주형 | 3만~15만 원 | 5~10일 |

4단계를 전부 거치는 경우도 있지만, 대부분은 **1~2단계면 금형 수정을 충분히 줄입니다.** 형상 확인 한 번에 10만 원이 들더라도 금형 수정 한 번(100만 원+)을 막으면 이득입니다.

# 사출용 설계를 3D프린팅할 때 주의할 점

사출과 3D프린팅은 설계 제약이 다릅니다. 사출용으로 설계한 파일을 그대로 3D프린팅하면 문제가 생기는 경우가 있습니다.

| 사출 설계 요소 | 3D프린팅에서의 차이 |
| --- | --- |
| 빼기 구배 (Draft angle) | 3D프린팅에서는 필요 없지만, 있어도 됩니다 |
| 균일 벽 두께 | 3D프린팅은 벽 두께 불균일에 덜 민감합니다 |
| 리브·보스 | 그대로 출력됩니다 |
| 언더컷 | 사출에서는 슬라이드 금형이 필요하지만, 3D프린팅은 그대로 뽑힙니다 |
| 게이트 위치 | 3D프린팅에서는 해당 없습니다 |

사출용 설계 파일을 3D프린팅 검증에 쓰는 것은 문제없습니다. 다만 **3D프린팅으로 OK가 나왔다고 사출에서도 OK인 것은 아닙니다.** 사출에서는 수축, 웰드 라인, 싱크 마크 같은 성형 고유의 문제가 추가됩니다.

3D프린팅 검증은 **설계 의도를 먼저 확인하는 단계**입니다. 사출 성형 자체의 검증은 간이 금형(시사출)으로 합니다.

# 실제 진행 순서

1. 3D 파일(STEP 또는 STL)을 준비합니다
2. 검증 목적을 정합니다 (형상·조립·기능)
3. 목적에 맞는 방식과 소재를 선택합니다
4. 시제품을 받고 확인합니다
5. 문제가 있으면 설계를 수정합니다
6. 필요하면 2~5를 반복합니다
7. 형상이 확정되면 금형 제작에 들어갑니다

이 과정에서 **3~5번이 비용을 절약하는 구간**입니다. 3D프린팅은 1~3일이면 수정본이 나오므로 빠르게 반복할 수 있습니다.

파일 형식이 맞는지 확인하려면 [3D프린팅 파일 형식 정리](/blog/3d프린팅-파일-형식-정리/)를 참고하시면 됩니다.

# 자주 묻는 질문

:::faq
3D프린팅 시제품으로 고객에게 보여줘도 되나요
됩니다. SLA로 출력하면 표면이 매끄럽고, 도장·도금까지 하면 양산품과 외관이 비슷해집니다. 전시회 샘플이나 투자 프레젠테이션에 쓰기 충분합니다.
:::

:::faq
사출 소재와 같은 물성으로 3D프린팅이 되나요
완전히 같지는 않습니다. 다만 PA12(나일론)는 사출 PA6/PA66과 비슷한 내열성·강도를 가집니다. ABS-Like 레진은 ABS와 비슷합니다. 기능 테스트 수준에서는 유사 물성으로 충분한 경우가 많습니다.
:::

:::faq
금형 없이 소량 양산이 가능한가요
가능합니다. 3D프린팅 직접 출력(1~30개)이나 진공주형(10~50개)으로 금형 없이 소량을 만들 수 있습니다. 시장 반응을 보고 금형 투자를 결정하는 방법입니다.
:::

:::faq
검증에 얼마나 걸리나요
형상 확인은 1~2일이면 됩니다. 조립 확인까지 포함하면 3~5일입니다. 설계 수정과 재출력을 2~3회 반복해도 2~3주면 끝납니다. 금형 제작 기간(3~6주)보다 짧습니다.
:::
