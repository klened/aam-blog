장비 부품이 하나 깨졌습니다. OEM에 주문하면 수 주가 걸립니다.

**라인이 서 있는 동안 기다릴 수 없습니다.** 3D프린팅으로 뽑으면 수일 안에 받을 수 있습니다.

# OEM 부품이 늦는 이유

| 상황 | 걸리는 것 |
| --- | --- |
| 단종 부품 | 더 이상 만들지 않습니다. 대체품을 찾아야 합니다 |
| 해외 OEM | 발주에서 입고까지 4~8주가 걸립니다 |
| 소량 주문 | 최소 수량이 있어 1개만 살 수 없습니다 |
| 설계 변경 | 장비를 개조했는데 원래 부품이 안 맞습니다 |

**네 경우 모두 3D프린팅으로 대응할 수 있습니다.** 도면이 있으면 그대로 뽑고, 없으면 실물을 [역설계](/blog/역설계-사례-4건/)해서 만듭니다.

# 정밀도와 소재

SLA는 치수 정확도 ±0.15%입니다. 센서 브래킷이나 정렬 지그처럼 위치가 중요한 부품에 맞습니다.

| 조건 | 방식·소재 | 이유 |
| --- | --- | --- |
| 정밀 브래킷 | SLA 레진 | ±0.15%. 표면이 매끄럽습니다 |
| 내약품성 | SLA 내화학 레진 | IPA, 아세톤에 버팁니다 |
| 내열 | ULTEM 9085 | 열변형온도 153°C. 고온 챔버 근처에 씁니다 |
| 강도·내구성 | SLS 나일론(PA12) | 반복 탈착에 버팁니다 |
| 투명 확인창 | SLA 투명 레진 | [투명 부품](/blog/투명-3d프린팅-부품-소재-비교/)으로 안을 봅니다 |

용도를 말씀해 주시면 소재를 같이 골라 드립니다. 어긋나면 모델만 고쳐 당일 다시 출력합니다.

# 클린룸 환경에서 주의할 것

클린룸 안에 넣는 부품은 두 가지를 확인해야 합니다.

| 항목 | 내용 |
| --- | --- |
| 아웃가싱 | 진공 환경에서 소재가 가스를 내뿜으면 안 됩니다. 소재 선택이 달라집니다 |
| 파티클 | SLS 표면에서 미세 분말이 떨어질 수 있습니다. 후처리로 표면을 막습니다 |

**클린룸 등급을 알려주십시오.** 등급에 따라 소재와 후처리가 달라집니다. 장비 바깥에서 쓰는 부품이면 이 제약이 없습니다.

# 맞는 경우와 다시 봐야 할 경우

| 구분 | 내용 |
| --- | --- |
| 잘 맞는 경우 | 단종 부품 대체 / 장비 개조 후 맞춤 부품 / 센서 브래킷·정렬 지그 / 시제품 단계 장비 조립 |
| 다시 봐야 할 경우 | **진공 챔버 내부** — 아웃가싱을 확인해야 합니다. 소재가 제한됩니다 / **전도성이 필요한 부품** — 일반 플라스틱은 전기가 통하지 않습니다. 전도성 소재를 봐야 합니다 / **수백 개 이상** — 사출이 개당 단가에서 이깁니다 |

# 담당자가 확인할 것

1. **도면이 있는지** 확인합니다. 없으면 실물을 보내주십시오. 역설계해 드립니다.
2. **장착 위치**를 알려주십시오. 클린룸 안인지 밖인지에 따라 소재가 달라집니다.
3. **주변 온도와 약품**을 확인합니다. 고온이나 약품이 있으면 내열·내화학 소재가 필요합니다.
4. **정밀도 요구**를 알려주십시오. ±0.1mm 이내가 필요하면 SLA가 맞습니다.

# 자주 묻는 질문

## 원래 부품과 똑같이 나오나요

역설계 정밀도에 따라 다릅니다. 3D 스캐너로 실물을 읽으면 형상은 거의 그대로 나옵니다. 소재가 다르므로 강도와 물성은 확인이 필요합니다.

## 금속 부품도 대체할 수 있나요

하중이 관건입니다. 구조적 하중이 크지 않은 부품이면 가능합니다. 브래킷이나 가이드는 나일론이나 ULTEM으로 대체한 사례가 있습니다. 하중이 크면 [금속 3D프린팅](/blog/금속-3d프린팅-사례-3건/)을 봐야 합니다.

## ESD 방지가 되나요

전도성 소재로 뽑으면 됩니다. 다만 선택할 수 있는 소재가 제한되므로 먼저 확인이 필요합니다.

먼저 정할 것은 소재가 아닙니다. **어디에 들어가는 부품인가**입니다. 위치가 정해지면 온도, 약품, 클린룸 등급이 따라오고 소재가 정해집니다.

도면이나 실물 사진을 보내주시면 방식을 잡아 드립니다.
