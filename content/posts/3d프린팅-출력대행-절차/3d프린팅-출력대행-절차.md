3D프린팅 출력대행은 파일을 보내고 기다리는 일로 끝나지 않습니다. 용도와 필수 치수를 먼저 확인해야 견적과 결과물이 맞습니다.

방식과 소재를 정해서 문의하실 필요는 없습니다. 무엇에 쓸 부품인지 알려주시면 출력업체가 후보를 좁힙니다.

# 출력대행은 5단계로 진행됩니다

| 단계 | 확인하는 것 | 결과 |
| --- | --- | --- |
| 1. 용도 확인 | 형상 확인용인지 실제 사용 부품인지 | 필요한 강도와 표면 수준을 정합니다 |
| 2. 자료 검토 | 3D 파일, 2D 도면, 실물, 사진 | 출력 가능 여부와 수정 범위를 확인합니다 |
| 3. 견적 확정 | 방식, 소재, 수량, 후처리, 납기 | 제작 범위와 금액을 확정합니다 |
| 4. 제작·검수 | 출력 방향, 후처리, 필수 치수 | 합의한 기준에 맞춰 제작합니다 |
| 5. 납품 | 포장, 배송, 수정 데이터 | 부품을 받고 다음 제작 조건을 남깁니다 |

## 1. 용도부터 확인합니다

같은 형상도 용도에 따라 방식이 달라집니다. 외관만 볼 목업과 장비 안에서 하중을 받는 부품은 같은 소재로 만들기 어렵습니다.

온도, 하중, 오일 접촉, 자외선 노출도 알려주셔야 합니다. 소재 이름을 모르셔도 됩니다. 사용 조건을 기준으로 FDM·SLA·SLS·MJF 같은 후보를 정합니다.

## 2. 자료를 검토합니다

STL이나 STEP 파일이 있으면 형상과 치수를 확인합니다. 꼭 지켜야 할 구멍과 결합면은 도면에 표시하는 편이 좋습니다.

도면이 없어도 시작할 수 있습니다. 실물, 사진, 손그림에서 3D 데이터를 만드는 방법이 있습니다. 이때는 모델링이나 역설계 비용이 견적에 추가됩니다. 파일별 차이는 [3D프린팅, 어떤 파일을 보내야 하나](/blog/3d프린팅-파일-형식-정리/)에서 확인할 수 있습니다.

## 3. 견적 범위를 확정합니다

금액만 보면 무엇이 포함됐는지 알기 어렵습니다. 견적서에는 아래 항목이 함께 있어야 합니다.

| 항목 | 확인할 범위 |
| --- | --- |
| 출력 | 방식, 소재명, 수량 |
| 후처리 | 서포트 제거, 세척, 연마, 스무딩, 도색 |
| 검수 | 필수 치수와 외관 기준 |
| 일정 | 제작 시작일과 수령 예정일 |
| 재작업 | 파일 변경이나 출력 불량이 생겼을 때 처리 기준 |

견적을 비교할 때는 포함 항목을 같은 기준으로 맞춰야 합니다. 업체별 차이는 [3D프린팅 업체 고를 때 확인할 3가지](/blog/3d프린팅-업체-선정-기준/)에 정리했습니다.

## 4. 출력하고 후처리합니다

출력 방향을 정합니다. 장비 배치도 함께 정합니다. 적층 방향은 강도와 표면에 영향을 줍니다. 필수 치수가 있으면 검수 방법도 제작 전에 합의해야 합니다.

출력이 끝나면 후처리합니다. 먼저 서포트를 제거하고 세척합니다. 용도에 따라 연마, 베이퍼 스무딩, 도색, 조립이 이어집니다. 필요한 작업은 [3D프린팅 후처리, 어디까지 해야 하나](/blog/3d프린팅-후처리-종류/)에서 고를 수 있습니다.

## 5. 납품 조건을 남깁니다

부품을 받은 뒤에는 조립과 기능을 확인합니다. 수정할 곳이 있으면 원본 데이터를 고쳐 다시 출력합니다.

조건을 기록합니다. 방식, 소재, 출력 방향, 후처리 조건입니다. 반복 주문에서도 같은 기준으로 제작할 수 있습니다.

# 일정과 금액이 달라지는 이유

단순 부품은 수일 안에 제작할 수 있는 경우가 많습니다. 정확한 일정은 형상과 수량을 검토한 뒤 견적서에서 안내합니다.

| 조건 | 일정과 금액에 미치는 영향 |
| --- | --- |
| 출력 가능한 3D 파일이 있음 | 바로 제작 검토를 시작할 수 있습니다 |
| 2D 도면이나 실물만 있음 | 모델링이나 역설계가 먼저 필요합니다 |
| 후처리가 많음 | 연마·도색·조립 기간이 추가됩니다 |
| 수량이 많음 | 장비 배치와 반복 생산 계획이 필요합니다 |
| 검사 기준이 있음 | 측정 항목과 합격 기준을 먼저 정해야 합니다 |

공개된 결제 사례도 있습니다. 역설계한 SLS 벽걸이 케이스 1개는 약 9만 원입니다. MJF로 출력한 역설계 부품 3개는 약 35만 원입니다. ULTEM·PEEK 부품 4개는 약 50만 원 사례가 있습니다.

금액은 참고용입니다. 크기보다 파일 상태와 소재, 수량, 후처리가 금액에 더 큰 영향을 주기도 합니다. 사례별 차이는 [같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)에서 확인할 수 있습니다.

# 맞는 경우와 다시 검토할 경우

| 잘 맞는 경우 | 다시 검토할 경우 |
| --- | --- |
| 시제품이나 부품이 1개부터 필요한 경우 | 같은 부품이 수백·수천 개 필요한 경우 |
| 설계를 수정하며 반복 제작하는 경우 | 금형이나 가공이 개당 단가에서 유리한 경우 |
| 내부 유로나 복잡한 형상이 있는 경우 | 규격 시험과 인증이 납품 조건인 경우 |
| 도면 없이 실물에서 시작하는 경우 | 수압·기밀·내구 시험 수치가 필요한 경우 |

3D프린팅이 가능하다는 판단과 납품 규격을 충족한다는 판단은 다릅니다. 시험 성적서나 소재 인증서가 필요하면 견적 전에 요구 조건을 확인해야 합니다.

# 담당자가 확인할 것

1. 부품을 **어디에 쓸지** 적습니다. 형상 확인인지 실제 사용인지 구분합니다.
2. 필요한 **수량과 날짜**를 확인합니다. 둘이 정해져야 방식과 배치를 검토할 수 있습니다.
3. STL·STEP·2D 도면·실물 중 **보유한 자료**를 확인합니다.
4. 구멍과 결합면처럼 **지켜야 할 치수**를 표시합니다.
5. 연마·도색·조립처럼 **필요한 후처리**를 정합니다.

문의 전에 준비할 항목은 [3D프린팅 견적 전에 정할 것 5가지](/blog/견적-전에-정할-것/)에서 자세히 확인할 수 있습니다.

# 자주 묻는 질문

## 방식과 소재를 정해서 문의해야 하나요

정하지 않으셔도 됩니다. 용도와 사용 조건을 알려주십시오. 온도, 하중, 접촉 물질에 맞춰 방식과 소재를 제안합니다.

## 3D 파일이 없어도 출력대행을 맡길 수 있나요

가능합니다. 2D 도면, 실물, 사진, 손그림을 기준으로 모델링하거나 역설계합니다. 데이터 제작 비용과 기간은 출력비와 별도로 확인합니다.

## 부품 1개만 제작할 수 있나요

가능합니다. 3D프린팅은 금형이 없어도 제작할 수 있어 1개 시제품에 잘 맞습니다. 수량이 많으면 사출이나 CNC와 비용을 비교합니다.

## 견적을 받으면 바로 출력이 시작되나요

방식, 소재, 수량, 후처리, 납기를 확정한 뒤 제작을 시작합니다. 결합 치수나 검사 기준이 있으면 출력 전에 함께 확정해야 합니다.

출력대행에서 먼저 정할 것은 장비 이름이 아닙니다. 부품의 용도와 반드시 지켜야 할 조건입니다.

파일과 수량, 필요한 날짜를 알려주시면 제작 가능한 범위부터 확인할 수 있습니다.
