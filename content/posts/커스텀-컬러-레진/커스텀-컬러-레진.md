SLA 3D프린팅 레진은 기본 색상이 정해져 있습니다. 흰색, 회색, 검정, 투명이 전부입니다.

**시제품을 실제 제품 색상으로 보고 싶으면 도색을 해야 했습니다.** 도색은 비용이 들고 시간이 걸립니다.

# 도색의 문제

| 문제 | 내용 |
| --- | --- |
| 추가 비용 | 도색비가 출력비만큼 나오는 경우도 있습니다 |
| 대기 시간 | 도색 후 건조까지 1~2일 추가됩니다 |
| 긁힘 | 도막이 벗겨지면 바탕색(흰색·회색)이 드러납니다 |
| 균일성 | 수작업 도색은 색 편차가 생깁니다 |
| 복잡한 형상 | 안쪽 면이나 좁은 틈은 도색이 어렵습니다 |

# 컬러 레진이란

베이스 레진에 색소(컬러 키트)를 섞어 원하는 색상을 만드는 방식입니다. 섞은 뒤 그대로 출력하면 됩니다.

| 항목 | 내용 |
| --- | --- |
| 베이스 레진 | 스탠다드 레진 (투명 또는 백색) |
| 컬러 키트 | 색소 농축액. 비율을 조절해 색을 맞춥니다 |
| 조색 범위 | 수십 가지 색상. 팬톤에 가깝게 맞출 수 있습니다 |
| 물성 변화 | 베이스 레진의 기계적 성질이 유지됩니다 |

**색이 레진 자체에 들어갑니다.** 표면만 칠하는 도색과 달리, 긁혀도 같은 색입니다.

# 가능한 색상

| 구분 | 설명 |
| --- | --- |
| 단색 | 빨강, 파랑, 노랑, 녹색, 주황 등 기본 색상 |
| 조색 | 두 가지 이상 색소를 섞어 중간 색상을 만듭니다 |
| 채도 조절 | 색소 비율을 낮추면 파스텔 톤이 됩니다 |
| 투명 착색 | 투명 베이스에 색소를 넣으면 유색 반투명이 됩니다 |

## 안 되는 것

| 제한 | 이유 |
| --- | --- |
| 멀티 컬러 (한 부품에 여러 색) | 한 번에 한 가지 레진만 씁니다 |
| 형광·야광 | 전용 색소가 필요합니다. 일반 키트에는 없습니다 |
| 금속 질감 | 펄이나 메탈릭은 제한적입니다 |
| 정확한 팬톤 매칭 | 근사치까지는 가능하지만, 인쇄물과 정확히 같지는 않습니다 |

멀티 컬러가 필요하면 [PolyJet·풀컬러 방식](/blog/풀컬러-3d프린팅-사례/)을 검토하십시오.

# 도색 vs 컬러 레진

| 항목 | 도색 | 컬러 레진 |
| --- | --- | --- |
| 색상 자유도 | 매우 높음 (어떤 색이든 가능) | 높음 (조색 범위 내) |
| 추가 비용 | 도색비 별도 | 색소 비용만 추가 (소량) |
| 소요 시간 | 출력 후 1~2일 추가 | 추가 시간 없음 |
| 긁힘 내성 | 도막 벗겨짐 | 소재 자체가 해당 색 |
| 균일성 | 수작업 편차 | 레진이 균일하면 색도 균일 |
| 복잡한 형상 | 안쪽 면 도색 어려움 | 전체가 같은 색 |

**시제품 검토용이면 컬러 레진이 효율적입니다.** 최종 제품 색상과 정확히 맞춰야 하는 프레젠테이션 목업은 도색이 나을 수 있습니다.

# 실무 적용

## 제품 디자인 검토

컨셉 단계에서 여러 색상 시제품을 빠르게 뽑아 비교합니다. 도색 없이 3~4가지 색상을 당일 확인할 수 있습니다.

## 조립 검증

조립품에서 부품별로 색을 다르게 뽑으면 조립 순서와 위치를 한눈에 확인할 수 있습니다.

## 전시·프레젠테이션

투자자나 고객에게 보여줄 목업을 실제 제품 색상에 가깝게 출력합니다.

## 의료·치과

치아 색상에 맞는 레진을 조색해 임시 보철이나 모형을 만듭니다.

# 담당자가 확인할 것

1. **목표 색상**을 알려주십시오. 팬톤 번호나 실물 샘플이 있으면 조색이 빨라집니다.
2. **투명도**를 정합니다. 불투명·반투명·투명 중 어느 쪽인지에 따라 베이스가 달라집니다.
3. **물성 요구**를 확인합니다. 컬러 키트는 스탠다드 레진 기반이라 고온·고강도가 필요하면 도색이 나을 수 있습니다.
4. **수량**을 알려주십시오. 같은 색상을 여러 개 뽑으면 레진을 한 번에 조색해 효율적입니다.

# 자주 묻는 질문

## 색소를 넣으면 레진 강도가 떨어지나요

아닙니다. 제조사가 지정한 비율 범위 안에서는 기계적 물성이 유지됩니다. 과도하게 넣으면 경화가 불완전해질 수 있으니 권장 비율을 지키십시오.

## 같은 색을 반복 생산할 수 있나요

됩니다. 색소 비율을 기록해 두면 같은 색을 재현할 수 있습니다. 다만 미세한 배치 편차는 있을 수 있습니다.

## 투명 레진에 색소를 넣으면 어떻게 되나요

유색 반투명이 됩니다. 색소 양을 늘리면 불투명에 가까워집니다. 스테인드글라스 효과나 라이트 가이드 시제품에 쓸 수 있습니다.

원하는 색상과 용도를 알려주시면 조색 가능 여부를 확인해 드립니다.
