라인에 게이지가 없으면 출하 검사가 멈춥니다. 절삭 가공은 2~3주가 걸립니다.

**게이지를 SLA 레진으로 뽑으면 수일 안에 받을 수 있습니다.** 시제품 검증이나 초도품 검사에서 절삭 게이지를 기다리지 않아도 됩니다.

# 절삭 게이지를 기다리기 어려운 상황

| 상황 | 문제 |
| --- | --- |
| 초도품 검사 | 금형은 나왔는데 게이지가 안 나왔습니다. 출하가 밀립니다 |
| 설계 변경 | 구멍 위치가 바뀌면 게이지도 다시 깎아야 합니다. 또 2~3주입니다 |
| 시제품 단계 | 형상이 확정되지 않았는데 절삭 게이지를 만들면 쓰기도 전에 폐기됩니다 |

게이지가 늦어서 버니어 캘리퍼스로 한 개씩 재는 일이 생깁니다. 느리고 오판이 납니다.

SLA 레진의 치수 정확도는 **±0.15%**입니다. 지름 10mm 구멍이면 ±15μm 안에 들어옵니다.

| 게이지 유형 | 되는가 |
| --- | --- |
| Go/No-Go 구멍 | 됩니다. 상한과 하한을 두 구멍으로 나눠 합/불합을 판정합니다 |
| 윤곽 게이지 | 됩니다. 곡면 프로파일이 그대로 나옵니다 |
| 높이·단차 게이지 | 됩니다. 단차를 정밀하게 넣을 수 있습니다 |
| 나사 게이지 | M4 이상이면 됩니다. M3 이하는 적층 계단이 나사산에 영향을 줍니다 |

**1개만 필요해도 됩니다.** 절삭은 셋업비가 붙어 1개와 10개 값이 비슷합니다. SLA는 1개 값이 1개 값입니다.

도면이 없어도 됩니다. 검사할 부품과 공차 기준을 주시면 게이지를 설계해 드립니다. 공차 잡는 법은 [끼워 맞추는 부품, 공차는 어떻게 잡나](/blog/3d프린팅-조립-공차/)에 정리했습니다.

# 절삭 게이지와 다른 점

| 항목 | SLA 레진 게이지 | 절삭 금속 게이지 |
| --- | --- | --- |
| 납기 | 수일 | 2~3주 |
| 치수 정확도 | ±0.15% | ±0.01mm 이하 |
| 내마모성 | 수십 회 사용 가능 | 수천 회 이상 |
| 수정 | 파일 고쳐 당일 재출력 | 다시 가공 2~3주 |

**정밀도 차이를 짚겠습니다.** 절삭 게이지는 ±0.01mm 이하까지 잡습니다. SLA는 10mm 기준 ±15μm이므로 대부분의 시제품 검사에는 충분합니다. 공차가 ±0.01mm보다 좁은 양산 검사에는 절삭 게이지가 맞습니다.

# 맞는 경우와 다시 봐야 할 경우

| 구분 | 내용 |
| --- | --- |
| 잘 맞는 경우 | 시제품 검증 / 초도품 검사 / 설계 변경이 잦은 단계 / 절삭 게이지 도착 전 임시 사용 |
| 다시 봐야 할 경우 | **양산 라인에서 매일 수백 회 쓰는 게이지** — 레진은 마모가 빠릅니다. 절삭 게이지로 만들어야 합니다 / **공차 ±0.01mm 이하** — SLA 정밀도로는 부족합니다 / **60°C 이상 환경** — 레진은 열변형 온도가 낮습니다. 내열 레진을 쓰거나 다른 방법을 봐야 합니다 |

**마모를 짚겠습니다.** SLA 레진 게이지는 시제품 단계에서 수십 회 쓰는 것이 목적입니다. 양산 라인에서 매일 쓸 게이지는 절삭으로 만들고, 그 절삭 게이지가 올 때까지 SLA 게이지로 검사를 시작할 수 있습니다.

비슷한 형태의 부품인 [현장 지그](/blog/3d프린팅-지그-고정구-사례-4건/)도 같은 방식으로 만듭니다.

# 담당자가 확인할 것

1. **검사할 치수와 공차**를 알려주십시오. 공차가 ±0.05mm 이상이면 SLA로 됩니다.
2. **사용 횟수**를 정합니다. 수십 회면 레진, 수천 회면 절삭입니다.
3. **사용 환경 온도**를 확인합니다. 60°C 이상이면 내열 레진을 써야 합니다.
4. **게이지 형태**를 정합니다. Go/No-Go인지, 윤곽인지, 높이인지에 따라 설계가 달라집니다.

# 자주 묻는 질문

## 레진 게이지로 검사 성적서를 발행할 수 있나요

교정 인증이 필요한 공식 검사에는 절삭 게이지를 써야 합니다. 내부 검증 목적이라면 SLA 게이지로 충분합니다.

## 게이지를 여러 개 만들면 싸지나요

SLA는 한 판에 여러 개를 함께 뽑을 수 있습니다. 개수가 늘면 개당 비용이 줄어듭니다. 비용 구조는 [같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)에 정리했습니다.

## 색을 넣을 수 있나요

SLA 레진은 투명·회색·검정이 기본입니다. Go 쪽과 No-Go 쪽을 다른 색으로 구분할 수 있습니다. 투명 레진은 [투명 부품, 소재는 어떻게 다른가](/blog/투명-3d프린팅-부품-소재-비교/)를 보십시오.

절삭 게이지가 올 때까지 라인을 세울 필요가 없습니다. **검사할 부품의 도면이나 공차표를 보내주시면 게이지 형상을 잡아 드립니다.**
