*설명을 위한 생성 이미지입니다.*

자동차에서 3D프린팅을 이야기하면 대개 시제품을 떠올립니다. 실제로는 그보다 넓습니다.

**시험 부품과 생산 라인 지그가 오히려 물량이 큽니다.** 눈에 잘 안 띄지만 매일 쓰이는 쪽입니다.

개발 순서를 따라가며 어디에 무엇이 들어가는지 보겠습니다.

# 1. 디자인·내장 검토

가장 앞 단계입니다. 화면 속 형상을 실물로 만들어 손으로 만져봅니다.

- 대시보드·콘솔 형상 확인
- 버튼·스위치 배치와 조작감
- 표면 질감과 색 검토
- 실내 공간감 확인

**표면과 색이 중요한 단계**입니다. 층결이 보이면 판단이 흐려집니다. SLA나 PolyJet으로 뽑고 도색까지 하는 경우가 많습니다.

색을 출력 단계에서 넣는 방법은 [풀컬러 3D프린팅, 도색이 필요 없는 이유](/blog/풀컬러-3d프린팅-사례-4건/)에 정리했습니다. 내장 시제품 사례는 [자동차 내장 시제품을 3D프린팅으로 만드는 경우](/blog/자동차-내장-시제품-3d프린팅/)에 있습니다.

# 2. 기능·시험 부품

형상이 잡히면 실제로 작동시켜 봅니다. 여기서 요구가 바뀝니다. 표면보다 **물성**이 중요해집니다.

## 엔진 주변 부품

열과 진동을 견뎌야 합니다. 나일론이나 고온 소재를 씁니다.

SLS로 만든 흡기 매니폴드를 엔진에 물려 2,000시간을 돌린 사례가 있습니다. [SLS 흡기 매니폴드, 엔진에서 2,000시간 시험한 사례](/blog/sls-흡기-매니폴드-시험-사례/)에 정리했습니다.

## 풍동 시험

차체 형상을 바꿔가며 공기 저항을 봅니다. 금형으로 만들면 형상 하나 바꿀 때마다 비용과 시간이 듭니다.

실제 크기 차체 타일을 3D프린팅으로 만들어 풍동에 넣은 사례는 [SLA 차체 타일로 실제 크기 풍동 시험을 한 사례](/blog/sla-풍동-차체-시험-사례/)에 있습니다.

## 유체가 지나는 부품

냉각수나 오일이 흐르는 부품입니다. 내부 유로 형상을 바꿔가며 시험합니다.

- 곡선 유로를 일체형으로 뽑습니다
- 새지 않아야 하므로 표면 처리가 붙습니다

만드는 방법은 [안에 유로가 있는 부품](/blog/배관-매니폴드-3d프린팅/)에, 기밀 처리는 [SLS 부품, 물이 새나요](/blog/sls-기밀성-베이퍼-스무딩/)에 정리했습니다.

약품이나 오일에 닿는 부품의 소재 선택은 [오일과 약품에 닿는 부품](/blog/내약품-3d프린팅-소재/)을 보시면 됩니다.

# 3. 생산 라인 지그와 공구

**여기가 실제로 물량이 가장 큰 쪽입니다.** 차량 부품이 아니라 그것을 만드는 도구입니다.

| 쓰는 곳 | 얻는 것 |
| --- | --- |
| 조립 지그 | 작업자가 부품을 정확한 위치에 놓습니다 |
| 검사 게이지 | 치수를 빠르게 확인합니다 |
| 로봇 그리퍼 | 부품 형상에 맞춰 잡습니다 |
| 부품 트레이 | 운반 중 흠집을 막습니다 |
| 위치 결정 툴 | 용접·접합 위치를 잡습니다 |

지그를 3D프린팅으로 바꾸면 무엇이 달라지는지는 [현장 지그를 3D프린팅으로 바꾸면](/blog/3d프린팅-지그-고정구-사례-4건/)에 사례로 정리했습니다.

큰 지그를 나누지 않고 한 번에 만든 사례는 [FDM으로 대형 위치 결정 지그를 한 번에 만든 사례](/blog/fdm-대형-지그-사례/)에 있습니다.

로봇 그리퍼는 [로봇 그리퍼를 3D프린팅으로 바꾸면](/blog/로봇-그리퍼-3d프린팅/), 검사 게이지는 [검사 게이지를 3D프린팅으로 만드는 경우](/blog/검사-게이지-3d프린팅/), 트레이는 [부품 트레이를 3D프린팅으로 만드는 경우](/blog/부품-트레이-3d프린팅/)를 보시면 됩니다.

**로봇 그리퍼는 무게가 중요합니다.** 가벼우면 로봇이 더 빨리 움직입니다. 탄소섬유 복합 소재로 무게를 줄인 사례는 [카본파이버 FDM 로봇팔](/blog/fdm-카본파이버-로봇팔-사례/)에 있습니다.

# 4. 소량 생산과 보수 부품

금형을 만들 수 없는 수량이 있습니다.

- **단종된 부품** — 금형이 이미 폐기된 경우
- **한정 모델 부품** — 수백 대만 만드는 차량
- **개조·튜닝 부품** — 주문마다 형상이 다름
- **시험차 전용 부품** — 몇 대분만 필요

단종 부품을 빠르게 만든 사례는 [FDM으로 단종된 열차 부품을 1주 만에 만든 사례](/blog/fdm-열차-단종-부품-사례/)에 있습니다. 철도 사례지만 자동차 보수 부품도 사정이 같습니다.

도면이 없는 경우가 많은데, 실물만 있어도 만들 수 있습니다. [도면 없는 부품, 실물만 보내도 제작할 수 있나](/blog/도면-없는-부품-제작/)와 [도면 없는 부품, 역설계 비용은 얼마인가](/blog/역설계-비용-사례-4건/)에 정리했습니다.

수량이 애매한 구간은 [금형 없이 소량 생산하는 3가지 방법](/blog/금형-없이-소량-생산/)을 보시면 됩니다.

# 5. 금형과 툴링

금형 자체를 3D프린팅으로 만드는 방법도 있습니다.

| 용도 | 방법 |
| --- | --- |
| 소량 사출 | 레진 금형으로 수십~수백 개 |
| 진공 성형 | 3D프린팅 금형에 시트를 성형 |
| 판금 성형 | 출력 다이로 박판 벤딩 |

소량 사출 사례는 [SLA 금형으로 ABS 60개·PP 100개를 사출한 사례](/blog/sla-사출-금형-소량생산-사례/)에, 진공 성형은 [진공 성형 금형을 3D프린팅으로 만드는 경우](/blog/진공성형-금형-3d프린팅/)에, 판금 다이는 [판금 성형 다이를 3D프린팅으로 만드는 경우](/blog/판금-다이-3d프린팅/)에 있습니다.

# 소재는 무엇을 쓰나

자동차에서 자주 걸리는 조건입니다.

| 조건 | 소재 |
| --- | --- |
| 실내 부품 · 난연 | 난연 등급 소재 |
| 엔진 주변 · 내열 | ULTEM·PEEK·고온 나일론 |
| 외부 노출 · 자외선 | ASA 등 실외용 소재 |
| 지그 · 경량 강성 | 탄소섬유 복합 |
| 개스킷 · 부싱 | TPU·실리콘 |

난연 요구는 [난연 부품을 3D프린팅할 때 확인할 것](/blog/난연-부품-3d프린팅/)에, 실외 노출은 [실외에서 쓰는 부품, 어떤 소재가 맞나](/blog/실외용-3d프린팅-소재/)에, 고온 소재는 [ULTEM·PEEK 3D프린팅](/blog/ultem-peek-3d프린팅-사례-4건/)에 정리했습니다.

# 어디부터 시작하나

3D프린팅을 처음 들이는 경우라면 **생산 라인 지그부터** 시작하시길 권합니다.

1. 효과가 바로 보입니다. 작업 시간이 줄어드는 것이 숫자로 나옵니다
2. 인증 부담이 없습니다. 차량에 들어가는 부품이 아닙니다
3. 실패해도 손실이 작습니다
4. 사내에서 설계를 고쳐가며 개선할 수 있습니다

여기서 경험이 쌓이면 시험 부품과 소량 생산으로 넓히는 순서가 자연스럽습니다.

장비를 살지 맡길지는 [3D프린터, 사는 게 맞는 경우 3가지](/blog/3d프린터-구매-출력대행-비교/)에 판단 기준을 정리했습니다.

# 자주 묻는 질문

:::faq
차량에 실제로 들어가는 부품도 만들 수 있나요
가능합니다. 다만 안전·인증 요구를 먼저 확인해야 합니다. 난연 등급이나 내열 조건이 정해져 있으면 그에 맞는 소재를 씁니다. 요구 조건을 알려주시면 소재를 맞춰 안내드립니다.
:::

:::faq
지그를 3D프린팅으로 바꾸면 얼마나 절약되나요
형상과 수량에 따라 다릅니다. 알루미늄으로 깎던 지그를 3D프린팅으로 바꾸면 비용과 납기가 함께 줄어드는 경우가 많습니다. 다만 무거운 하중을 받는 지그는 금속을 그대로 쓰셔야 합니다.
:::

:::faq
단종 부품을 만들려면 무엇이 필요한가요
실물 하나만 있으면 됩니다. 3D 스캔이나 실측으로 형상을 만든 뒤 출력합니다. 도면이나 파일이 없어도 진행할 수 있습니다.
:::

:::faq
엔진룸에 들어가는 부품도 되나요
소재를 맞추면 됩니다. 온도 조건과 접촉하는 유체를 알려주시면 그에 맞는 소재를 고릅니다. 다만 장기 내구성이 필요한 부품이면 시험을 거쳐야 합니다.
