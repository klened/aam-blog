3D프린팅 부품끼리 또는 3D프린팅 부품과 금속을 나사로 고정하는 경우가 많습니다.

**소재가 약하면 나사산이 무너집니다.** 체결 방식도 소재에 맞춰야 합니다.

# 체결 방식 4가지

![3D프린팅 부품에 적용한 4가지 나사 체결 방식을 비교하는 모습](/images/나사-체결-소재-비교/2.webp)

| 방식 | 설명 | 반복 탈착 | 비용 |
| --- | --- | --- | --- |
| 직접 출력 나사산 | 나사산 형상을 그대로 출력합니다 | 1~3회 | 없음 |
| 셀프 태핑 | 하부 구멍만 출력하고 나사가 파고 들어갑니다 | 3~5회 | 낮음 |
| 열삽입 인서트 | 인두로 가열해 금속 인서트를 녹여 넣습니다 | 수십~수백 회 | 보통 |
| 압입 인서트 | 프레스로 금속 인서트를 밀어 넣습니다 | 수십~수백 회 | 보통 |

**반복 탈착이 필요하면 금속 인서트가 답입니다.**

# 소재별 나사 체결 성능

| 소재 | 방식 | 직접 출력 | 셀프 태핑 | 인서트 | 비고 |
| --- | --- | --- | --- | --- | --- |
| PA12 (나일론) | SLS | 가능 | 우수 | 우수 | 나사 체결에 가장 안정적 |
| PA11 (나일론) | SLS | 가능 | 우수 | 우수 | 충격에 강해 균열 위험 낮음 |
| PA12+카본 | SLS | 가능 | 우수 | 우수 | 강성 높아 보스 변형 적음 |
| 터프 레진 | SLA | 가능 | 보통 | 보통 | ABS급 강도. 과토크에 주의 |
| 스탠다드 레진 | SLA | 주의 | 주의 | 주의 | 깨지기 쉬움. 시제품만 |
| ABS | FDM | 가능 | 보통 | 우수(열삽입) | 적층 방향에 따라 분리 위험 |
| PETG | FDM | 가능 | 보통 | 보통 | ABS보다 약간 유연 |
| PEEK | FDM/SLS | 우수 | 우수 | 우수 | 고하중 체결 |

**SLS 나일론이 나사 체결에 가장 안정적입니다.** 나사산이 무너지지 않고 인서트도 잘 잡힙니다.

# 직접 출력 나사산

나사산 형상을 CAD에서 설계하고 그대로 출력합니다.

| 조건 | 내용 |
| --- | --- |
| 적합 피치 | M4 이상 (M3 이하는 해상도에 따라 무너질 수 있음) |
| 적합 방식 | SLA (정밀도 높음) 또는 SLS (강도 높음) |
| 주의 | FDM은 적층 사이에 틈이 있어 나사산이 약합니다 |

한두 번 조이는 시제품이면 이 방식으로 충분합니다.

# 셀프 태핑 나사

하부 구멍만 출력하고, 나사를 돌려 넣으면 나사 스스로 나사산을 깎으며 들어갑니다.

| 조건 | 내용 |
| --- | --- |
| 하부 구멍 지름 | 나사 외경의 약 80~90% |
| 적합 소재 | PA12, PA11, ABS (적당히 연한 소재) |
| 주의 | 레진은 깨질 수 있습니다. 토크를 줄이십시오 |

3~5회 정도 탈착할 수 있습니다. 구멍이 넓어지면 인서트로 바꿉니다.

# 금속 인서트

반복 탈착이 필요하면 금속 인서트를 넣습니다.

## 열삽입 인서트

![FDM 하우징 보스에 황동 인서트를 열삽입하는 모습](/images/나사-체결-소재-비교/3.webp)

인두나 전용 장비로 인서트를 가열해 플라스틱을 녹이면서 밀어 넣습니다. 녹은 플라스틱이 인서트의 널링(빗살)에 스며들어 고정됩니다.

| 장점 | 내용 |
| --- | --- |
| 고정력 우수 | 녹은 플라스틱이 널링에 채워져 잘 빠지지 않습니다 |
| 반복 탈착 | 수십~수백 회 가능합니다 |
| 적합 소재 | 나일론(SLS), ABS(FDM) — 열에 녹는 열가소성 소재 |

**SLA 레진은 열경화성이라 열삽입이 안 됩니다.** 레진에는 압입 인서트나 접착 고정을 씁니다.

## 압입 인서트

구멍에 인서트를 프레스나 바이스로 밀어 넣습니다.

| 장점 | 내용 |
| --- | --- |
| 열 불필요 | SLA 레진에도 가능합니다 |
| 장비 간단 | 프레스나 바이스로 충분합니다 |
| 주의 | 구멍 치수가 정확해야 합니다. 헐거우면 빠집니다 |

# 보스 설계 가이드

나사가 들어가는 기둥(보스)은 충분히 두꺼워야 합니다.

| 항목 | 기준 |
| --- | --- |
| 보스 외경 | 인서트 외경의 2배 이상 |
| 보스 높이 | 인서트 길이 + 1~2 mm |
| 벽 두께 | 인서트 주변 최소 1.5 mm |
| 챔퍼 | 입구에 0.5 mm 챔퍼를 넣으면 삽입이 쉽습니다 |

보스가 얇으면 인서트를 넣을 때 갈라집니다. 특히 SLA 레진에서 주의해야 합니다.

# 담당자가 확인할 것

1. **탈착 횟수**를 정합니다. 1~3회면 직접 출력, 반복이면 인서트입니다.
2. **체결 하중**을 확인합니다. 가벼우면 나일론, 무거우면 카본+인서트입니다.
3. **소재 특성**을 확인합니다. SLA 레진은 열삽입이 안 되니 압입을 씁니다.
4. **나사 규격**을 알려주십시오. 인서트 크기와 보스 치수를 맞춰 설계합니다.

도면과 체결 조건을 알려주시면 소재와 인서트를 추천해 드립니다.
