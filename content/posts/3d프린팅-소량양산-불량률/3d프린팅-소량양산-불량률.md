소량 양산 비용은 출력 수량이 아니라 합격 수량으로 나눠야 합니다. 출력 실패와 후처리 재작업, 치수 검사 탈락이 생기면 견적에서 본 개당 가격보다 실제 원가가 올라갑니다. 첫 배치에서 합격률과 재작업 시간을 기록하십시오.

# 출력이 끝났다고 납품 수량이 되지는 않습니다

장비에서 100개를 꺼내도 100개를 바로 납품하지는 못할 수 있습니다. 휨과 표면 손상, 구멍 치수, 색상, 조립 상태를 확인한 뒤 합격품과 재작업품을 나눕니다.

기존 [3D프린팅 수량별 단가 글](/blog/3d프린팅-소량생산-단가/)은 한 배치에 몇 개가 들어가는지 설명합니다. 이 글은 배치가 끝난 뒤 실제로 몇 개가 합격했는지 계산하는 기준을 다룹니다.

# 손실은 5곳에서 생깁니다

| 단계 | 발생할 수 있는 손실 | 비용에 넣을 항목 |
| --- | --- | --- |
| 출력 | 중단, 적층 불량, 장비 오류 | 다시 쓴 소재와 장비 시간 |
| 냉각·분리 | 휨, 균열, 플랫폼 분리 손상 | 폐기 수량과 다시 출력한 수량 |
| 후처리 | 서포트 자국, 과도한 연마, 염색 편차 | 작업자 시간과 재처리 비용 |
| 검사 | 치수·외관 기준 미달 | 측정 시간과 탈락 수량 |
| 조립 | 끼움, 체결, 작동 실패 | 수정 설계와 재출력 비용 |

출력 실패만 불량으로 기록하면 실제 손실이 작게 보입니다. 납품 기준에 맞지 않아 다시 손댄 부품도 재작업 시간과 비용에 포함해야 합니다.

# 첫 배치에서 기준을 확정합니다

시제품 1개가 맞았다고 100개가 모두 같은 조건으로 나오지는 않습니다. 생산 수량이 늘면 여러 배치와 소재 로트, 작업자와 후처리 순서가 달라질 수 있습니다.

Stratasys Direct는 시제품에서 생산으로 넘어갈 때 여러 소재 로트와 반복 빌드, 여러 장비, 후처리와 검사자까지 관리 대상이 된다고 설명합니다. 본 수량을 주문하기 전에 첫 소량 배치에서 다음 항목을 확인해야 합니다.

1. 합격 기준이 표시된 도면과 승인 샘플
2. 배치마다 측정할 주요 치수
3. 재작업이 가능한 결함과 바로 폐기할 결함
4. 부족 수량을 보충하는 일정과 비용
5. 장비·소재·후처리 조건을 바꿀 때의 승인 절차

반복 주문의 파일과 소재, 후처리 기록은 [3D프린팅 반복 생산 관리](/blog/3d프린팅-반복-생산/)에서 확인할 수 있습니다.

# 불량률만 낮추려고 검사 기준을 늦추면 안 됩니다

검사 항목을 줄이면 숫자로 보이는 불량률은 낮아집니다. 하지만 조립 현장에서 문제가 발견되면 선별과 반품 비용이 더 커질 수 있습니다.

먼저 기능에 영향을 주는 치수를 정합니다. 모든 치수를 전수 검사하기보다 첫 부품과 배치별 표본, 안전에 영향을 주는 항목을 구분해야 합니다. 검사 범위는 [3D프린팅 부품 검수와 성적서](/blog/3d프린팅-부품-검수/)에서 자세히 볼 수 있습니다.

# 견적서에서 따로 확인할 항목

| 확인할 항목 | 확인 질문 |
| --- | --- |
| 납품 수량 | 출력 수량인지 검사 합격 수량인지 |
| 예비 수량 | 부족분에 대비해 몇 개를 추가 제작하는지 |
| 재작업 | 연마·염색·치수 보정 비용이 포함됐는지 |
| 검사 | 첫 부품·표본·전수 가운데 어느 범위인지 |
| 보충 제작 | 탈락 수량을 언제 어떤 비용으로 다시 만드는지 |

검사와 보충 제작 조건이 없으면 가장 낮은 개당 가격만 보이게 됩니다. 납품일에 필요한 합격 수량을 받을 수 있는지가 더 먼저입니다.

# 맞는 경우와 다시 검토할 경우

| 소량 양산을 진행하기 좋은 경우 | 공정을 다시 비교할 경우 |
| --- | --- |
| 첫 배치에서 합격 기준을 확정했습니다 | 시제품 파일이 계속 바뀝니다 |
| 주요 치수와 검사 수량을 정했습니다 | 외관과 색상 기준이 정해지지 않았습니다 |
| 장비·소재·후처리 기록을 남깁니다 | 요구 공차가 해당 공정의 능력보다 좁습니다 |
| 부족 수량의 보충 일정이 있습니다 | 반복 수량이 커져 사출·CNC가 유리해졌습니다 |

수량이 늘면 3D프린팅만 고집하지 않아도 됩니다. 금형비와 설계 변경 가능성을 함께 계산하고 사출·CNC 전환 시점을 정해야 합니다.

# 담당자가 확인할 것

1. 필요한 수량을 출력 수량이 아니라 합격 납품 수량으로 적습니다.
2. 첫 소량 배치에서 폐기와 재작업 사유를 구분해 기록합니다.
3. 주요 치수와 외관 기준, 검사 수량을 제작 전에 전달합니다.
4. 예비 수량과 부족분 보충 일정을 견적서에서 확인합니다.
5. 합격품 1개당 원가를 계산해 다음 배치와 비교합니다.

# 자주 묻는 질문

## 100개를 주문하면 몇 개를 더 출력해야 하나요

정해진 비율은 없습니다. 첫 배치의 합격률과 형상, 검사 기준을 확인한 뒤 예비 수량을 정해야 합니다.

## 재작업한 부품도 합격품으로 쓸 수 있나요

합격 기준을 충족하면 사용할 수 있습니다. 다만 재작업 방법이 치수와 강도, 표면에 영향을 주는지 확인하고 작업 기록을 남겨야 합니다.

## 불량품 비용은 누가 부담하나요

견적과 계약 조건에 따라 달라집니다. 납품 수량과 검사 기준, 보충 제작 범위를 발주 전에 정해야 비용 해석이 달라지지 않습니다.

## 첫 주문부터 전수 검사해야 하나요

안전과 규격에 영향을 주는 항목은 전수 검사가 필요할 수 있습니다. 일반 부품은 첫 부품과 배치별 표본을 정하고 조립에 영향을 주는 치수를 우선 확인합니다.

3D프린팅 소량 양산을 검토 중이라면 부품 파일과 합격 납품 수량, 검사 항목을 보내주세요. 담당 엔지니어가 시험 배치와 예비 수량, 보충 제작 조건을 확인한 뒤 회신드리겠습니다.
