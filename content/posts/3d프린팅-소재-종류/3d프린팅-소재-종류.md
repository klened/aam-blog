*요구 조건으로 소재를 고르는 흐름을 나타낸 설명용 이미지입니다.*

3D프린팅 소재를 고를 때 종류부터 외우면 헤맵니다. PLA인지 ABS인지 나일론인지를 먼저 정하려 하면 답이 안 나옵니다.

먼저 결론입니다. **소재는 부품이 정합니다.** 열을 받는지, 힘을 받는지, 약품에 닿는지, 안이 보여야 하는지를 적으면 후보가 좁혀집니다. 이 글은 그 요구 조건에서 소재로 이어지는 지도입니다.

# 소재부터 고르면 틀립니다

소재 이름은 결과입니다. 출발점이 아닙니다.

같은 부품도 쓰는 자리에 따라 소재가 달라집니다. 실내에 두는 하우징과 실외에 두는 하우징은 다른 소재로 갑니다. 그래서 소재를 묻기 전에 **부품이 무엇을 견뎌야 하는지**를 먼저 정합니다.

# 요구 조건으로 소재를 찾는 지도

부품이 받는 조건을 왼쪽에서 찾으면 후보 소재가 나옵니다. 소재마다 자세한 글로 이어집니다.

| 부품이 받는 것 | 보는 소재 | 자세히 |
| --- | --- | --- |
| 열 (140°C 안쪽) | PC | [PC 3D프린팅](/blog/pc-폴리카보네이트-3d프린팅/) |
| 더 높은 열 (200°C 이상) | ULTEM·PEEK | [ULTEM·PEEK](/blog/ultem-peek-3d프린팅-사례-4건/) |
| 무르고 유연해야 함 | TPU·실리콘 | [TPU와 실리콘](/blog/tpu-실리콘-무른-부품/) |
| 힘을 받아 휘면 안 됨 | 섬유 강화 | [섬유를 섞은 소재](/blog/카본파이버-소재/) |
| 안이 보여야 함 | 투명 레진 | [투명 부품 소재](/blog/투명-3d프린팅-부품-소재-비교/) |
| 기름·약품에 닿음 | PP·나일론 | [내약품 소재](/blog/내약품-3d프린팅-소재/) |
| 식품·의료 접촉 | 생체적합 소재 | [식품·의료 접촉 소재](/blog/식품-의료-접촉-소재-비교/) |
| 정전기 방지 | ESD 소재 | [ESD 지그·트레이](/blog/esd-지그-트레이-소재/) |
| 물이 닿음·방수 | SLS 실링·SLA | [방수 하우징 소재](/blog/방수-하우징-소재-비교/) |
| 실외·자외선 | ASA | [실외용 소재](/blog/실외용-3d프린팅-소재/) |
| 불에 견뎌야 함 | 난연 등급 | [난연 부품 소재](/blog/난연-부품-3d프린팅/) |
| 꼭 금속이어야 함 | 금속(DMLS) | [금속 판단 기준](/blog/금속-3d프린팅-판단-기준/) |
| 특별한 조건 없음, 기능만 | 나일론 | [나일론 3D프린팅](/blog/나일론-3d프린팅/) |

![투명 유로 하우징과 연질 벨로즈, ESD 트레이, 나일론 기어 하우징을 용도별로 비교하는 모습](/images/3d프린팅-소재-종류/2.webp)

조건이 없으면 나일론이 기본입니다. 질기고 두루 쓰이기 때문입니다.

# 부품 종류로 골라도 됩니다

받는 조건이 애매하면 부품 이름으로 찾는 방법도 있습니다.

- 기어·캠이면 [어떤 소재가 좋을까](/blog/기어-캠-소재-비교/)
- 나사로 조이는 부품이면 [나사 체결 소재](/blog/나사-체결-소재-비교/)
- 딸깍 걸리는 스냅핏이면 [스냅핏·래치 소재](/blog/스냅핏-래치-소재-비교/)

# 소재가 공정을 데려옵니다

소재를 정하면 뽑는 방식도 대체로 정해집니다.

| 소재 | 주로 쓰는 공정 |
| --- | --- |
| 나일론 | SLS·MJF (분말) |
| 레진·투명 | SLA (레진) |
| PC·ABS·ULTEM·카본 | FDM |
| 풀컬러·연질 | PolyJet |
| 금속 | PBF (금속 분말) |

![같은 브라켓을 FDM과 SLS, SLA, 금속 공정으로 제작해 표면을 비교하는 모습](/images/3d프린팅-소재-종류/3.webp)

방식을 처음부터 고르고 싶으시면 [산업용 3D프린터 방식 4가지](/blog/산업용-3d프린터-방식-4가지/)에 부품으로 고르는 기준을 정리했습니다.

# 비용은 소재보다 이것으로 정해집니다

소재값 차이는 대개 2차입니다. 금액을 크게 바꾸는 것은 따로 있습니다.

- **수량** — 개당 단가는 수량이 늘수록 내려갑니다.
- **크기** — 클수록 출력 시간과 소재가 늘어납니다.
- **후처리** — 어디까지 다듬느냐가 금액을 가장 크게 바꿉니다.

같은 소재라도 이 셋으로 값이 달라집니다. 비용을 잡는 법은 [같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)와 [10개·50개·100개 단가](/blog/3d프린팅-소량생산-단가/)에 있습니다.

# 담당자가 확인할 것

1. **부품이 받는 것**을 적습니다. 열·힘·약품·접촉·정전기 중 무엇인지 정합니다.
2. **투명이나 색**이 필요한지 정합니다. 여기서 소재가 크게 좁혀집니다.
3. **수량**을 정합니다. 소재보다 금액을 크게 바꿉니다.
4. **도면이 있는지** 확인합니다. 없어도 실물로 진행합니다.

# 자주 묻는 질문

:::faq
소재를 뭘 써야 할지 정말 모르겠어요
용도만 알려주시면 됩니다. 부품이 받는 조건을 들으면 소재를 좁혀 드립니다. 소재 이름을 미리 정하실 필요가 없습니다.
:::

:::faq
PLA나 ABS는 왜 표에 없나요
취미와 학습에 많이 쓰는 소재입니다. 산업 기능 부품에서는 나일론·PC·ULTEM처럼 조건을 견디는 소재를 먼저 봅니다. 형상만 빠르게 확인할 때는 값싼 소재로 뽑기도 합니다.
:::

:::faq
처음엔 싼 소재로 확인하고 나중에 바꿔도 되나요
됩니다. 초기에는 값싼 소재로 형상과 조립을 확인하고, 실제 조건이 걸리면 그때 실소재로 다시 뽑습니다. 금형이 없어 소재를 바꿔도 형틀 비용이 들지 않습니다.
:::

:::faq
도면이 없어도 소재를 정할 수 있나요
됩니다. 실물이나 샘플과 쓰임을 알려주시면 조건을 읽어 소재를 잡습니다. 데이터는 역설계로 만듭니다.
:::

소재 이름을 외울 필요는 없습니다. 부품이 무엇을 견뎌야 하는지만 정리하면 됩니다. 조건을 적어 오시면 소재와 공정, 비용을 함께 잡아 드립니다. 값싼 소재로 1개 먼저 뽑아 형상을 확인하고 실소재로 넘어가는 방법도 있습니다.

여러 소재로 실제 부품을 뽑아 온 경험이 있습니다. 부품 사진과 쓰임을 알려주시면 어느 소재가 맞는지 확인해 드립니다.
