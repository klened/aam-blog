*오일과 약품에 닿는 3D프린팅 소재의 시험을 설명하기 위한 이미지입니다.*

“오일에 닿아도 되는 소재로 뽑아 주세요”라는 요청만으로는 소재를 정하기 어렵습니다. 절삭유와 윤활유, 세척제는 성분이 다르고 온도와 접촉 시간도 다릅니다.

먼저 받아야 할 정보는 **약품의 정확한 이름과 사용 조건**입니다.

# 내약품성은 조건마다 달라집니다

UltiMaker의 내약품 소재 안내도 약품과 농도, 온도, 노출 시간, 기계적 응력을 함께 보도록 설명합니다.

| 확인 항목 | 예시 |
| --- | --- |
| 약품 | 윤활유, IPA, 세정액, 냉각수 |
| 농도 | 원액인지 희석액인지 |
| 온도 | 상온인지 가열 상태인지 |
| 접촉 방식 | 튀는 정도, 반복 세척, 계속 잠김 |
| 하중 | 약품에 닿은 상태에서 힘을 받는지 |

같은 소재라도 상온에서 잠깐 닦는 조건과 60℃ 액체에 계속 잠기는 조건은 결과가 다릅니다.

# 소재 후보는 사용 조건으로 좁힙니다

PP는 여러 약품과 수분에 견디는 용도로 검토합니다. 나일론은 강도와 마모가 필요한 기계 부품에 많이 쓰지만 수분 흡수와 약품 종류를 확인해야 합니다. TPU는 유연한 씰과 보호부에 쓰며, 등급마다 오일 반응이 다릅니다.

| 우선 조건 | 검토할 후보와 주의점 |
| --- | --- |
| 약품과 수분 접촉 | PP 계열, 출력 변형과 접합을 확인합니다 |
| 기계 하중과 마모 | 나일론 계열, 흡습과 치수 변화를 봅니다 |
| 유연한 보호부 | TPU 계열, 오일 종류별 자료가 필요합니다 |
| 고온과 강한 용제 | 고온용 소재, 장비와 비용을 함께 검토합니다 |

PP의 출력 방식과 한계는 [PP를 3D프린팅으로 뽑는 방법](/blog/pp-3d프린팅/)에서 확인할 수 있습니다.

# 원재료가 견뎌도 출력 부품은 샐 수 있습니다

소재 데이터는 원재료의 대표 성질을 보여 줍니다. 출력 부품에는 적층선과 표면 틈, 결합부가 있습니다. 액체가 벽을 통과하거나 틈에 남아 오염을 만들 수 있습니다.

액체가 흐르는 매니폴드는 유로 청소와 압력 시험까지 확인해야 합니다. 형상 기준은 [안에 유로가 있는 부품, 3D프린팅으로 만드는 경우](/blog/배관-매니폴드-3d프린팅/)에서 볼 수 있습니다.

SLS 부품은 표면 처리를 검토할 수 있습니다. 다만 스무딩이 규격 등급을 대신하지는 않습니다. [SLS 부품, 물이 새나요](/blog/sls-기밀성-베이퍼-스무딩/)에서 표면과 기밀성의 차이를 확인하십시오.

# 실제 조건으로 시험합니다

1. 같은 소재와 출력 방향으로 시험편을 만듭니다.
2. 실제 농도와 온도에 노출합니다.
3. 정해진 시간 뒤 질량과 치수를 잽니다.
4. 부풀음과 균열, 끈적임, 색 변화를 확인합니다.
5. 하중을 받는 부품은 노출 뒤 조립과 강도를 다시 봅니다.

장기간 쓰거나 누설이 안전과 연결되는 부품은 실제 조립품과 지정 시험 기준이 필요합니다.

# 담당자가 확인할 것

1. **제품명과 물질안전보건자료를 준비합니다.** 통칭보다 성분 정보가 정확합니다.
2. **농도와 온도를 적습니다.** 세척 직후의 최고 온도도 포함합니다.
3. **접촉 시간을 구분합니다.** 비산, 반복 세척, 연속 침지를 나눕니다.
4. **하중과 밀폐 요구를 표시합니다.** 소재와 구조 시험의 범위가 달라집니다.
5. **합격 기준을 정합니다.** 치수 변화와 질량 변화, 누설, 외관 가운데 무엇을 볼지 정합니다.

# 자주 묻는 질문

:::faq
나일론은 오일에 모두 강한가요
오일 종류와 첨가제, 온도, 접촉 시간에 따라 다릅니다. 정확한 제품 정보와 소재 등급을 대조한 뒤 시험해야 합니다.
:::

:::faq
PP로 출력하면 약품 탱크를 바로 만들 수 있나요
소재의 내약품성과 탱크의 누설은 다른 문제입니다. 벽 두께와 출력 품질, 이음부를 포함한 침지 또는 압력 시험이 필요합니다.
:::

:::faq
소재 데이터시트만 제출하면 되나요
납품처 요구에 따라 다릅니다. 데이터시트는 대표 물성 자료이고, 실제 납품 부품의 시험 결과는 아닙니다.
:::

:::faq
간단히 확인할 수 있는 시험이 있나요
같은 공정의 시험편을 실제 액체에 노출한 뒤 질량과 치수, 외관을 비교할 수 있습니다. 안전과 인증이 관련되면 지정 규격에 맞춘 시험이 필요합니다.
:::

내약품 소재는 이름으로 고르지 않습니다. 약품과 농도, 온도, 접촉 시간, 하중을 적어야 시험할 후보를 정할 수 있습니다.
