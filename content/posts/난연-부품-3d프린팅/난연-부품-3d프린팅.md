*난연 부품의 제작 조건을 설명하기 위한 이미지입니다.*

도면에 “난연 소재”라고 적혀 있으면 ULTEM 같은 소재부터 찾기 쉽습니다. 그러나 소재 이름만 정해서는 납품 조건을 맞췄는지 판단할 수 없습니다.

먼저 확인할 것은 **요구 규격과 부품 조건**입니다.

# 난연과 내열은 다릅니다

![시험 장치에서 3D프린팅 고분자 시편의 연소 상태를 확인하는 모습](/images/난연-부품-3d프린팅/2.webp)

내열은 높은 온도에서 형상과 물성을 유지하는 성질입니다. 난연은 불꽃을 제거한 뒤 연소가 어떻게 이어지는지 같은 시험 결과로 판단합니다. 열을 잘 견디는 소재라도 필요한 난연 등급이 없을 수 있습니다.

| 도면에 적힌 요구 | 제작 전에 확인할 자료 |
| --- | --- |
| 사용 온도 | 상시 온도와 순간 최고 온도 |
| UL 94 등급 | 등급, 시험 두께, 시험편 조건 |
| 운송 분야 FST | 적용 규격과 요구 수치 |
| 고객사 승인 소재 | 승인된 소재 등급과 제조사 |

[ULTEM·PEEK 3D프린팅 사례](/blog/ultem-peek-3d프린팅-사례-4건/)처럼 고온용 부품에 ULTEM 계열을 쓰기도 합니다. 난연 요구가 없다면 더 저렴한 소재가 맞을 수 있습니다.

# 등급은 소재 이름만으로 끝나지 않습니다

![벽 두께와 출력 방향이 다른 시편의 열 노출 상태를 검사하는 모습](/images/난연-부품-3d프린팅/3.webp)

Stratasys는 ULTEM 9085를 난연용 FDM 소재로 안내합니다. 공식 자료에도 UL 등급과 FST 결과가 시험편 두께, 출력 방향, 장비와 소재 등급에 따라 구분돼 있습니다.

같은 이름의 재료를 썼다는 사실만으로 실제 납품 부품이 같은 결과를 낸다고 단정하면 안 됩니다. 얇은 벽과 두꺼운 벽은 시험 조건이 다르고, 적층 방향도 결과에 영향을 줄 수 있습니다.

| 확인 항목 | 왜 필요한가 |
| --- | --- |
| 최소 벽 두께 | 시험 자료가 적용되는 두께인지 확인합니다 |
| 출력 방향 | 시험편과 실제 부품의 적층 방향을 비교합니다 |
| 장비와 소재 등급 | 승인 자료에 적힌 조합인지 확인합니다 |
| 후처리 | 도색과 접착제가 난연 요구에 영향을 줄 수 있습니다 |
| 추적 자료 | 사용한 소재 로트와 공정을 확인할 수 있어야 합니다 |

# 견적 전에 받을 자료

“V-0 소재로 제작해 주세요”보다 다음 자료가 정확합니다.

1. 요구 규격의 이름과 등급
2. 부품의 최소 벽 두께
3. 사용 온도와 불꽃에 노출될 가능성
4. 고객사에 제출할 문서 목록
5. 도색, 접착, 인서트 같은 후처리 여부

산업용 장비가 필요한 이유는 출력 크기만이 아닙니다. 공정 기록과 소재 추적이 납품 조건에 포함될 수 있습니다. 장비 선택 기준은 [스트라타시스 산업용 3D프린터, 언제부터 필요한가](/blog/스트라타시스-산업용-3d프린터/)에서 확인할 수 있습니다.

# 맞는 경우와 다시 검토할 경우

| 난연 소재를 검토할 경우 | 별도 시험이 필요한 경우 |
| --- | --- |
| 전장 장비 안의 브라켓과 덕트 | 완성 부품의 등급을 증명해야 하는 납품 건 |
| 운송 장비의 소량 내장 부품 | 도료와 접착제까지 포함한 평가가 필요한 부품 |
| 고온 지그와 절연 부품 | 고객사가 지정한 시험기관 성적서를 요구하는 경우 |
| 승인 소재가 도면에 지정된 부품 | 기존 자료와 다른 두께나 출력 조건을 쓰는 경우 |

소재 데이터시트와 완성 부품의 시험 성적서는 다른 문서입니다. 필요한 발행 주체까지 먼저 확인해야 합니다.

# 담당자가 확인할 것

1. **난연 규격의 정확한 이름을 받습니다.** “불에 강한 소재”라는 설명만으로는 견적을 정하기 어렵습니다.
2. **최소 벽 두께를 표시합니다.** 얇은 구간이 시험 자료의 범위에 드는지 확인합니다.
3. **출력 방향을 검토합니다.** 하중 방향과 난연 자료를 함께 봅니다.
4. **후처리 재료를 적습니다.** 도료와 접착제도 최종 구성에 포함됩니다.
5. **제출 문서를 합의합니다.** 데이터시트, 소재 로트 자료, 시험 성적서를 구분합니다.

# 자주 묻는 질문

:::faq
UL 94 V-0 소재로 출력하면 부품도 V-0인가요
자동으로 정해지지 않습니다. 시험편의 두께와 출력 방향, 장비·소재 조합이 실제 부품 조건과 맞는지 확인해야 합니다. 완성 부품의 성적서가 필요하면 별도 시험 범위를 정합니다.
:::

:::faq
내열 소재면 난연 부품으로 쓸 수 있나요
내열과 난연은 평가 항목이 다릅니다. 사용 온도를 견디면서 요구 난연 규격도 충족하는 소재인지 각각 확인해야 합니다.
:::

:::faq
도색하면 난연 등급이 유지되나요
도료와 프라이머가 최종 부품에 추가되므로 별도 확인이 필요합니다. 납품 규격이 엄격하다면 후처리까지 포함한 조건으로 검토합니다.
:::

:::faq
견적을 받으려면 무엇을 보내야 하나요
3D 파일과 도면, 요구 규격, 최소 두께, 수량, 제출 문서 목록을 보내주십시오. 사용 온도와 후처리 여부도 함께 적으면 소재와 장비를 좁힐 수 있습니다.
:::

난연 부품은 소재부터 고르는 일이 아닙니다. 요구 규격과 부품 조건을 먼저 정해야 제작 방법을 판단할 수 있습니다.
