*3D프린팅 구멍의 출력과 측정을 설명하기 위한 이미지입니다.*

도면에는 구멍이 있는데 출력물에서는 작게 나옵니다. 작은 구멍은 막혀 보이기도 합니다.

프린터가 바깥 윤곽과 구멍을 똑같이 만들지는 않습니다. 구멍의 방향과 깊이, 재료를 빼낼 길이 결과를 바꿉니다.

# 먼저 구멍 3가지를 구분합니다

![방향과 크기가 다른 3D프린팅 구멍을 금속 핀으로 확인하는 모습](/images/3d프린팅-구멍-설계/2.webp)

| 구멍 종류 | 먼저 볼 조건 |
| --- | --- |
| 관통 구멍 | 지름, 출력 방향, 드릴 접근 가능 여부 |
| 막힌 구멍 | 깊이, 바닥 모양, 세척 가능 여부 |
| 내부 유로 | 입구와 출구, 굴곡, 레진·분말 배출 경로 |

관통 구멍은 출력 뒤 드릴이나 리머로 맞출 수 있습니다. 내부 유로는 공구가 닿지 않습니다. 처음부터 다른 기준을 적용해야 합니다.

# 도면보다 작아지는 이유

적층 과정에서는 구멍 가장자리가 계단처럼 만들어집니다. 눕혀 출력한 원형 구멍은 위쪽 형상이 처지거나 거칠어질 수 있습니다.

SLA에서는 남은 레진과 세척 상태를 확인해야 합니다. SLS는 구멍 안의 분말을 빼낼 공간이 필요합니다. 작은 유로가 길고 굽어 있으면 입구가 열려 있어도 내부에 재료가 남을 수 있습니다.

Formlabs의 설계 사양도 최소 구멍과 배출 구멍을 따로 안내합니다. 장비별 값은 출발점입니다. 구멍 길이와 방향이 달라지면 실제 통과 지름도 달라질 수 있습니다.

# 용도에 따라 방법을 정합니다

| 구멍의 용도 | 권장 방법 |
| --- | --- |
| 볼트가 지나가는 구멍 | 여유를 두고 설계하거나 출력 후 드릴로 맞춥니다 |
| 핀이 정확히 들어가는 구멍 | 작게 출력한 뒤 리밍하고 핀 게이지로 확인합니다 |
| 나사가 직접 체결되는 구멍 | 탭 가공 또는 인서트 사용을 먼저 검토합니다 |
| 액체·공기가 지나는 유로 | 입구와 출구, 세척·분말 배출 경로를 함께 설계합니다 |

보정값을 무조건 더하는 방식은 안전하지 않습니다. 같은 보정값도 세워 출력한 구멍과 눕혀 출력한 구멍에서 다른 결과를 낼 수 있습니다.

# 내부 유로는 눈으로 확인하기 어렵습니다

![보어스코프와 공기압으로 3D프린팅 매니폴드 내부 유로를 검사하는 모습](/images/3d프린팅-구멍-설계/3.webp)

외부 구멍은 핀 게이지로 잴 수 있습니다. 굽은 내부 유로는 입구만 재도 전체 상태를 알 수 없습니다.

공기나 물을 흘려 통과 여부를 확인하고, 필요한 경우 압력 손실이나 누설도 시험합니다. 완전 밀폐가 규격으로 요구되면 별도 시험 조건과 합격 기준이 필요합니다. [안에 유로가 있는 부품, 3D프린팅으로 만드는 경우](/blog/배관-매니폴드-3d프린팅/)에서 형상별 검토 항목을 확인할 수 있습니다.

# 첫 출력에서 남길 값

기능 구멍이 여러 개라면 1개 부품에 서로 다른 후보 지름을 배치해 볼 수 있습니다. 출력 후 실제 핀이나 볼트를 넣어 맞는 값을 찾습니다.

측정값에는 공정과 소재, 방향을 함께 기록합니다. 다음 제작에서 같은 조건을 써야 보정값을 다시 적용할 수 있습니다. 치수 기록 방법은 [3D프린팅 공차, 도면 치수대로 어디까지 나오나](/blog/3d프린팅-치수-공차/)에서 다룹니다.

# 맞는 경우와 다시 검토할 경우

| 출력과 후가공으로 맞추기 좋은 경우 | 먼저 다시 검토할 경우 |
| --- | --- |
| 공구가 양쪽에서 닿는 관통 구멍 | 막혀 있고 길게 굽은 내부 유로 |
| 기성 볼트가 통과하는 여유 구멍 | 베어링과 정밀 핀이 바로 끼워지는 구멍 |
| 1개를 측정해 보정할 수 있는 부품 | 세척 상태를 검사할 방법이 없는 부품 |
| 후가공 면을 도면에 표시한 부품 | 의료·유체 규격의 시험 성적이 필요한 부품 |

# 담당자가 확인할 것

1. **기능 구멍을 표시합니다.** 외관 구멍과 조립 구멍을 구분합니다.
2. **관통 여부와 깊이를 적습니다.** 막힌 구멍은 세척 가능성도 확인합니다.
3. **실제 상대 부품을 준비합니다.** 볼트와 핀, 튜브로 끼움을 시험합니다.
4. **후가공 허용 여부를 정합니다.** 드릴과 리머가 닿는 방향을 봅니다.
5. **내부 유로의 검사법을 정합니다.** 통과, 유량, 압력 가운데 필요한 항목을 고릅니다.

# 자주 묻는 질문

## 구멍을 도면에서 얼마나 크게 해야 하나요

일률적인 보정값은 권하기 어렵습니다. 공정과 소재, 지름, 깊이, 출력 방향을 정한 뒤 시험 출력값으로 보정하십시오.

## 작은 구멍이 막히면 뚫어서 쓰면 되나요

공구가 닿는 관통 구멍은 가능합니다. 굽은 내부 유로나 얇은 벽 가까이에 있는 구멍은 손상 위험이 있어 설계를 먼저 바꾸는 편이 낫습니다.

## 원형 구멍이 타원처럼 나오는 이유는 무엇인가요

출력 방향과 적층 단면이 원형도에 영향을 줍니다. 구멍 방향을 바꾸거나 후가공할 기준면을 추가해 개선할 수 있습니다.

## 내부 유로에 분말이 남았는지 어떻게 확인하나요

무게와 흔들림만으로는 충분하지 않습니다. 압축 공기, 세척액, 유량 시험 등 부품 용도에 맞는 검사 방법을 정해야 합니다.

구멍은 파일에서 보인다고 기능이 보장되지 않습니다. 상대 부품이 통과하고 내부 재료가 빠져야 합니다. 구멍 종류와 검사 방법을 도면에 표시하면 보정과 견적 범위를 함께 정할 수 있습니다.
