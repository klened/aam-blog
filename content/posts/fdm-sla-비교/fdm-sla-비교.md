3D프린팅을 처음 맡기면 대부분 두 가지 중 하나를 고르게 됩니다. FDM 아니면 SLA입니다.

둘 다 3D 파일을 실물로 만들어주지만 원리가 다릅니다. FDM은 플라스틱 실(필라멘트)을 **녹여서 쌓고**, SLA는 액체 수지(레진)를 **빛으로 굳힙니다.**

이 차이가 표면, 정밀도, 강도, 비용까지 전부 갈라놓습니다.

# 원리가 다릅니다

## FDM (Fused Deposition Modeling)

필라멘트를 노즐로 녹여 한 층씩 쌓습니다. 가장 보편적인 방식이고, 개인용부터 산업용까지 폭이 넓습니다.

- 소재: ABS, PLA, PETG, 나일론, PC, ULTEM
- 층 두께: 0.1~0.3mm
- 조형 크기: 소형부터 1m 이상 대형까지

## SLA (Stereolithography)

수조에 담긴 레진을 레이저(또는 LCD 빛)로 한 층씩 굳힙니다. FDM보다 정밀하고 표면이 매끄럽습니다.

- 소재: 표준 레진, 터프 레진, 고온 레진, 캐스터블 레진
- 층 두께: 0.025~0.1mm
- 조형 크기: 대부분 소~중형 (대형 SLA도 있음)

방식별 전체 개요는 [산업용 3D프린터 방식 4가지](/blog/산업용-3d프린터-방식-4가지/)에 정리했습니다.

# 4가지 기준으로 비교합니다

## 1. 표면 품질

**SLA가 훨씬 매끄럽습니다.**

FDM은 층결(레이어 라인)이 보입니다. 층 두께가 0.1mm여도 육안으로 확인됩니다. 후처리(연마·퍼티·도장)를 하면 매끄러워지지만 비용과 시간이 붙습니다.

SLA는 층 두께가 0.025~0.05mm입니다. 출력 직후에도 매끄러운 표면이 나옵니다. 외관 시제품이나 프레젠테이션 모형에 적합합니다.

| 기준 | FDM | SLA |
| --- | --- | --- |
| 층결 | 눈에 보임 | 거의 안 보임 |
| 표면 조도 | Ra 10~25μm | Ra 1~5μm |
| 후처리 없이 사용 | 형상 확인 수준 | 외관 시제품 수준 |

## 2. 정밀도

SLA가 높습니다. 다만 FDM도 산업용 장비라면 ±0.15mm까지 맞출 수 있습니다.

| 기준 | FDM | SLA |
| --- | --- | --- |
| 일반 공차 | ±0.2~0.5mm | ±0.1~0.15mm |
| 산업용 장비 | ±0.15mm | ±0.05mm |
| 미세 형상 | 0.8mm 이상 | 0.3mm 이상 |

끼워 맞춤이 필요한 부품은 SLA가 안전합니다. 조립 공차 설계는 [3D프린팅 조립 공차 가이드](/blog/3d프린팅-조립-공차/)를 참고하시면 됩니다.

## 3. 강도와 물성

FDM이 유리합니다. 쓸 수 있는 소재가 더 넓기 때문입니다.

FDM은 ABS, 나일론, PC, ULTEM 같은 엔지니어링 플라스틱을 씁니다. 이 소재들은 내열성, 내화학성, 충격 강도가 높습니다.

SLA 레진은 **경화 후 취성(깨지기 쉬움)이 있는 경우**가 많습니다. 터프 레진이나 듀러블 레진으로 보완할 수 있지만 FDM 엔지니어링 소재만큼은 안 됩니다.

| 기준 | FDM | SLA |
| --- | --- | --- |
| 인장 강도 | 높음 (ABS·나일론) | 보통 (레진 종류에 따라) |
| 내열성 | 높음 (PC 140°C, ULTEM 200°C+) | 보통 (표준 레진 60~80°C) |
| 내충격성 | 높음 | 낮음~보통 |
| 옥외 내구성 | ASA 사용 시 가능 | 자외선에 약함 |

**기능 테스트나 실사용 부품은 FDM이 맞습니다.** 외관 확인이나 주조용 원형은 SLA가 맞습니다.

출력 방향에 따라 강도가 달라지는 것은 두 방식 모두 해당됩니다. [출력 방향과 강도](/blog/출력-방향과-강도/)에서 자세히 설명했습니다.

## 4. 비용과 납기

FDM이 쌉니다. 소재비가 낮고 출력 속도가 빠릅니다.

| 기준 | FDM | SLA |
| --- | --- | --- |
| 단가 (손바닥 크기) | 1만~5만 원 | 3만~15만 원 |
| 소재비 | 필라멘트 kg당 3만~10만 원 | 레진 L당 10만~40만 원 |
| 납기 | 당일~1일 | 1~2일 |
| 후처리 | 서포트 제거 | 세척 + 경화 + 서포트 제거 |

SLA는 출력 후 **세척과 UV 경화**가 필수입니다. 이 후처리 시간과 비용이 추가됩니다. FDM은 서포트만 떼면 바로 쓸 수 있습니다.

비용 구조 전체는 [같은 크기인데 왜 값이 다른가](/blog/3d프린팅-비용-구조/)에 정리했습니다.

# FDM도 SLA도 아닌 경우

두 방식 모두 안 맞을 때가 있습니다.

| 상황 | 대안 |
| --- | --- |
| 서포트 없이 복잡한 형상을 뽑아야 한다 | SLS |
| 풀컬러가 필요하다 | PolyJet |
| 금속 부품이다 | DMLS 또는 CNC |
| 10개 이상 동일 부품이 필요하다 | SLS 또는 진공주형 |

SLS와 MJF의 차이는 [SLS와 MJF 비교](/blog/sls-mjf-차이/)에, SLA·SLS를 포함한 전체 비교는 [SLA와 SLS 비교](/blog/sla-sls-비교/)에 정리했습니다.

# 둘 다 써보는 방법

어떤 방식이 맞는지 모르겠으면 **같은 파일로 FDM과 SLA를 하나씩 뽑아보는 것**이 가장 확실합니다. 표면, 정밀도, 강도를 직접 비교할 수 있습니다.

실물 비교 사례는 [같은 부품 방식별 비교](/blog/같은-부품-방식별-비교-사례-3건/)에서 확인하실 수 있습니다.

방식을 정하지 않고 부품 사진이나 도면과 함께 용도를 알려주시면 어떤 방식이 맞는지 안내드립니다.

# 자주 묻는 질문

:::faq
FDM으로 뽑은 부품을 매끈하게 만들 수 있나요
가능합니다. 연마, 퍼티 처리, 도장을 하면 층결이 사라집니다. 다만 후처리 비용이 추가되므로 처음부터 SLA로 뽑는 편이 나을 수 있습니다. 후처리 종류는 [3D프린팅 후처리 종류](/blog/3d프린팅-후처리-종류/)를 참고하시면 됩니다.
:::

:::faq
SLA 부품은 깨지기 쉬운가요
표준 레진은 그렇습니다. 터프 레진이나 듀러블 레진을 쓰면 충격 강도가 올라갑니다. 다만 FDM 나일론이나 ABS만큼은 아닙니다. 기능 부품은 소재 선택을 먼저 상담하시면 됩니다.
:::

:::faq
투명한 부품은 어떤 방식이 맞나요
SLA가 맞습니다. 클리어 레진으로 출력하면 반투명~투명 수준이 나옵니다. FDM으로는 투명 소재가 있지만 층결 때문에 불투명해집니다. [투명 3D프린팅 부품 소재 비교](/blog/투명-3d프린팅-부품-소재-비교/)에서 자세히 다뤘습니다.
:::

:::faq
대형 부품은 어떤 방식이 맞나요
FDM이 맞습니다. SLA는 조형 크기가 제한적입니다. 30cm 이상 부품은 FDM 대형 장비로 출력하거나 분할 출력 후 접합하는 방법을 씁니다.
:::
