*3D프린팅 반복 생산의 품질 관리를 설명하기 위한 이미지입니다.*

첫 주문 20개는 조립됐는데 2개월 뒤 주문한 부품은 끼움이 빡빡할 수 있습니다. 파일은 같아도 출력과 후처리 조건이 달라졌기 때문입니다.

반복 생산에서 말하는 “같다”는 **합의한 기준 안에 들어온다**는 뜻이어야 합니다.

# STL 파일만 같으면 부족합니다

결과를 다시 맞추려면 6가지 기록이 필요합니다.

| 관리 항목 | 남길 내용 |
| --- | --- |
| 파일 | 파일명과 개정 번호, 변경일 |
| 출력 공정 | 방식, 장비, 주요 조건 |
| 배치 | 출력 방향과 배치 위치, 수량 |
| 소재 | 정확한 제품명과 색상, 로트 |
| 후처리 | 세척, 염색, 스무딩, 연마 조건 |
| 검사 | 측정 위치, 도구, 허용 범위 |

같은 형상이라도 방향을 돌리면 표면과 강도가 달라질 수 있습니다. 염색 시간이나 연마량이 바뀌면 색과 치수도 달라집니다.

# 반복성과 정확도는 다릅니다

반복성은 여러 번 만들었을 때 결과가 얼마나 일정한지를 말합니다. 정확도는 목표 치수에 얼마나 가까운지를 봅니다.

매번 0.2mm 크게 나오는 공정은 반복성은 좋지만 정확하지 않을 수 있습니다. 반대로 평균값은 목표와 가까워도 부품마다 값이 크게 흔들리면 반복 생산에 쓰기 어렵습니다.

Stratasys와 Formlabs도 장비의 반복성을 시험할 때 여러 위치와 여러 빌드에서 시편을 측정합니다. 제조사 연구의 수치를 모든 부품에 그대로 적용하기보다, 실제 부품의 주요 치수로 승인 범위를 정해야 합니다.

# 첫 주문을 기준으로 남깁니다

첫 주문에서 해야 할 일은 합격품을 고르는 것입니다. 외관만 찍어 두지 말고 실제 조립과 주요 치수를 확인합니다.

1. 첫 부품을 제작합니다.
2. 상대 부품에 조립해 봅니다.
3. 주요 치수와 표면 상태를 기록합니다.
4. 승인 샘플 1개를 보관합니다.
5. 다음 주문부터 같은 기준으로 검사합니다.

검사 항목은 [3D프린팅 부품 검수, 치수 측정과 성적서](/blog/3d프린팅-부품-검수/)에 정리했습니다. 공차가 필요한 위치는 [3D프린팅 공차, 도면 치수대로 어디까지 나오나](/blog/3d프린팅-치수-공차/)를 함께 보십시오.

# 소재와 후처리도 고정합니다

“나일론 검정”만 적으면 재료 등급과 착색 방식이 달라질 수 있습니다. 소재 제조사와 제품명, 원재료 색상, 염색 또는 도색 조건까지 기록해야 합니다.

납품 문서가 필요한 부품은 로트 자료도 확인합니다. 문제가 생겼을 때 어느 재료와 어느 배치에서 만든 부품인지 찾을 수 있어야 합니다.

# 맞는 경우와 다시 검토할 경우

| 반복 생산으로 관리하기 좋은 경우 | 공정을 다시 정해야 하는 경우 |
| --- | --- |
| 매달 같은 지그를 10개씩 주문하는 경우 | 파일이 주문마다 바뀌는 개발 시제품 |
| 서비스 부품을 필요한 만큼 보충하는 경우 | 색상과 표면 기준이 정해지지 않은 부품 |
| 승인 샘플과 주요 치수가 있는 경우 | 장비나 소재를 임의로 바꿔도 된다고 발주한 경우 |
| 배치별 검사 기록이 필요한 납품 건 | 사출품 수준의 외관을 기준 없이 요구하는 경우 |

수량이 늘면 개당 단가만 보지 말고 검사와 재주문 주기를 함께 봐야 합니다. 비용 항목은 [3D프린팅 소량생산, 수량이 늘면 단가는 어떻게 되나](/blog/3d프린팅-소량생산-단가/)에서 확인할 수 있습니다.

# 담당자가 확인할 것

1. **기준 파일의 개정 번호를 정합니다.** 메일에 흩어진 파일 대신 승인본 1개를 관리합니다.
2. **승인 샘플을 보관합니다.** 색과 표면, 조립감을 비교할 실물이 필요합니다.
3. **주요 치수를 표시합니다.** 모든 치수보다 조립과 기능에 영향을 주는 위치가 먼저입니다.
4. **변경 승인 절차를 정합니다.** 장비나 소재, 후처리를 바꿀 때 알림을 받을지 정합니다.
5. **배치별 검사 수량을 합의합니다.** 첫 부품, 표본, 전수 검사 가운데 고릅니다.

# 자주 묻는 질문

:::faq
같은 파일이면 다음 주문도 똑같이 나오나요
같은 파일은 출발점일 뿐입니다. 장비와 출력 방향, 소재, 후처리, 측정 조건이 함께 관리돼야 편차를 줄일 수 있습니다.
:::

:::faq
승인 샘플은 몇 개를 보관해야 하나요
기준 비교용으로 최소 1개가 필요합니다. 파손 가능성이 있거나 여러 사업장에서 검사한다면 보관 수량을 늘립니다.
:::

:::faq
소재 로트가 바뀌면 다시 승인해야 하나요
납품 요구와 부품 민감도에 따라 다릅니다. 색과 치수, 물성 변화가 문제가 되는 부품이라면 변경 확인이나 표본 검사가 필요합니다.
:::

:::faq
매번 전수 검사해야 하나요
안전과 규격에 영향을 주는 항목은 전수 검사가 필요할 수 있습니다. 일반 부품은 첫 부품과 배치별 표본을 정하는 방법이 있습니다.
:::

반복 주문의 기준은 기억이 아니라 기록입니다. 첫 주문에서 승인할 값과 샘플을 남겨야 다음 주문을 같은 기준으로 받을 수 있습니다.
