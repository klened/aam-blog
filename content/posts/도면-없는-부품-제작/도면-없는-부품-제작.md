*실물 부품을 기준으로 데이터를 복원하는 과정을 설명하기 위한 이미지입니다.*

설비는 멈췄는데 부품 도면이 없습니다. 제조사는 단종됐고, 남은 것은 마모된 실물 1개뿐인 경우도 있습니다.

이때도 제작을 검토할 수 있습니다. 실물을 바로 출력하지는 않습니다. 측정하고 3D 데이터를 먼저 만듭니다.

# 시작할 수 있는 자료

| 보유 자료 | 확인할 수 있는 것 | 추가로 필요한 것 |
| --- | --- | --- |
| 멀쩡한 실물 | 바깥 형상과 결합 치수 | 재질과 사용 조건 |
| 마모·파손된 실물 | 남은 형상과 상대 부품의 결합 위치 | 원래 치수의 추정 근거 |
| 사진 | 전체 모양과 설치 위치 | 기준 치수와 여러 각도 사진 |
| 손그림·스케치 | 기능과 대략적인 구조 | 실제 치수와 결합 방식 |
| 2D 도면 | 주요 치수와 단면 | 누락된 면과 최신 변경 내용 |

자료가 많을수록 추정이 줄어듭니다. 실물과 사진, 설치 위치를 함께 보내면 기능을 이해하기 쉽습니다.

# 실물은 3단계로 데이터가 됩니다

## 1. 기능과 기준 치수를 확인합니다

먼저 무엇과 맞물리는지 봅니다. 나사 구멍, 축 중심, 밀폐면처럼 기능을 결정하는 곳을 표시합니다.

## 2. 측정하고 모델을 만듭니다

단순 형상은 캘리퍼스와 높이 게이지로 측정할 수 있습니다. 자유곡면이 많으면 3D 스캔을 씁니다. Formlabs도 실물을 스캔한 뒤 CAD 형상으로 바꾸는 과정을 안내합니다.

스캔 데이터는 점과 면의 기록입니다. 수정 가능한 CAD 모델이 필요하면 다시 모델링해야 합니다.

![마모된 기계 부품을 3D스캔해 형상 데이터를 만드는 모습](/images/도면-없는-부품-제작/2.webp)

## 3. 1개를 출력해 맞춰 봅니다

첫 부품을 실제 장비에 끼워 봅니다. 간섭과 유격, 작동 방향을 확인하고 데이터를 보정합니다. 이후 파일을 보관하면 다음 주문부터 같은 기준으로 만들 수 있습니다.

![원본 부품과 출력 대체품을 비교해 장비에 장착하는 모습](/images/도면-없는-부품-제작/3.webp)

# 스캔만으로 해결되지 않는 것

마모된 면은 현재 상태로 측정됩니다. 원래 두께와 구멍 위치를 자동으로 복원하지는 못합니다. 상대 부품이나 같은 설비의 멀쩡한 부위를 함께 확인해야 합니다.

실물 안쪽이 막혀 있으면 광학 스캐너가 내부 형상을 볼 수 없습니다. 분해, 절단, CT 촬영, 기능을 바탕으로 한 재설계 중에서 방법을 정합니다.

재질도 겉모양만으로 확정하기 어렵습니다. 온도, 하중, 오일 접촉, 반복 동작을 알려주면 출력 소재 후보를 좁힐 수 있습니다.

# 맞는 경우와 다시 검토할 경우

| 제작 검토가 가능한 경우 | 먼저 확인할 경우 |
| --- | --- |
| 단종돼 구매할 수 없는 설비 부품 | 아직 정품 부품을 구할 수 있는 경우 |
| 형상은 남고 도면만 없는 부품 | 마모가 심해 원래 치수를 추정하기 어려운 경우 |
| 상대 부품에 맞춰 시험할 수 있는 경우 | 내부 구조를 확인할 수 없는 밀폐 부품 |
| 1개를 먼저 제작해 수정할 수 있는 경우 | 특허·디자인권 등 권리 확인이 필요한 경우 |

정밀 기어와 고속 회전 부품은 형상 복원만으로 끝나지 않습니다. 재질, 열처리, 표면, 내구 시험까지 다시 검토해야 합니다.

# 담당자가 확인할 것

1. **실물과 파손 조각을 버리지 않습니다.** 작은 조각도 형상 복원의 근거가 됩니다.
2. **설치된 모습을 촬영합니다.** 주변 부품과 작동 방향이 보여야 합니다.
3. **기준 치수를 3곳 이상 잽니다.** 사진만 보낼 때는 자를 함께 놓습니다.
4. **사용 조건을 적습니다.** 온도, 하중, 접촉 물질, 반복 횟수가 필요합니다.
5. **원하는 산출물을 정합니다.** 출력 부품만 필요한지, 수정 가능한 CAD도 필요한지 구분합니다.

역설계 비용이 궁금하면 [도면 없는 부품, 역설계 비용은 얼마인가](/blog/역설계-비용-사례-4건/)에서 실제 사례를 확인할 수 있습니다.

# 자주 묻는 질문

## 실물을 택배로 보내야 하나요

정확한 역설계에는 실물이 필요한 경우가 많습니다. 먼저 여러 각도 사진과 기준 치수를 보내면 가능 여부와 필요한 측정 방법을 안내할 수 있습니다.

## 부서진 부품도 만들 수 있나요

남은 형상과 상대 부품에서 원래 치수를 추정할 수 있으면 가능합니다. 추정한 부분은 1개를 시험 제작해 확인해야 합니다.

## 3D 스캔 파일만 받으면 바로 출력할 수 있나요

스캔 상태에 따라 다릅니다. 구멍과 평면, 마모된 면을 수정하고 출력 가능한 닫힌 형상으로 만드는 작업이 필요할 수 있습니다.

## 1개만 만들어도 되나요

가능합니다. 처음에는 1개를 제작해 장착과 작동을 확인하는 편이 안전합니다.

도면이 없다는 이유만으로 제작을 포기할 필요는 없습니다. 실물에서 기능을 읽고, 기준 치수를 정한 뒤 데이터를 복원하면 됩니다.
