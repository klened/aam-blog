# 금지 표현과 고쳐 쓰는 법

이 목록은 생각나는 대로 적은 것이 아니다. `dowon-blog/content` 발행본 265편에
돌려서 **한 번도 걸리지 않은 것만** 남겼다. 발행본은 사람이 고쳐 내보낸 글이라
거기서 걸리는 규칙은 초고를 고치는 게 아니라 완성된 글을 흔든다.

처음 만든 목록은 265편 중 242편을 걸었다. 749건 중 722건이 오탐이었다.
그래서 아래 2부가 1부만큼 중요하다.

---

# 1부 · 쓰지 않는다

## 은유 명사

영어 낱말을 그대로 옮기면 나온다. 「방법」이라고 쓰면 될 자리다.

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| 지금이라도 대응할 **길이 있습니다** | 지금이라도 대응할 **수 있습니다** |
| 아직 **풀 길이** 남았습니다 | 아직 **방법이** 남았습니다 |
| 성공의 **열쇠**는 준비입니다 | 미리 준비하면 됩니다 |
| 해결의 **첫걸음**입니다 | 여기서부터 시작합니다 |
| 합의의 **관문**을 넘으면 | 합의가 끝나면 |
| 절세의 **지름길** | 세금을 줄이는 방법 |

## 마무리 인사

부탁받지 않은 인사다. 산업 글에서는 전부 군더더기다.

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| **도움이 되었으면 합니다** | (삭제) |
| **궁금한 점이 있으시면** 연락 주세요 | 상황을 알려주시면 확인해 드립니다 |
| **참고하시기 바랍니다** | (삭제) |
| **함께 살펴보겠습니다** | (삭제하고 본론부터) |
| **오늘은 퇴직금에 대해 알아보겠습니다** | (삭제하고 본론부터) |

## 상투구

어느 글에나 들어가는 문구다. 들어가면 글이 남의 글처럼 읽힌다.

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| **게임 체인저**입니다 | 무엇이 어떻게 바뀌는지 쓴다 |
| **강력한 도구**입니다 | 무엇을 할 수 있는지 쓴다 |
| 노무 관리의 **세계로** | (삭제) |
| **깊이 들여다보면** | (삭제) |
| **여정을 시작**합니다 | (삭제) |
| **오늘날의 급변하는** 환경에서 | (삭제) |
| **당신은 혼자가 아닙니다** | (삭제) |
| **완벽하지 않아도 괜찮습니다** | (삭제) |
| **핵심은 다음과 같습니다** | (삭제하고 바로 서술) |
| 한 가지 **밝혀둡니다** | (삭제하고 바로 서술) |
| 마지막 항목을 **밝혀둡니다** | 마지막 항목이 **특히 중요합니다** |

「밝혀 두다」는 사실을 드러내 알린다는 뜻이다. 부연 설명에 쓰면 무게가 안 맞는다.
265편에서 0건이다. **「마지막 항목」 자체는 정상이다.** 2부를 볼 것.

## 번역 투

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| **당신의** 회사는 | 사업장은 / (주어 삭제) |
| 자료를 **가지고 있습니다** | 자료가 **있습니다** |
| 가장 강한 자료 **중 하나입니다** | 가장 강한 자료가 **진술입니다** |
| 단순한 벌금 **그 이상입니다** | 벌금**에 그치지 않습니다** |
| 설명하는 **데 도움이 됩니다** | 설명이 **쉬워집니다** |
| 방법이 **존재합니다** | 방법이 **있습니다** |
| 확인**할 필요가 있습니다** | 확인**해야 합니다** |
| 검토**를 진행합니다** | **검토합니다** |
| **여러 사례들** | **여러 사례** |
| **효과적인 전략적** 접근 | (「~적」은 한 문장에 하나만) |

## 등치 구문

「A하는 것이 B하는 것이다」로 두 가지를 같다고 묶으면 경구처럼 보이지만 뜻이
흐려진다. 조건과 결과로 푼다. 265편에서 0건 걸렸다.

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| 서류를 받는 **것이** 시간을 버는 **것입니다** | 서류를 미리 받아두면 판단할 시간이 생깁니다 |
| 기록을 남기는 **것이** 방어하는 **것입니다** | 기록을 남겨두면 나중에 반박할 수 있습니다 |

「A가 아니라 B다」는 대비라서 정상이다. 2부를 볼 것.

## 글의 가치를 자평하지 않는다

「이 글에서 가장 ~하다」처럼 글을 스스로 평가하면 독자가 쓸 데가 없다. 독자가
할 행동으로 바꾼다. 265편에서 「이 글에서」는 0건이다.

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| 이 부분이 **이 글에서 가장 실용적입니다** | 계약 전에 **가장 먼저 확인하셔야 할 부분입니다** |

「이 글은 ~를 놓고 적었습니다」처럼 **범위를 한정하는 쓰임은 정상이다.** 2부를 볼 것.

## 띄어쓰기와 숫자

| 쓰지 않는다 | 이렇게 쓴다 |
|---|---|
| 세번째 입니다 | **3번째입니다** |
| 세 가지 입니다 | **3가지입니다** |
| 사흘 안에 | **3일 안에** |

숫자는 아라비아 숫자로 쓴다. 「하루」 「이틀」은 관용이라 그대로 둔다.

# 2부 · 고치지 않는다

아래는 발행본 265편에서 실제로 쓰는 말이다. **번역 투로 오해하고 고치면
글이 나빠진다.** 처음 만든 규칙이 이것들을 걸어서 242편이 검출됐다.

## 「두 번째로 / 세 번째는」 — 본문 뼈대다

265편이 이 구조로 쓰였다. 305건 걸렸고 전부 정상이었다.

> 두 번째로 확인하는 것이 **퇴직일을 조정할 수 있는지**예요.
> 세 번째는 **근로계약서**예요.

개수를 세는 것 자체는 문제가 아니다. 문제는 「세번째 입니다」처럼 띄어쓰기가
틀린 경우와, 개수만 예고하고 내용이 없는 경우다.

## 「사실상」 — 노동법 용어다

「사실상 하나의 사업」은 노동위원회 판단 기준이다. 지우면 뜻이 달라진다.

> 급여·인사·회계가 **사실상 하나로** 굴러가면 합산될 수 있습니다.

## 관용구는 은유가 아니다

| 그대로 둔다 | 이유 |
|---|---|
| 전례가 **발목을 잡아요** | 굳어진 관용구 |
| **문을 연 지** 얼마 안 된 회사 | 개업을 뜻하는 관용구 |
| **손을 들어** 주는 경우 | 관용구 |

새로 만든 은유만 잡는다. 사전에 있는 관용구는 그냥 한국어다.

## 「둘 중 하나입니다」 — 갈래가 둘이라는 뜻이다

one of the 직역이 아니다. 앞에 수를 세는 말이 오면 정상이다.

> 임금을 못 주는 회사는 대개 **다음 중 하나입니다.**
> 이유는 대개 **둘 중 하나예요.**

잡아야 하는 것은 「가장 강력한 도구 **중 하나입니다**」 꼴이다.

## 「가능성이 있으면」 — 평범한 한국어다

> 장해가 남을 **가능성이 있으면** 그보다 높게 잡습니다.
> 업무상 **필요성이 있는가**를 먼저 봅니다 ← 괴롭힘 판단 기준 용어

## 「A는 ~하는 것이고 B는 ~하는 것입니다」 — 대비 설명이다

둘을 갈라 설명할 때는 이 꼴이 맞다.

> 앞은 피보험자격을 알리는 **것이고**, 뒤는 지급한 소득을 신고하는 **것입니다.**

「A가 아니라 B다」도 같은 대비다. 265편에서 4건 걸렸고 전부 정상이었다.

> 넘겨주는 **것이 아니라** 내보내는 **것입니다.**
> 못 받는 **것이 아니라** 늦게 받는 **것입니다.**

혼자 쓰였고 대비가 아니면 그때만 「~합니다」로 줄인다.

## 「지점」 — 이 블로그의 뼈대다

은유 명사로 오해하기 쉽지만 발행본 전반에 쓰이고 `_템플릿.md`에도 들어 있다.
고치면 글이 밋밋해진다.

> 결과가 **갈리는 지점**입니다.
> 여기가 실무에서 **뒤집히는 지점**입니다.
> 가장 많이 **놓치는 지점**입니다.

## 「이유가 여기 있습니다」 — 지시어로 끝내도 된다

상담하듯 설명하는 문체라 자연스럽다. 265편에서 널리 쓰인다.

> 연봉이 오를 때마다 계약서를 다시 쓰는 **이유가 여기 있습니다.**
> 다투는 지점은 **이것입니다.**
> 끼임 사고의 대부분이 **여기입니다.**

## 「마지막 항목」 — 표를 짚어 주는 말이다

앞의 목록에서 어느 줄을 봐야 하는지 알려 준다. 265편에서 12건 쓰였고 전부
정상이었다. 「위 표」 「아래 표」도 3건 있고 같다.

> **마지막 항목이** 건설현장에서 특히 중요합니다.
> **마지막 항목은** 특히 조심하셔야 합니다.
> **마지막 항목이** 의외로 많습니다.
> **위 표대로** 한 사람씩 놓고 보시면 어긋나는 자리가 보입니다.

고칠 것은 항목을 가리키는 말이 아니라 뒤에 붙는 서술어다. 「마지막 항목을
밝혀둡니다」는 서술어가 과하다. 「마지막 항목이 특히 중요합니다」처럼 바로
내용에 붙인다.

## 「이 글은 ~」 — 범위를 한정하는 말이다

글을 자평하는 「이 글에서 가장 ~」과는 다르다. 읽는 사람이 자기 상황에
해당하는지 판단하게 해 준다.

> **이 글은** 병원에서 근무하는 봉직의를 놓고 적었습니다.
> **이 글은** 구조를 정리한 것이고, 실제 신청은 그해 기준으로 확인하셔야 해요.

## 「옆에 있어야」 — 「~에 있어서」가 아니다

`있어서` 규칙은 「~에 있어(서)」라는 일본어 번역 투를 잡는 것이다. 그런데
「곁에 있어야」 「사내에 있어야」처럼 **장소를 나타내는 조사 뒤에 동사 「있다」가
오는 경우**까지 함께 걸린다. 뜻이 전혀 다르므로 고치지 않는다.

> 장비가 옆**에 있어**야 합니다.
> 담당자가 현장**에 있어**야 확인이 됩니다.

고칠 것은 「검토**에 있어서**」 「선정**에 있어**」처럼 명사 뒤에 붙어
「~에서」로 바꿔야 하는 쪽이다.

## 「대부분입니다」 — 「~하는 부분입니다」가 아니다

`부분입니다` 규칙은 「확인이 필요한 부분입니다」처럼 군더더기로 붙는 「부분」을
잡는 것이다. **「대부분」은 그 자체로 한 낱말**이라 걸려도 고치지 않는다.

> 장비가 서 있는 시간이 **대부분입니다**.
> 문의는 **대부분** 도면 없이 들어옵니다.

## 「갈라지다」 — 저절로 갈라지는 것이다

`갈라` 규칙은 서술어와 목적어가 어긋나는 것을 잡는다. 그런데 **「갈라지다」는
자동사**라 목적어를 받지 않는다. 유로가 갈라지고 흐름이 갈라지는 것은 정상이다.

> 내부에 T자로 **갈라지는** 유로
> 흐름이 **갈라지는** 지점

고칠 것은 사람이 무엇을 「가른다」고 쓸 때다. 그때는 목적어가 맞는지 본다.

## 「정리하면」 — 동사로 쓸 때가 있다

`정리문구` 규칙은 「정리하면 이렇습니다」처럼 글을 요약하며 끊는 말을 잡는다.
「서류를 **정리하면** 됩니다」 「외관만 **정리하면** 될 때」처럼 실제로 무엇을
정돈한다는 뜻이면 그대로 둔다.

# 검사

원고를 내기 전에 두 도구를 돌린다. 역할이 다르다. 둘 다 `dowon-blog` 저장소
뿌리에서 돌린다.

```bash
node scripts/문체검사.mjs 원고.txt      # 문형·문장 길이·문단 리듬
python scripts/korfix.py 원고.md        # 어휘·상투구
```

규칙을 새로 넣을 때는 발행본에 먼저 돌린다. 거기서 걸리면 규칙이 아니라 오탐이다.

```bash
python scripts/korfix.py content --quiet
```

초고와 발행본의 차이에서 새 규칙 후보를 캐려면 아래를 쓴다.

```bash
python scripts/초고비교.py --초고
```
