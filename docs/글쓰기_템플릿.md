첫 문단에서 결론과 적용 범위를 밝힙니다. 인사말이나 “알아보겠습니다” 같은 예고형 문장은 쓰지 않습니다.

둘째 문단에서는 독자가 왜 이 질문을 하게 되었는지 실제 상황을 짚습니다. 첫 문단과 같은 결론을 반복하지 않습니다.

# 판단 기준은 무엇인가

결론을 가르는 기준을 설명합니다. 독자가 자신의 상황을 대입할 수 있게 조건과 예외를 함께 씁니다.

비교할 항목이 둘 이상일 때만 표를 사용합니다.

| 구분 | 판단 기준 | 결과 |
| --- | --- | --- |
| 첫 번째 경우 | 기준을 씁니다 | 결과를 씁니다 |
| 두 번째 경우 | 기준을 씁니다 | 결과를 씁니다 |

# 실제로는 어떻게 적용되는가

제공받은 실제 사례가 있으면 사실과 수치 안에서 씁니다. 실제 사례가 없고 설명에 도움이 될 때만 가정한 예시를 사용합니다.

:::예시 어떤 조건에서 결과가 달라지는지
가정한 상황임을 알 수 있게 조건을 적습니다.

- 첫 번째 판단 기준 → 결과
- 두 번째 판단 기준 → 결과

이 선택이 실제로 어떤 차이를 만드는지 정리합니다.
:::

# 예외와 주의할 점

앞의 결론이 적용되지 않거나 별도 확인이 필요한 조건을 씁니다. 모든 글에 억지로 만들 필요는 없습니다.

관련 글은 독자의 다음 판단에 실제로 필요할 때만 [문맥 안에서 연결](/blog/다른-글-슬러그/)합니다.

# 담당자가 확인할 것

1. 지금 바로 확인해야 할 자료나 사실을 씁니다.
2. 결론을 바꾸는 조건을 확인합니다.
3. 기한이나 다음 행동을 확인합니다.

# 자주 묻는 질문

본문과 겹치지 않는 실제 질문이 있을 때만 작성합니다. 질문 수를 맞추기 위해 내용을 반복하지 않습니다.
