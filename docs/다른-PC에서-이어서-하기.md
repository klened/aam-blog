# 다른 PC에서 이어서 하기

같은 계정으로 로그인해도 **계정은 인증만 해 준다.** 파일은 따라오지
않는다. 저장소는 깃이 옮겨 주고, 나머지 셋은 손으로 옮겨야 한다.

## 1. 저장소 (깃이 옮겨 준다)

윈도우 PowerShell 은 `&&` 를 못 쓴다. 한 줄씩 따로 친다.

```
git clone https://github.com/choim-gif/dowon-blog.git
```
```
cd dowon-blog
```
```
npm install
```
```
npm run build
```

세 줄이 전부다. **`.env` 는 만들지 않아도 된다.** 주소·GA·채널톡 값이
모두 `src/config/site.ts` 에 기본값으로 박혀 있어서, 파일이 없으면 그
기본값을 쓴다. 2026-08-06 에 `.env` 를 치우고 빌드해 314쪽이 그대로
나오고 canonical 도 https://blog.dowonhr.com 으로 맞는 것을 확인했다.

값을 바꿔야 할 때만 `.env.example` 을 `.env` 로 복사한다. 그때도
명령을 칠 것 없이 탐색기에서 복사해 이름만 바꾸면 된다.

이것으로 **글 245편, 그림 전부, 코드, 표지 스크립트**가 다 온다.
배포는 깃 푸시가 방아쇠라서 `git push` 만 하면 사이트가 다시 올라간다.

표지를 만들 거면 파이썬이 더 있어야 한다. 글꼴은 윈도우 기본 맑은
고딕을 쓰므로 윈도우면 따로 깔 것이 없다.

```bash
pip install pillow
```

## 2. 클로드 기억 (손으로 옮긴다)

프로젝트마다 따로 쌓이고 **폴더 이름이 프로젝트 경로를 그대로 인코딩**한
것이라, 새 PC 에서도 **작업 폴더 경로가 같아야** 찾는다.

| | |
| --- | --- |
| 있는 곳 | `C:\Users\owner\.claude\projects\C--Users-owner-Desktop------claude\memory\` |
| 개수 | 27개 (2026-08-06 기준) |
| 경로가 뜻하는 것 | `C:\Users\owner\Desktop\★업무\.claude` |

그래서 새 PC 에서도 작업 폴더를 **`C:\Users\owner\Desktop\★업무\`** 아래
같은 이름으로 두는 편이 편하다. 사용자 이름이 다르면 폴더 이름의
`owner` 부분이 달라지므로, 그때는 새 PC 에서 클로드를 한 번 띄워
어떤 폴더가 생기는지 보고 그 안에 넣는다.

대화 기록(`*.jsonl`)도 같은 폴더에 있다. 옮기면 지난 대화를 이어서
열 수 있고, 안 옮겨도 작업에는 지장이 없다.

## 3. 시트 원자료 (손으로 옮긴다)

`npm run 계획` 이 읽고 쓰는 자리다. 구글 시트를 받아 오지 못할 때
쓰는 사본과, 아직 시트에 안 넣은 MAP 추가안들이 들어 있다.

| | |
| --- | --- |
| 있는 곳 | `C:\Users\owner\Desktop\1\` |
| 중요한 것 | `도원_시트원본.csv`, `MAP_*추가안.csv` |

폴더가 없으면 저장소 안 `작업/` 폴더로 떨어진다. 다른 자리를 쓰려면
환경변수로 준다.

```bash
작업폴더=D:/도원 npm run 계획
```

인터넷이 되면 구글 시트를 직접 읽으므로 `도원_시트원본.csv` 가 없어도
`npm run 계획` 은 돈다. 사본은 시트를 못 받을 때만 쓴다.
