# 대표이미지 만드는 스크립트

글마다 들어가는 1200×630 대표이미지를 만든다. 2026-08-06 까지는 세션
임시 폴더에만 있었다. 임시 폴더는 지워지므로 저장소로 옮겼다.

## 쓰는 법

파이썬과 Pillow 가 있어야 한다. 글꼴은 윈도우 기본 맑은 고딕을 쓴다.

```bash
pip install pillow
python scripts/표지/cover_seonghuirong.py
```

만들어진 그림은 `content/posts/<슬러그>/1.webp` 로 바로 들어간다.
그다음 `npm run 이미지모으기` 로 `public/images/` 에 옮긴다.

## 구조

`cover_chebul2_base.py` 하나가 엔진이다. 나머지는 묶음별 원고라서
맨 위에서 이 파일을 `exec` 로 불러 쓴다.

```python
exec(compile(io.open(os.path.join(여기, 'cover_chebul2_base.py'),
     encoding='utf-8').read(), 'base', 'exec'))
```

엔진이 주는 것은 여섯이다.

| 이름 | 하는 일 |
| --- | --- |
| `base(제목, 근거)` | 바탕과 머리글을 그리고 `(im, d)` 를 준다 |
| `table(d, 머리, 줄들, 강조, 폭, top)` | 표를 그리고 표 아래 y 좌표를 준다 |
| `steps(...)` | 단계 그림 |
| `footer(d, 제목, 설명)` | 아래쪽 주의 문구 |
| `save(im, 슬러그)` | 글 폴더에 1.webp 로 저장 |
| `f(굵기, 크기)` | 글꼴 |

2배 확대(S=2)로 그린 뒤 줄여서 글자가 매끄럽다.

## 자리 잡을 때 걸리는 것

**표 아래 글이 아래쪽 주의 문구를 덮는다.** 아래쪽이 y=464 와 504 에
고정이라, 표가 길면 그 위 글이 거기까지 내려온다.

| 표 줄 수 | `top` | 표 아래 글 간격 |
| --- | --- | --- |
| 2줄 | 140 | 40 / 76 / 116 / 152 |
| 3줄 | 140 | 40 / 76 / 112 / 146 |
| 4줄 이상 | 118 | 42 / 78 (두 줄까지만) |

넘칠 것 같으면 `top` 을 내리기 전에 **글을 한 줄 줄이는 편**이 낫다.
줄이 촘촘해지면 표지에서 읽히지 않는다.

## 새 묶음을 만들 때

가장 가까운 묶음 파일을 복사해서 고쳐 쓴다. 표 줄 수가 같은 것을
고르면 자리를 다시 잡을 일이 없다.
